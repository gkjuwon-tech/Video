## 0. 요약

1. **우리 컴퓨트의 화폐는 FLOPs가 아니라 교사 호출(NFE)이다.** 90일 상시 가동 기준 2×T4는 4,320 T4-h이고, 그중 약 55–60%가 이미지 교사 호출(데이터 엔진과 솔버)에 쓰인다. 수십M 모델 카탈로그 **전체(약 0.25B 파라미터)를 처음부터 한 번 학습하는 데는 약 195 T4-h**(2×T4로 약 4일)가 든다. 작은 모델 학습 비용은 반올림 오차 수준이다. 그러므로 최적화 대상은 학습 효율이 아니라 **교사 호출 1회당 뽑아내는 정보량**이다.
2. **접착제 가설(Glue Hypothesis).** 수십M이면 충분한 이유는 우리 모델들이 세계를 "아는" 모델이 아니라는 데 있다. 이 모델들은 이미 지식을 가진 원천들 사이의 **인터페이스(glue)**만 학습한다. 의자가 어떻게 생겼는지는 교사가, 빛이 어떻게 튀는지는 렌더러가, 물체가 어떻게 떨어지는지는 시뮬레이터가, 벽돌이 어떻게 쌓이는지는 절차 생성 코드가 안다. 인수분해 덕분에 각 인터페이스는 국소적이고 저차원이며 대역이 제한된 함수가 된다.
3. **카탈로그.** Phase 1용 12개(약 180M)와 Phase 2용 5개(약 69M)로 구성한다. 핵심은 LBO-S(세계 공간 디테일 연산자, 24M), MRH(교사 특징 위의 "독심" 헤드, 22M), BRP(3D bedrock prior, 42M), PWMT(세계 전속 미니 교사, 5M, 테스트타임 학습), 그리고 DP-0 3종(Hand-S 8M, Path-S 19M, CRM-S 12M)이다.
4. **제약이 낳은 아이디어 Top 3.** (a) **PWMT**: 세계 하나 안에서도 교사를 amortize하는 테스트타임 학습 surrogate. 순서 불변성을 지키는 Jacobi 대칭 부분집합 선택을 쓴다. (b) **MRH**: 노이즈 상태 latent에서 교사의 기하 의도를 읽는다. 외부 depth 모델을 금지한 덕분에, 원리적으로 외부 모델은 할 수 없는 일을 하게 됐다. (c) **기생 학습(Parasitic Training) + Feature Tap Bus**: 시스템 어디서든 교사가 한 번 호출되면 모든 헤드가 그 호출에서 동시에 학습 신호를 받는다.
5. **해자는 데이터 엔진이다.** 데이터 엔진의 기본 문장은 "기하는 코드에서, 외형은 교사에서, 라벨은 구성(construction)에서"다. 하루 생산량은 교사 운송 샘플 약 2만 장/T4-day, 절차 생성 voxel 장면 약 100만 개, 재질 타일은 사실상 무제한이고, 솔버로 만든 세계 W*는 하루 1.5–6개다. 이 데이터는 렌더러, WNF, 솔버, 절차 생성, IMU 캡처 파이프라인이 모두 있어야만 나온다. 그래서 H100을 가진 경쟁자도 컴퓨트로 살 수 없다.

### 1.2 T4 루프라인 설계 규칙 [신규 설계 규칙]

T4의 compute-bound 경계는 65 TFLOPS / 320 GB/s ≈ **203 FLOP/byte**다. 여기서 소형 모델 형태에 대한 규칙이 나온다.

- **Transformer:** 큰 M에서 matmul 강도는 약 KN/(K+N)이다. d=256(K=N=256)이면 128로 **memory-bound**다. d=512에 MLP 4×(512×2048)이면 410이다. 그래서 **d ≥ 384, 토큰 배치 ≥ 32k**로 둔다. 얕고 넓게 설계한다.
- **3×3 conv:** 강도는 약 4.5·C다. C=32면 144로 bound이고, C=64면 288이다. 그래서 **채널 ≥ 64**로 둔다. TAESD처럼 64채널이면 경계선에 있다.
- elementwise(norm, 활성함수)는 대역폭에 묶이므로 fuse한다. `channels_last` fp16을 쓴다.
- 결론: 파라미터가 같으면 깊은 것보다 넓은 것이 T4에서 2배 가까이 빠르다. 카탈로그의 모든 아키텍처는 이 규칙을 따른다.

| 항목 | 상시 (T4-h) | % | Kaggle (T4-h) | 내용 |

## 2. 허용 범위 판정: 교사 특징 위의 헤드, 어댑터, 라벨 계보

### 2.1 판정 기준 (네 가지 테스트)

창업자 제약의 취지는 "**지식의 원천을 빌린 이미지 모델 1개 + 우리 데이터 + 학습 없는 구조로 제한한다**"이다. 여기서 네 가지 테스트를 세운다.

| 테스트 | 질문 | 통과 조건 |
|---|---|---|
| T-출처 | 이 구성요소가 새 지식 원천을 들여오는가? | 빌린 이미지 모델 1개(VAE와 텍스트 인코더 포함), 우리 데이터, 고전 알고리즘에서만 지식이 온다 |
| T-주체 | 학습된 가중치를 누가 만들었는가? | 우리가 from scratch로 학습했다. 단 교사에 붙는 LoRA는 예외 |
| T-규모 | 교사를 바꾸는가? | 교사는 동결한다. 어댑터는 교사 파라미터의 2% 이하(SDXL 기준 약 50M 이하) |
| T-계보 | 라벨이 어디서 왔는가? | 다른 사전학습 모델이 만든 라벨은 쓰지 않는다(엄격 모드) |

### 2.2 판정표

| 항목 | 판정 | 근거 |
|---|---|---|
| **교사 동결 특징 + from-scratch 헤드 (MRH)** | **허용** | 네 테스트를 모두 통과한다. 헤드는 교사가 이미 가진 표상을 읽는 readout이고 새 지식을 넣지 않는다. 선례로 VPD(SD 특징 기반 depth/seg), DIFT, "Beyond Surface Statistics"(SD 내부 활성에서 depth가 선형으로 디코드되고 디노이징 초반에도 나타남)가 있다. Marigold처럼 UNet 전체를 파인튜닝하는 방식은 쓰지 않는다 |
| 교사 LoRA (rank ≤ 64): few-step, fake score, `<plate>` 대체안 | 허용 | "아주 가벼운 어댑터"에 해당한다. SDXL rank 64 LoRA는 약 25–50M |
| G-Adapter (T2I-Adapter식 26M, from scratch) | 허용 | v1의 `ctrl=Gbuffer` 경로를 서드파티 ControlNet 없이 만든다 |
| 교사 텍스트 인코더를 다른 소형 모델의 텍스트 임베더로 사용 | 허용 | 같은 아티팩트다. Path-S, BRP, MoPrior-S의 텍스트 조건에 쓴다 |
| 같은 계열의 few-step distill 체크포인트 | 조건부 허용 | 같은 base 위의 LoRA 형태(Lightning/Hyper류)를 선호한다. 라이선스 확인 필요 |
| 서드파티 ControlNet, IP-Adapter, 파인튜닝 VAE(예: fp16-fix VAE) | **금지 권고** | 다른 사전학습 가중치다. VAE fp16 NaN 문제는 문제 레이어 fp32 upcast나 commit 시 fp32 decode로 푼다 |
| LPIPS(VGG/AlexNet)를 **학습 손실**로 사용 | 금지 | 대체: **TPD (Teacher-Perceptual Distance)** [조합]. 작은 t에서 CRN 노이즈를 공유한 교사 UNet 특징 거리 |
| Blender OIDN 디노이저로 데이터 렌더 | 엄격 모드 금지 | raster 렌더와 교사 운송으로 대체한다(§6) |
| 사전학습 모델이 만든 라벨 데이터셋(DataDoP 궤적은 MonST3R 추출, SpatialVID 주석 등) | 엄격 모드 학습 금지, 평가는 허용 | **라벨 계보 장부**로 거른다(§6.4) |
| GeCo(VGGT+UFM), FID, LPIPS **평가** | 허용(평가 전용) | 단, 평가 모델의 출력은 학습 신호로도 쓰지 않는다(Goodhart 방지) |
| COLMAP/GLOMAP, 평면 스윕 MVS, DIS flow, graph cut, Warp/MuJoCo, xatlas, Infinigen류 절차 생성 | 허용 | 학습 없는 구조다 |
| CC0/CC-BY 3D 에셋, 재질 라이브러리(Poly Haven, ambientCG, MatSynth, GSO) | 허용 | **에셋은 모델이 아니라 데이터다** |

### 2.3 금지 덕분에 오히려 좋아진 점

Depth Anything을 쓸 수 있었다면 교사가 다 그린 **픽셀**에서 기하를 읽었을 것이다. MRH는 교사 **내부**를 읽으므로 노이즈 레벨 t=0.6에서도 교사가 커밋하려는 레이아웃을 읽는다. 외부 depth 모델은 노이즈 latent를 받을 수 없으니 원리적으로 불가능한 일이다. 결과적으로 WSSC가 **픽셀이 존재하기 전에 기하를 융합**할 수 있게 된다(§5 M1, §9).

## 3. 접착제 가설: 왜 수십M으로 충분한가

| 지식 | 누가 이미 갖고 있나 | 비용 |
|---|---|---|
| 사진 같은 외형, 미감, 구도 | 빌린 교사(2.6–6B, 사전 컴퓨트는 남이 냄) | 호출당 1.4 s |
| 빛 수송, 렌즈, 센서 | 렌더러, 광학 수식 | 파라미터 0 |
| 강체·유체·파괴 동역학 | 시뮬레이터(Warp/MuJoCo/MPM) | 파라미터 0 |
| 벽돌, 잎, 자갈, 도시 문법 | 절차 생성 코드(Infinigen류, 자체 ProcGen) | 파라미터 0 (코드 수만 줄) |
| 다시점 일관성 | 세계 W 하나(T1, T2) | 정의상 |

우리 모델이 배워야 하는 것은 이 원천들 사이의 **사상(mapping)**뿐이다.

- **LBO-S:** 부모 대역, 재질, 기하가 주어졌을 때 한 옥타브의 잔차를 낸다. 국소적이고 정상(stationary)이며 파워법칙 스펙트럼을 따른다. 선례로 Real-ESRGAN(16.7M), SwinIR(11.8M), HAT-S(9.6M)가 있다.
- **MRH:** 교사 특징을 기하로 읽는 readout이다. 이해는 2.6B 교사가 이미 했다.
- **BRP:** 64³ 코스 레이아웃 완성이다. 맨해튼 구조라 엔트로피가 낮다. LMSCNet(0.35M) 같은 SSC 선례가 있다.
- **IPM-S:** 이미지에서 절차 파라미터 64차원 이하로 가는 역사상이다.
- **Hand-S:** 생리적 떨림, 보행, 호흡은 저차원 확률과정이다.
- **CRM, Path-S:** 렌더러가 depth, flow, saliency를 **정확히** 주므로 비전 백본이 필요 없다. 이것을 수제 지각(analytic perception)이라 부른다.
- **EPD-S:** 사건 골격(1,024 토큰 이하)만 샘플하고 동역학은 시뮬레이터가 맡는다.

**TinyStories 효과 [부품].** 분포가 좁고 깨끗하면 10–30M 모델도 유창해진다. 인수분해는 각 모델의 분포를 **구성상** 좁게 만든다. 그래서 작은 모델이 통한다는 사실 자체가 v1 테제("Decide before you draw")를 실증하는 증거가 된다.

### M1. MRH: Mind-Reading Heads (독심 헤드) `P1-코어` [조합/신규: 노이즈 t 융합 신호로 사용]

- **역할.** v1에 있던 여러 자리를 하나로 대체한다.
  - v1 의사코드의 `Teacher(...) → (x̂0_v, ĝ_v)` "(+depth/normal head)"
  - Spectral Federalism 표의 "dreamer depth head(L1)", "dreamer normal(L3)"
  - explain-away cascade의 intrinsics
  - DTC의 $\hat p_T$ 추정(디포커스, EV)
  - 소유권 점수의 $\hat\sigma^2_k(i,b)$
  - sem 채널과 Gaffer의 Aes
  - DA3, VGGT, MoGe, SigLIP, DINO를 합친 자리
- **교사 탭 (SDXL급):**

  | 탭 | 형태 | 1×1 proj 출력 |

  | mid | 1280@32² | 256 |

- **아키텍처.**
  - DPT식 fusion neck: 256ch, RCU 12개, 3스케일, FiLM(t). 약 14M
  - 전역 transformer: 16²로 풀링한 토큰 + register 8개, d=384, 4층. 약 7M. 화각, 초점거리, 디포커스 스케일, EV, WB, 수평선을 출력한다
  - 헤드 9개: 합쳐서 약 1–2M

  - log-depth 1 (affine-invariant. metric은 scene graph 스케일로 고정)
  - normal 3, albedo 3, rough/metal 2, shading 1, defocus σ 1
  - sem 768 @128² (교사 텍스트 임베딩 공간, open-vocabulary)
  - σ̂ 대역 4개 (log variance)
  - Aes 스칼라
  - 전역 intrinsics 8
- **학습 데이터.**
  - (a) **교사 운송** 15만: 절차 생성 장면을 렌더하고 교사로 SDEdit한다. GT 기하를 쓰고, 결정 곡선으로 대역 마스크를 건다(§6.2)

  - (c) **W* 자가 라벨** 15만: 솔버가 commit한 세계에서 다시 렌더한 depth/normal. 세계 일관성이 보장된 의사 라벨이다
  - (d) σ̂ 라벨: X1-slim의 seed 간 실측 분산
  - (e) Aes: 자체 사람 쌍대 비교 2–3만. AVA는 연구용 라이선스라 엄격 모드에서 제외한다
- **손실.** scale-shift 불변 log-depth L1 + gradient matching, normal 각도, intrinsic 일관성(albedo × shading ≈ 선형화 이미지), 대역 마스크 손실.

- **비용.**
  - 헤드 순전파 약 0.2 TFLOPs. 교사 NFE(6.6 TFLOPs)의 3%다
  - 학습 30만 샘플 × 0.6 TFLOPs = 1.8×10¹⁷, **2×T4로 2 h**
  - 탭은 기생으로 얻는다. 별도로 수집하면 30만 × 0.8 s(UNet 부분 순전파) = 67 T4-h다

- **게이트 X-S1 (D30).**
  - 운송 holdout에서 depth AbsRel ≤ 0.10 (t ≤ 0.5), ≤ 0.15 (t = 0.7)

### M3. LBO-S: Chart-SR, 세계 공간 디테일 연산자 `P1-코어` [조합]

- **역할.** v1의 LBO(200M)와 WDD(L4 극미세)를 통합한 학생이다. 미세 레벨을 **표면 chart 위의 2D 문제**로 바꾼다. 표면 chart는 UKA texel payload를 연속으로 묶은 것이고, parameterization은 xatlas류 고전 알고리즘으로 bedrock commit 때 만든다. band-iso 뷰가 사실상 chart의 정사영이라서 이미지 SR과 같은 문제가 된다.
- **입력 텐서** X ∈ ℝ^{55×80×80} (자식 해상도 64² + apron 8):

  | 채널 그룹 | 채널 수 | 내용 |
  |---|---|---|
  | 부모 texel 업샘플 | 12 | L_d 3, albedo 3, normal 섭동 3, rough, metal, height |
  | 기하 | 7 | 월드 normal 3, 곡률 2, AO, chart 왜곡 |
  | sem | 8 | 교사 텍스트 공간 PCA |
  | matter | 8 | 재질 클래스 임베딩 |
  | WNF 노이즈 | 8 | 자식 레벨 Philox, nested |

  조건 벡터: Fourier(log₂ h_l) 16, 대역 인덱스, flow 시간 t. FiLM으로 넣는다.
- **출력 텐서** Y ∈ ℝ^{12×64×64}. 잔차(자식 − 부모 업샘플)를 출력하고, **2×2 자식 블록마다 평균 0으로 사영**한다. 이렇게 하면 **효도(filial) 제약이 구성상 정확히 성립**한다(학습 불필요).
- **아키텍처.** 3레벨 U-Net(80²/40²/20², 채널 96/192/384), 각 레벨 res block 2개, 20²에서 windowed attention 2블록. 약 24M, 타일당 순전파 30 GFLOPs. 루프라인 규칙 충족.
- **샘플링.** rectified flow, K=2–3 Euler 스텝. 초기 노이즈는 WNF에서 가져오므로 **결정론적**이다. 수용장이 유계라서 **T8 비트 동일성이 성립**한다. 전제는 결정론 커널(`use_deterministic_algorithms`), 고정 타일 격자(수요 순서와 무관), atomic 없는 reduction이다. 보장 범위는 "같은 엔진 파일 + 같은 GPU 아키텍처"다.
- **데이터 사다리 (총 800만 타일/세대).**
  1. **CC0 PBR 재질** 200만: MatSynth 약 4천 개, ambientCG 약 2천 개, Poly Haven 약 700개, 4K–8K. 옥타브마다 다운샘플 쌍을 만든다(**프랙탈 재사용**: 파워법칙 스펙트럼이라 재질 1개가 모든 레벨의 데이터가 된다). L_d는 우리 렌더러가 무작위 env로 셰이딩해서 만든다
  2. **절차 재질 그래프** 100만: 노드 그래프 파라미터를 무작위화한다. 무제한 생산 가능
  3. **교사 band-iso 타일** 300만: 1.2만 뷰, 약 22 T4-h. intrinsics는 MRH가 단다
  4. **W* chart** 200–500만: expert iteration. 세대마다 가중치를 올린다
- **손실.** rectified-flow MSE + 반경 파워 스펙트럼 손실(fp32 FFT, v1 RE-FT 정신으로 블러 해법을 차단) + 파인튜닝 단계에서만 배치 5%에 TPD.
- **비용.**
  - 학습: 800만 × 90 GFLOPs = 7.2×10¹⁷, **2×T4로 8.3 h/세대**
  - 추론: 방 규모 4K 세계의 최미세 레벨(약 2천만 texel)은 4.9천 타일 × 3스텝 = 4.4×10¹⁴ FLOPs, **약 20 s**(fp16). INT8 TensorRT면 약 10 s. Powers of Ten(1.6억 셀)은 약 3분
- **메모리.** 가중치 48 MB, 배치 64타일 활성 약 3 GB (GPU1).
- **관할 (§9 Federal Devolution).** 처음에는 **L4만** 맡는다(v1의 WDD 자리). 재질 클래스별로 Worldness Gap과 2AFC를 통과하면 L3로 승격한다.

### M4. PWMT: Per-World Micro-Teacher (세계 전속 미니 교사) `P1-코어` [신규]

> 이 제약이 아니었으면 아무도 생각하지 않았을 아이디어다. 컴퓨트가 무한하면 모든 뷰에서 교사를 부르면 된다. T4에서는 교사 호출 1회가 1.4초라서 **세계 하나 안에서도 amortize**해야 한다.

- **메커니즘.** 레벨 l, Jacobi 라운드 r에서 다음을 한다.
  1. 부분집합 $S_r=\{v\in V_l:\mathrm{hash}(\text{seed},l,r,v)<\rho_r\}$를 고른다. 방문 순서가 아니라 순수 함수다.
  2. $S_r$의 뷰에만 교사를 lockstep으로 호출한다.
  3. PWMT(5M, 메타 init)를 $\{(\text{저대역}(v),\ \text{교사의 대역 } b\ \hat x_0(v))\}_{v\in S_r}$로 300스텝 테스트타임 학습(TTT)한다. 데이터 순서는 해시 정렬로 고정하고 커널은 결정론적으로 쓴다.
  4. $v\notin S_r$에는 PWMT가 대역 b 제안을 낸다.
  5. Sync에서 소유권 가중치에 신뢰도 $c_{PWMT}<1$을 곱한다. $c$는 $S_r$을 9:1로 나눈 holdout으로 보정한다.
  6. 라운드가 바뀔 때마다 $S_r$이 바뀐다. **각 블록이 최소 한 라운드에서는 교사 소유 뷰를 갖도록** 커버리지 제약을 건다.
- **비회귀 조항 점검.**
  - $W^{(r+1)}=F(W^{(r)},\text{seed})$인 동기식 Jacobi 사상이다. 방문 순서 간선이 없다(조항 1).
  - PWMT 가중치는 "같은 레벨 전역 통계"다. SMF의 τ 통계 투표와 같은 지위다. 비유하면 **τ가 32차원 벡터에서 5M 차원 가중치가 된 것**이다(조항 2).
  - 영역을 넓히지 않는다(조항 3).
  - **정직한 등급:** 수요가 확장되어 $V_l$이 바뀌면 PWMT도 바뀐다. 그래서 PWMT는 native 비트 동일(T8)이 아니라 **solver 모드 OIE ≤ 0.05 범주**다. 완화책으로 PWMT를 **8 m 슈퍼블록 × 재질 클래스** 단위로 나눠 학습한다. 그러면 수요 확장의 영향이 해당 슈퍼블록에만 국한된다.
- **부수 효과 (미감).** 같은 세계의 같은 벽돌이 어디서나 "같은 벽돌"이 된다(**재질 정체성 일관성**). 반대 위험은 단조로움(모든 벽돌이 똑같아짐)이다. 그래서 WNF 노이즈 입력과 인스턴스 조건을 유지하고, 클래스 내 다양성 지표를 감시한다.
- **비용.**
  - 메타 init: W* 200개 세계에 Reptile, 약 10 T4-h
  - TTT: 300스텝 × 배치 16 × 128² ≈ 2×10¹⁴ FLOPs, GPU1에서 15–30 s. GPU0이 교사를 돌리는 동안 병렬로 끝난다
- **효과 목표.** 교사 호출 비율을 라운드별 0.5 → 0.3 → 0.25로 낮춰 평균 약 0.35. 방 세계당 NFE를 8천에서 약 2.5천으로(LBO-S 웜스타트 포함).
- **게이트 X-S3 (D60).** NFE/세계 ×0.4 이하, DR_rel 증가 ≤ 5%, seam 2AFC 변화 없음, OIE ≤ 0.05.

### M5. BRP: Bedrock Prior (3D 완성 prior) `P1-코어` [조합]

- **역할.** v1 CWM(4–8B)의 역할 중 "**내부와 뒷면 포함, 구멍 없음**"만 맡는다. 보이는 쪽 외형은 bedrock 단계의 WSSC가 맡는다(코스 레벨, 시네마틱 뷰, hero still도 같은 lockstep 실행 안의 뷰 하나다. 캔버스가 아니다). BRP는 관측되지 않은 셀을 채우는 전역 1-pass prior다. 비회귀 조항이 명시한 유일한 예외 범위 안에 있다.
- **입출력.**
  - 입력: 64³ 청크 × 32ch. occ 1, sem 8, 코스 albedo 3, normal 3, emissive 1, matter logits 16. 관측된 셀은 MRH depth를 역투영해서 관측 마스크와 함께 채운다
  - 조건: 교사 텍스트 임베딩(8³ bottleneck에서 cross-attention), 스케일 h_{l_g}
  - 출력: 완성된 64³×32
- **아키텍처.** 3D U-Net(48/96/192/384), 레벨당 res conv 8개, 약 42M. 순전파 0.49 TFLOPs.
- **데이터.**
  - 자체 ProcGen(ProcRoom, ProcStreet, ProcTerrain, ProcProp. CPU에서 샘플당 0.5–2 s) 20만
  - Infinigen 장면 약 3천
  - 실사 lift 300 (DL3DV/ScanNet++를 COLMAP + 3DGS로. 미관측은 마스크)
  - 캡션은 문법 템플릿을 교사 텍스트 인코더로 임베딩한다(**LLM 없음**)
- **비용.** 학습 2.9×10¹⁷ FLOPs. 3D conv는 효율이 낮아 **2×T4로 3.5–7 h**. 추론 16스텝 약 8 TFLOPs로 청크당 약 1 s. 방은 1–4청크, 거리는 64청크(약 1분).
- **왜 42M이면 되나.** 64³ 코스 레이아웃은 엔트로피가 낮다. SSC 문헌의 선례(LMSCNet 0.35M)를 보면 42M도 넉넉하다.

### M0. TAE-T (Tiny Teacher AutoEncoder) `P1-코어` [부품: TAESD 방식을 from scratch로 학습]

- **역할.** 솔버 inner loop의 `Enc(Cam R(W))`와 프리뷰 decode를 대체한다. **full VAE는 commit과 최종 단계에서만** 쓴다.
- **효과.** VAE 왕복 약 1–1.5 s가 20 ms가 된다. 방 세계 하나에서 VAE 오버헤드만 1–2 T4-h를 절감한다.
- **데이터와 손실.** 교사 VAE 쌍을 기생으로 얻는다. 손실은 L1 + TPD + from-scratch 패치 판별기(2M).

### M2. G-Adapter `P1-코어-lite` [조합]

- **역할.** v1의 `ctrl=Gbuffer_v(W)`. 서드파티 ControlNet은 금지이므로 직접 만든다.
- **구조.** T2I-Adapter식으로 **샘플당 1회만 계산**하고 모든 스텝에서 재사용한다. 채널 192/384/768/768에서 1×1 proj로 UNet 폭에 맞춘다. 26M(T2I-Adapter-SDXL 약 77M의 1/3).
- **학습.**
  - 교사는 동결하고 UNet을 통과해 역전파한다. 768², gradient checkpointing으로 약 9 GB
  - 샘플당 약 2.5 s × 10만 = **70 T4-h** (GPU0)
  - 데이터: 교사 자기 샘플에 MRH가 읽은 G-buffer를 단다(**교사가 그리고, 교사의 마음을 읽은 라벨로 다시 교사를 조건화**). 교사 운송 GT 쌍도 쓴다
- **조건부 배치.** X1에서 SDEdit만으로 코스 레벨 레이아웃이 지켜지면(결정 창이 깨끗하면) 생략한다. 그러면 70 T4-h가 솔버로 돌아간다.

### M6. IPM-S (Inverse Procedural Model) `P1-코어` [조합. 선례: MATch, 역절차 재질 모델링]

- **역할.** v1의 SMF 인스턴서 $G_{SM}$를 **학습 파라미터 0개인 절차 인스턴서**(scatter, L-system, 노드 그래프)로 바꾸고, IPM-S가 교사 이미지에서 그 파라미터를 읽는다.
- **출력.**
  - τ_SMF 32차원: 밀도, vMF 방향, log-normal 크기, 색 평균/공분산, 군집도
  - CARRIER: k₁, k₂, 위상 오프셋, profile 코드 16
  - 재질 그래프: 약 150종 중 top-k 선택 + 그래프당 파라미터 24개 이하
- **데이터.** 절차 생성 장면은 파라미터를 알고 있으므로 **라벨이 공짜**다. 교사 운송 샘플의 MRH neck 특징을 그대로 받는다(기생).
- **v1과의 연결.** CI(Cardboard Index) 문제를 구조적으로 푼다. 인스턴스는 결정론 코드가 만들므로 무한 해상도이고, 줌인해도 녹지 않는다.

### M8–M11. DP-0 소형 3종 + 1

- **Hand-S (8M).**
  - 토큰: 20 ms 패치(gyro 3 + accel 3, 4샘플)
  - 조건 토큰: 리그, 오퍼레이터 프로파일 64차원, 의도 속도/가속, 피로, 숨 참기
  - 출력: μ-law 256-bin 이산 혼합. fp16에서 안정적이다
  - 데이터: 자체 캡처 300시간. 폰 4대와 GoPro 2대, 오퍼레이터 6명, 리그 10종. 평행이동 성분은 VIO(고전)로 얻는다. Betaflight blackbox, DJI 로그도 쓴다. 장비비 약 $3–5k이고, 하루 약 7시간 촬영이면 6주
  - **리그 전달함수 증강:** 같은 손을 숄더, 짐벌, 스테디캠 질량 필터에 통과시켜 데이터를 배로 늘린다
  - 게이트: v1 X7c, 카메라 튜링 2AFC ≤ 55%
- **Path-S (19M).**
  - 세계 토큰: 객체 64개 이하. 클래스는 교사 텍스트 임베딩, bbox, saliency
  - 키프레임 토큰 16개 이하: Toric 6, 렌즈, 시간, 리그
  - 데이터: **절차 촬영 문법**(12 의도 × 14 리그 × ProcGen 세계, 삼분할, lead room, 액션 축 규칙. CPU로 무제한) 500만 + CC/퍼블릭 도메인 영화 샷 5–10k를 **자체 GLOMAP으로 추출**. DataDoP는 엄격 모드에서 제외(라벨이 MonST3R 출신)
- **CRM-S (12M).**
  - **수제 지각:** 렌더러가 프레임당 64차원 통계를 10 fps로 정확히 준다. 깊이층별 saliency 가중 시차 히스토그램, reveal/wipe 사건, 프레이밍 격자, 수평 기울기, 모션블러 에너지, jerk PSD, clearance, 노출이다. 비전 백본은 필요 없다
  - **합성 선호 사전학습 [조합]:** 원 경로와 열화 경로(지터 주입, 충돌, 머리 잘림, 수평 기울기, 속도 스파이크, 지루한 정지)의 쌍 200만 개. 원본이 선호된다는 라벨이 공짜다. 그 뒤 사람 쌍으로 Bradley–Terry, 전문가 쌍으로 마진 손실을 건다
  - 비용: 학습 0.5 h. 160×90 프리뷰 렌더 18 T4-h
- **Rig-ID-S (3M).** ShotDNA 리그 역추정을 amortize한다. 데이터는 리그 시뮬, Hand-S 샘플, 추출기 노이즈 $|H|^2$로 만든 합성이고 10분이면 학습된다. 쓰임새는 T4± 경로 이식, Path-S 데이터 정제(의도, 리그, 손 분리).

### M7. Flow-S `P1-확장`

먼저 고전 DIS/LK 피라미드로 Σ_u(dream jitter, 서브픽셀에서 수 px)를 처리한다. 경쟁 영상의 T4± 경로 추출은 GLOMAP과 SIFT로 CPU에서 한다. Flow-S는 Phase 2 실사 lift 트랙에 필요해지면 학습한다(28 h). 데이터는 우리 렌더러의 정확한 flow로 무제한이다.

## 6. 데이터 엔진 "주조소(Foundry)": 진짜 해자

### 6.1 왜 데이터가 해자인가

1. **작은 모델에서는 데이터 분포의 좁음과 품질이 전부다.** 선례로 TinyStories와 phi-1이 있다. 우리 인수분해는 분포를 구성상 좁힌다.
2. **우리 데이터는 컴퓨트로 살 수 없다.** 한 샘플은 (절차 GT 기하) ⊗ (교사 photoreal 외형) ⊗ (교사 내부 특징, 모든 t) ⊗ (대역 유효성 마스크) ⊗ (계보 태그)의 다섯 겹이다. 이것을 만들려면 렌더러, WNF, 결정 곡선 보정, 솔버, 절차 생성기가 모두 있어야 한다. H100을 가진 경쟁자는 웹 비디오로 큰 모델을 학습하지, 이 다섯 겹 데이터는 갖고 있지 않다.
3. **복리로 쌓인다.** 솔버가 W*를 만들면 학생이 좋아진다. 그러면 세계당 NFE가 줄어 하루 세계 수가 늘고, W*가 다시 쌓인다. 플라이휠 속도는 **NFE/세계**로 잰다.
4. **모델은 버려도 데이터는 남는다.** 카탈로그는 4일 만에 다시 학습할 수 있다. 데이터는 Merkle 주소 shard로 영구 누적되고, 계보가 깨끗해 자산으로 팔 수도 있다.

### 6.2 핵심 기법: 교사 운송(Teacher Transport) + 결정 곡선 라벨 마스크 [조합/신규]

```
절차 장면 (GT: depth, normal, albedo, sem, 파라미터) ── raster(EEVEE급) ──> x_proc
   x' = SDEdit_teacher(x_proc, t ∈ [0.3, 0.7], 2 NFE)            # 외형만 photoreal로 운송
   라벨 유효 대역 = { o : D(o, t) ≤ 0.1 }                        # v1 X1 결정 곡선. 저대역 기하는 보존됨
   손실 = Σ_o∈유효 ‖Π_o(pred − GT)‖   (무효 대역은 마스크)
   품질 필터: 현 MRH(x')와 GT의 저대역 불일치 > τ → 폐기
```

- v1의 X1 보정 곡선 $D(o,t)$가 **데이터 엔진의 라벨 유효성 증명서**가 된다. 보정 실험과 데이터 엔진이 같은 측정을 공유한다.
- 슬로건: **"기하는 코드에서, 외형은 교사에서, 라벨은 구성에서."** 경로추적(Cycles) 대신 교사가 사실감을 맡는다. 1024² 경로추적은 T4에서 20–60 s인데 운송은 4.3 s다.

### 6.3 파이프라인과 하루 생산량

```
[Tier-1 CPU 절차 주조]  ProcGen(방/거리/지형/소품) + Infinigen + CC0 재질·에셋
     │ scene program = 라벨 (파라미터, 기하, 재질, SMF τ, CARRIER ψ)
     ▼
[GPU1 raster]  nvdiffrast/3DGUT: G-buffer(depth, normal, albedo, sem, flow, inst) + 1024² 셰이딩
     ▼
[GPU0 Tier-2 교사]  운송(2 NFE) / band-iso 타일(4 NFE) / X1-slim 프로브(1 NFE)
     │ Feature Tap Bus: taps{32²,64²,128²}, x̂0, latent → 링버퍼 → 헤드 온라인 학습 (기생)
     ▼
[GPU0+1 Tier-3 솔버]  WSSC v3 + MRH + TAE-T + PWMT → W* → chart 타일 → LBO-S, BRP, PWMT-meta
[Tier-H 사람]  IMU 캡처, 선호 쌍, 전문가 → Hand-S, CRM-S
[Tier-P 물리]  Warp/MuJoCo → 사건 집합 → EPD-S, F_φ-S (P2)
     ▼
Merkle 주소 WebDataset shard + 라벨 계보 장부
```

| 생산물 | 하루 생산량 | 자원 | 90일 계획 |
|---|---|---|---|
| 교사 운송 샘플 (GT 기하 + photoreal + 탭) | 약 2만 장/T4-day | GPU0 | 15–20만 (MRH, IPM, TAE에 충분. 남는 예산은 Tier-3로) |
| band-iso 교사 타일 뷰 | 약 1.3만 장/T4-day (뷰당 64² 타일 256개) | GPU0 | 1.2만 뷰 = 300만 타일 (22 T4-h) |
| 솔버 세계 W* | GPU당 1.5–6개/day (세대가 오를수록 증가) | GPU0+1 | **약 680개** → chart 타일 약 400만 |
| BRP용 voxel 장면 | 약 100만/day | CPU 16코어 | 20만 사용 |
| raster G-buffer | 10만+/day | GPU1 유휴 2 h | |
| 재질 타일 | 사실상 무제한 | CPU | 200만/세대 |
| 절차 촬영 문법 경로 | 수백만/day | CPU | 500만 |
| 물리 sim (P2) | 약 10¹⁰ env-step/day | GPU1 | 500만 에피소드 |
| IMU | 3–7 h/day | 사람 | 300 h |

- **저장 공간.** 운송 샘플 1개는 약 2–3 MB다(이미지 0.5 MB, 512² 라벨 1.5 MB, 탭 PCA int8은 20% 샘플만). 20만 개면 약 0.5 TB, 전체 1–2 TB다.
- **Kaggle 모드: 생성 즉시 소비.** 저장하지 않고 학습에 바로 흘려보낸다(기생 학습). 저장은 5만 개 이하로 한다.

### 6.4 라벨 계보 장부 (Label Provenance Ledger)

모든 샘플에 다음 태그를 붙인다.

`{GT-proc, GT-sensor, classical(COLMAP/MVS/DIS), teacher-transport(t, 유효 대역), teacher-self(MRH vK), solver-W*(gen k), human(pool), sim}`

- 학습 세트는 태그 필터로 정의한다(엄격 모드, 완화 모드).
- **모든 배치에서 GT-proc와 GT-sensor 비율을 50% 이상**으로 둔다. 자가 라벨의 순환 붕괴를 막기 위해서다.
- ScanNet++ 레이저 스캔은 **평가 전용 홀드아웃**으로 둔다(라이선스도 연구용).

## 7. 2×T4 배치: 메모리 지도와 역할 분담

### 7.1 역할: "꿈꾸는 카드(Dreamer)와 짓는 카드(Builder)" [조합: actor–learner 분리]

| GPU0 "Dreamer" (16 GB) | GB | GPU1 "Builder" (16 GB) | GB |
|---|---|---|---|
| 교사 UNet fp16 (SDXL급) | 5.1 | STRATA 작업 세트 (활성 레벨 chart 2–4, UKA 캐시 0.5–1, BVH 0.5) | 3–5.5 |
| 텍스트 인코더: 프롬프트 임베딩 캐시 후 CPU로 내림 | 0 | 렌더러 (3DGUT raster + OptiX RT. **T4에 RT 코어 40개**) | 1–2 |
| VAE (decoder는 commit 때 fp32 upcast) | 0.3 | LBO-S 추론 (배치 64타일) | 0.5–3 |

## 8. 저예산 학습 레시피

### 8.1 FP16 안정화 (BF16, TF32 없음)

1. 가중치와 Adam 상태는 fp32 master, 연산은 autocast fp16. GradScaler(초기 2¹⁶, growth 2000), inf가 나오면 해당 스텝을 건너뛴다.
2. **u-μP (unit-scaled μP) [부품]을 transformer 기본값으로 쓴다.** 활성이 단위 분산 근처에 머물게 설계되어 있어 fp16 범위(최대 65,504)를 구조적으로 지킨다. μP의 HP 이전도 함께 얻는다.
3. **QK-RMSNorm**으로 attention logit 폭주를 막는다. 분류 logit은 tanh soft-cap 30. Pre-LN에 잔차 스케일 $1/\sqrt{2L}$.
4. norm, softmax, 손실, FFT(스펙트럼 손실)는 fp32로 한다. cuFFT fp16은 2의 거듭제곱 크기 제약도 있다. 결정론이 필요한 FFT는 fp32로 한다.
5. conv 네트: GroupNorm과 RMSNorm은 fp32, BatchNorm은 쓰지 않는다(작은 배치). weight standardization을 선택적으로 쓴다.
6. 100스텝마다 층별 활성 max-abs를 로깅하고, 2×10⁴을 넘으면 경보를 낸다.
7. `allow_fp16_reduced_precision_reduction=False`.
8. 어텐션은 PyTorch SDPA mem-efficient 백엔드(sm75 가능)를 쓴다. FA2는 쓰지 않는다. 시퀀스가 4k 이하라 문제없다.
9. `torch.compile`/Triton의 sm75 지원 범위는 X-S0에서 확인한다(검증 필요). 안 되면 CUDA Graphs와 수작업 fusion을 쓴다.
10. **교사 fp16 점검 (X-S0).** SDXL VAE의 fp16 NaN은 mid-block upcast로 해결한다. bf16으로 학습된 6B DiT는 fp16 overflow 위험이 있으므로 NFE 1만 회에서 NaN 0회여야 채택한다.

### 8.2 μP 프록시와 병렬 실험 공장

- **폭 1/4 프록시.** 파라미터가 1/16이고 FLOPs도 약 1/16이다. 전체 1회 학습 비용으로 32개 설정을 sweep할 수 있다. 깊이는 프록시와 본 모델을 같게 둔다(depth-μP는 선택).
- **CUDA MPS.** T4 1장에 소형 잡 4–8개를 겹쳐 SM 활용도를 올린다(SM 40개). 실험 단위는 2시간 이하의 **멱등 잡**으로 쪼갠다. 잡 = 순수 함수(입력 해시, 설정 해시)이고 출력은 Merkle 주소에 쓴다. SQLite 큐로 관리한다.
- **반복 속도.** 대부분의 모델은 2시간 안에 학습이 끝나므로 하루에 여러 세대를 돌린다. 카탈로그 전면 재학습은 주 1회 가능하다.

### 8.3 체크포인트와 재개 (Kaggle 대비)

- **무상태 샘플러.** 샘플 인덱스 $i=\mathrm{PRP}(\text{seed},\ \text{step}\cdot B+j)$(Feistel 순열)로 정한다. dataloader 상태가 없으므로 어느 스텝에서든 정확히 재개된다.
- **15분 또는 1,000스텝마다 저장.** 모델 fp32, EMA, 옵티마이저, GradScaler, step, RNG 전부(python, numpy, torch CPU/CUDA), 설정 해시, git 커밋을 저장한다. tmp에 쓰고 fsync한 뒤 rename한다(원자적 쓰기). 30–60분마다 외부 저장소(HF Hub 비공개 또는 GCS)로 비동기 업로드한다.
- **Kaggle 세션 설계.** 세션당 9–12시간, 주 30시간이므로 주 3회, 회당 약 10시간이다. 잡은 8시간 이하 단위로 나눈다. 교사 가중치(약 7 GB)는 Kaggle Models나 Dataset에서 로드한다(약 2–3분). 세션은 길게 쓴다.
- **Kaggle 모드에서 남는 것** (780 T4-h): 카탈로그 학습은 전부 들어간다(200 T4-h). 솔버 세계는 약 120개다. Day-90 게이트는 **범주 1–2개에서** 노린다. 정직한 축소다.

| T4 스로틀링으로 처리량 −20–40% | X-S0 지속 클럭 | 버퍼 14%, INT8, 야간 데이터 엔진 |
| 자가 라벨 순환 | 홀드아웃 센서 GT 괴리 | GT 비율 50% 이상 강제, ScanNet++ 평가 고정 |
| MoPrior와 F_φ 데이터 기아 (P2c) | 학습 곡선 | 자체 캡처 투자. 이 부분은 컴퓨트가 아니라 장비 문제다 |
| 저장과 IO 1–2 TB | 디스크 | 생성 즉시 소비, 탭은 20%만 저장 |

## 13. 제약 덕분에 좋아지는 점

- **반복 속도.** 대부분의 모델이 2시간 안에 학습되고, 카탈로그 전면 재학습도 4일이다. 대형 모델 팀이 체크포인트 하나를 기다리는 동안 우리는 세대를 몇 번 돌린다.
- **인수분해가 실증이 된다.** 250M짜리 카탈로그로 이기면 그 자체가 "Decide before you draw"의 증거다.
- **깨끗한 IP.** 학습된 가중치는 전부 우리 데이터와 교사 1개에서 왔다. 라이선스 계보가 한 줄이다.
- **추론이 싸다.** 카탈로그 전체가 0.25B라 INT8이면 소비자 GPU나 WebGPU에서도 돈다. v1의 실시간 뷰어(쇼케이스 #10)가 현실적인 목표가 된다.
- **결정론이 쉬워진다.** 작은 모델과 고정 엔진을 쓰면 비트 동일 보장의 범위가 넓어진다.
- **데이터가 자산이 된다.** 모델은 소모품이고 주조소의 shard는 복리로 쌓인다. 나중에 H100이 생겨도 같은 아키텍처를 μP로 키우기만 하면 된다.
- 마지막으로, T4는 원래 추론 카드다. 우리는 추론 카드로 파운데이션 모델을 만든다. 기생 학습이 그걸 가능하게 한다. 개소리 같지만, 숫자상으로는 된다.
