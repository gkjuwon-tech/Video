# Part A. 실패 지점 7개와 업그레이드

## A1. 디테일 위상을 너무 늦게 고정한다

**실패 시나리오.** 서점 세계를 반경 2m로 오빗합니다. 책등 글자, 화분의 잎, 철망에서 세 가지 문제가 나옵니다.

- (a) 실루엣이 이중으로 겹친 반투명 유령이 생깁니다.
- (b) 카메라가 소유 뷰 경계를 지나면 "여기서부터 다른 화가가 그렸다"는 정적 이음새가 보입니다. 끓지는 않지만 퀼트처럼 읽힙니다.
- (c) 저역 합의 단계에서 뷰마다 다른 노출과 색이 섞여 얼룩이 됩니다.

전문가 평가에서는 "스플랫 냄새"라는 판정이 나옵니다.

**기술적 원인**

1. **제안서 1.4절의 수식이 원인을 이미 말하고 있습니다.** 디테일 위상 φ는 노이즈가 작은 스텝에서 정해집니다. 뷰를 독립적으로 생성하면 φ_v는 뷰마다 따로 샘플링되므로, 융합 시점의 고주파 상관 ρ(ω)는 거의 0입니다. 소유권(2.3)은 평균을 피할 뿐이고, 실제로 하는 일은 "어느 뷰의 위상을 쓸지 고르는 것"입니다. 위상 불일치는 그대로 남아 경계에서 드러납니다.
2. **"고주파 = 텍스처"라는 가정은 평면에서만 성립합니다.** 잎, 털, 철망, 레이스, 군중 실루엣에서는 고주파가 곧 기하(occupancy)입니다. 뷰 A와 뷰 B가 잎 가장자리를 다른 위치에 그리면, 저역 기하 위에 고역을 얹는 분해 `G*·, H*·` 자체가 정의되지 않습니다.
3. **이미지 공간 컷오프는 세계 주파수와 1:1이 아닙니다.** 같은 ω_c가 뷰마다 다른 세계 주파수 `ω_world = ω_c·Z/(f_px·cosθ)`에 대응합니다. 그래서 소유 경계에서 대역 틈(band gap)이나 이중 계수가 생깁니다.
4. **Waechter 2014식 MRF는 측정 노이즈를 가정합니다.** 생성 불일치는 창문 개수나 간판 글자처럼 의미 수준에서 일어나므로, 텍스처 마스킹(seam_cost)으로 숨길 수 있는 범위를 넘습니다.

**업그레이드: 위상 고정 세계 디노이징 (Phase-Locked World Denoising, PLWD).** 위상이 정해지는 스텝에서 모든 시점이 **하나의 세계와 하나의 노이즈**를 공유하게 만듭니다. 제안서의 정리 `B(ω) ≈ A²(1−ρ)`를 진단에만 쓰지 않고 설계 원리로 씁니다. ρ→1을 렌더 단계가 아니라 생성 단계에서 만듭니다.

**(1) Surface Noise Field (SNF): 노이즈에게 주소를 준다**

```
ξ : S → R^C            C = teacher latent 채널 수 (예: 16)
표면 샘플 s: 면적 a_s ≤ (최소 latent footprint)/16
ξ_s = Φ⁻¹( hash(node_id, s_idx, seed, k) ) ~ N(0, I_C)      # 해시로 즉석 생성, 저장 0 B, k = 샘플러 스텝 인덱스

뷰 v, latent 픽셀 j:
  w_{v,j}(s) = a_s · cov_{v,j}(s) · T_{v,j}(s)                # footprint 커버리지 × α 합성 투과율
  ε_v[j]     = Σ_s w_{v,j}(s)·ξ_s / sqrt( Σ_s w_{v,j}(s)² )
```

- 각 `ε_v[j]`는 정확히 N(0, I)입니다. footprint가 겹치지 않는 latent 픽셀끼리는 독립입니다(α 경계는 예외). 두 뷰가 같은 표면을 보면 노이즈 상관은 footprint가 겹치는 비율과 같습니다. teacher가 기대하는 iid 가우시안 가정을 깨지 않으면서 뷰 사이에 무작위성을 공유합니다.
- **스케일 중첩(nested)**: 거친 footprint의 노이즈는 미세 노이즈를 정규화해 더한 것입니다. 그래서 줌인은 "같은 주사위를 더 자세히 읽는 일"이 됩니다.
- 하늘과 무한원은 방향 구(HEALPix) 위에 SNF를 둡니다.

**(2) Lockstep 동기화 디노이징**

```
PLWD(level ℓ):
  입력: 커밋된 W_{<ℓ}, 수요 맵 ℓ*(x) (A5), SNF 시드, 텍스트 y, PIS 위험 맵 (A3)
  V_ℓ ← ViewCover({x: ℓ*(x) ≥ ℓ}, risk)              # greedy set cover. 표면 footprint ≈ h_ℓ가 되도록 뷰 배치
  t_ℓ ← SpectralStart(ω_{ℓ-1}, ω_ℓ)                  # (3)
  ∀v: z_v ← √ᾱ_{t_ℓ}·Enc(Cam_θv(R_v(W))) + √(1−ᾱ_{t_ℓ})·ε_v(ξ)
  for k = 1..K  (distilled 4~8 step teacher):
     ∀v 병렬: ẑ0_v ← D_teacher(z_v, t_k, y ⊕ lensTags(θ_v), ctrl = {depth_v, normal_v}(W))
              Î_v  ← Dec(ẑ0_v)
     W ← WorldFit(W, {Î_v}):
           L_low  = Σ_v ‖G_ωc * (Cam_θv(R_v(W)) − Î_v)‖_ρ                       # 저역은 robust 합의
           L_high = Σ_v Σ_{p∈own(v)} ‖H_ωc * (···)‖₁ · 1[t_k < t_own]            # 소유권을 루프 안의 후반 스텝에서만 적용
           + L_down + L_attr(A3) + L_geo(Î_v에서 추정한 normal/α를 루프 안에서 융합)
     ∀v 병렬: z0_v ← γ_k·Enc(Cam_θv(R_v(W))) + (1−γ_k)·ẑ0_v                     # t_k→0일수록 γ_k→1
              z_v  ← SamplerStep(z_v, z0_v, t_k→t_{k+1}, ε_v(ξ, k))             # 확률 성분도 SNF에서 뽑음
  W_ℓ 커밋 → 이후 모든 프레임은 결정론적 렌더
```

**(3) 스펙트럴 시작점과 Down 제약.** 레벨 ℓ은 레벨 ℓ−1의 렌더를 t_ℓ까지만 노이즈화한 상태에서 출발합니다.

```
SNR_t(ω) = ᾱ_t·P(ω) / (1 − ᾱ_t),   P(ω) ≈ P₀·ω^{-2}  (teacher latent 공간에서 대역별 SDEdit 복원으로 실측 보정)
t_ℓ: SNR_{t_ℓ}(ω_ℓ) = 1   →   SNR(ω_{ℓ-1}) ≈ 4 (보존),  SNR(2ω_ℓ) ≈ 0.25 (재생성)
L_down = Σ_v ‖ G_{ω_{ℓ-1}} * ( R_v(W_ℓ) − R_v(W_{ℓ-1}) ) ‖₁
```

**원안의 디테일 소유권은 버리지 않고 루프 안으로 옮깁니다.** SNF 덕분에 후반 스텝의 뷰 간 차이가 이미 작아져 있으므로, 소유권 경계가 눈에 띄지 않습니다.

**아웃페인팅이 아니라는 정량 논증**

- 생성의 축은 시간이나 경로가 아니라 (스케일 × 노이즈 레벨)입니다.
- **Lockstep**: 같은 레벨의 어떤 타일도 더 완성된 이웃을 조건으로 보지 않습니다. 모든 타일이 k스텝을 마치기 전에는 아무 타일도 k+1스텝으로 넘어가지 않습니다.
- 상태를 갖는 것은 세계뿐입니다. 이미지 캔버스는 매 스텝 세계에서 다시 렌더하는 일회용 관측입니다.
- **순서 불변성 (Order Invariance)**: SNF가 고정되어 있고 조건이 `W_{<ℓ}`뿐이므로, 영역 A와 B를 어떤 순서로 정제해도 결과가 같아야 합니다. 지표는 `OIE = LPIPS(R(W_{A→B}), R(W_{B→A}))`입니다. 순차 아웃페인팅에서는 B가 A의 픽셀을 조건으로 보므로 구조적으로 OIE ≫ 0입니다. 우리 목표는 **OIE ≤ 0.05**입니다. "아웃페인팅이 아니다"를 주장이 아니라 숫자로 보여 줍니다.

**비용 감각.** 레벨당 뷰 400장, 2048² 해상도, 4-step distilled 12B급 teacher를 가정합니다. H100에서 뷰·스텝당 약 1~2초, 스텝당 world fit 200 iteration에 약 20~40초가 걸리면 레벨당 1~2 GPU·시간입니다. 장면당 레벨은 4~6개입니다. 10분 원테이크용 대형 세계는 수십에서 수백 GPU·시간이 듭니다. 쇼케이스용으로는 감당할 수 있고, PLWD 결과물은 그대로 **amortized 세계 생성기(지형도 P1, DMD2 + 이미지 teacher)의 학습 데이터**가 됩니다. 지금은 test-time compute로 품질을 증명하고, 비용은 나중에 상각합니다.

## A2. 탈촬영의 역설: 화가에게서 렌즈를 빼면 미감도 같이 빠진다

**실패 시나리오.** RAW-pinhole LoRA로 그린 원판은 전 구간에 초점이 맞고, 톤이 평평하고, 비네팅이 없습니다. 그 결과 "부동산 광각 사진"처럼 보입니다. Q-Align과 미학 점수가 떨어집니다. 역카메라 후처리로 HDR을 복원하면 8bit sRGB에서 이미 잘린 태양, 전구, 스페큘러의 radiance를 지어내야 하므로, 나중에 물리 플레어와 블룸을 입혀도 값이 틀립니다. 최종 영상은 "광학은 정확한데 사진은 밋밋하다"는 평을 받습니다.

**기술적 원인**

1. **미감 prior가 사진적 렌더링과 얽혀 있습니다.** 얕은 심도는 피사체를 분리하고, 톤 커브와 비네팅은 시선을 유도합니다. teacher의 "미친 미감"의 상당 부분이 렌즈와 현상에서 옵니다. LoRA로 분포를 옮기면 고미감 다양체(manifold)를 벗어납니다.
2. **역문제가 ill-posed입니다.** 클리핑된 하이라이트를 HDR로 복원하는 일이나 디포커스를 제거하는 일은 결국 환각입니다. 뷰마다 다르게 환각하므로 **불일치가 하나 더 생깁니다.**
3. **조명이 시점마다 따로 연출됩니다.** 이미지 모델은 뷰마다 어디서 왔는지 모를 림라이트를 넣습니다. 이를 하나의 세계로 합치면 **조명이 평균되어** 평평해집니다.

**업그레이드: 카메라를 통과하는 증류 (Distill-Through-Camera, DTC), 즉 광학 설명소거(optical explaining-away).** teacher는 맨 세계를 보지 않습니다. 항상 우리 카메라를 통과한 이미지만 봅니다.

```
x = Cam_θ( R(W, c) )
θ = (d_f 포커스 거리, N 조리개, f 초점거리, EV, WB, 톤 커브 T(샷 공유), 비네팅, 플레어(lights()))   # 증류 중에는 그레인 off
∇_W L_DTC = E_{c~p(c|path), θ~p̂_T(θ|c,y), t} [ w_t · ( s_fake(x_t,t,y(θ)) − s_real(x_t,t,y(θ)) ) · ∂x/∂W ]
y(θ) = prompt ⊕ lensTags(θ)       예: "85mm, f/1.4, shallow depth of field, focus on the girl" / "f/11, deep focus"
```

**식별성 논증: 왜 세계가 렌즈 효과를 구울 수 없는가**

| 효과 | θ나 뷰에 따라 변하는가 | 세계에 구우면 생기는 일 | 수렴 결과 |
|---|---|---|---|
| 보케 | d_f와 N 샘플마다 다름 | 같은 배경이 어떤 샘플에서는 초점 대상이 됨 → 구운 블러는 벌점 | **all-in-focus 세계** |
| 플레어와 고스트 | 광원과 광학 중심을 잇는 직선 위에 있어 뷰마다 다름 | 세계에 고정된 플레어는 다른 뷰에서 틀림 | **플레어 문신 제거** |
| 노출 | EV 샘플마다 클리핑 위치가 다름 | 단일 LDR 세계로는 모든 EV를 설명할 수 없음 | **HDR 복원** (HDR-NeRF 원리) |
| 비네팅 | 화면 좌표에 고정 | 세계 좌표로는 설명할 수 없음 | 카메라로 귀속 |
| 톤과 룩 | 샷 단위 공유 파라미터 | — | 세계 밖으로 빠짐 |

- **p̂_T(θ|c,y) 추정**: 프롬프트 계열마다 teacher 샘플 수백 장을 뽑습니다. 디포커스 맵과 단안 깊이로 thin lens를 피팅해 (d_f, N)을 얻고, 휘도 히스토그램으로 EV와 톤 분포를 얻어 혼합 분포로 저장합니다. 여기에 lensTags 조건을 걸어 explaining-away를 더 조입니다.
- **조명의 평균의 저주는 "샷별 조명 치팅"으로 해결합니다.** 실제 영화는 셋업마다 조명을 다시 칩니다. 연속성은 광자 수준이 아니라 이야기 수준에서 지켜집니다.

```
Light_shot = Light_world ⊕ ΔL_shot,    ΔL_shot = { (type, pos, size, radiance, gobo) }_{≤8}   # 저차원, 약 10~50 파라미터
샷 안에서는 고정 (그림자가 미끄러지지 않음). 샷이 바뀌면 바뀔 수 있음.
DTC가 ΔL_shot를 최적화하므로, teacher의 "출처 없는 림라이트" 욕구는 albedo에 구워지지 않고 물리 조명으로 흡수됨.
```

- **렌더 구조**: Tier A는 구운 HDR base radiance `L_base`에 ΔL의 직접광을 더합니다. 직접광은 Gaussian 디퍼드 셰이딩으로 계산하고, 그림자는 3DGRT 광선으로 냅니다. Tier B는 D9(빛만 흐르는 세계)처럼 재조명이 무거운 시퀀스용으로, G-buffer 기반 neural forward renderer(DiffusionRenderer 계열)를 SNF 노이즈로 돌립니다.
- **Teacher 정책**: score는 미분할 수 있어야 하므로 open-weight 모델을 씁니다. 상업용으로는 Apache-2.0 계열(예: Qwen-Image)을 우선하고, FLUX dev 계열은 비상업 라이선스이므로 연구용으로만 씁니다(라이선스 확인 필요). 닫힌 최상위 모델(GPT Image 2, Nano Banana Pro, Seedream 5급)은 **아트 디렉터**로 씁니다. 레퍼런스 스틸, 스타일 참조, Still Parity의 비교 기준이 그 역할입니다.

## A3. PIS가 불일치를 "재질"로 바꾼다

**실패 시나리오.** 멈춘 도서관을 오빗하면 회벽, 종이, 피부 같은 무광 표면의 색이 아주 천천히 변합니다. PIS가 허용한 느린 드리프트입니다. 깜빡임은 보이지 않지만 관객은 "플라스틱 같다", "젖은 것 같다", "새틴 같다"고 말합니다. FPV에서는 기하 불일치를 c(x,ω)로 흡수하려다 반투명 껍질(shell)이 여러 겹 생기고, 시차가 틀린 floater가 됩니다.

**기술적 원인**

1. **Material-from-motion (Doerschner et al., 2011, Current Biology).** 시각계는 운동 단서로 광택과 무광을 구분합니다. 표면에 붙어 움직이는 흐름(texture flow)과 곡률을 따라 미끄러지는 흐름(specular flow)을 구분하는 것입니다. 무광 표면의 시점 의존 색 변화는 specular flow로 읽히고, 재질을 잘못 귀속하게 만듭니다. **PIS가 CSF 아래로 밀어낸 잔차는 깜빡임으로는 안 보여도 재질로는 보입니다.** 재질 지각의 문턱은 CSF가 아닙니다.
2. **CSF는 시선이 고정됐다고 가정합니다.** 관객은 피사체를 추종(pursuit)합니다. 망막 속도는 `v_R = v_T − v_E`이고, Daly의 SPEM 모델로 `v_E = min(0.82·v_T + 0.15°/s, 80°/s)`입니다. 전경 피사체를 추종하며 오빗하면 배경의 망막 속도가 커집니다. 화면 속도로 계산한 f_l은 실제 지각과 어긋납니다.
3. **모든 불일치가 시점 의존 radiance인 것은 아닙니다.** 깊이와 가림 불일치는 c(x,ω)로 표현할 수 없습니다.
4. **"패닝은 공짜"는 노달 헤드에서만 맞습니다.** 플루이드 헤드는 입사동(entrance pupil)보다 약 8~15cm 뒤를 축으로 돌고, 입사동은 포커스와 줌에 따라 움직입니다. 그래서 팬에도 작은 평행이동이 있습니다. 덧붙이면 이 미세 시차 자체가 우리가 시뮬레이션해야 할 리얼리즘 단서입니다.

**업그레이드: PIS 2.0. 숨기지 말고 귀속시키고, 일관성 예산은 시차가 있는 곳에 쓴다**

(a) **귀속 제약 외관 (attribution-constrained appearance).** 헌법 제1조를 시점 의존성에도 적용합니다.

```
c(x,ω) = L_d(x) + Σ_k f_r(x; ρ,m,n)(ω, l_k)·L_k·V_k + ∫ f_r·L_env + r(x,ω)
L_attr = Σ_x ‖r(x,·)‖²_SH / B_mat(x)²  +  λ_sf · L_specflow
  B_mat: matte ≈ 0.5 JND (ΔE_ITP 기준), semi-gloss 1~2 JND, glossy/metal은 물리 lobe 밖 잔차를 1 JND 이하로
  L_specflow: 하이라이트 이동이 곡률에서 예측한 specular flow를 따르도록 강제
```

(b) **PIS 플래너: 잔차를 다듬는 정규화에서 일관성 계산 배분기로 바꿉니다.**

```
Ω_x = ‖v_⊥ + ω × d_pupil‖ / Z                               # 입사동 오프셋 포함
v_R(x,t) = v_screen(x,t) − SPEM(v_screen(target_DP0(t)))       # DP-0의 포커스 타깃을 추종한다고 가정
risk(g) = E_{shots}[ P_detect( Δ_g ; v_R, u_g, mask ) ]       # ColorVideoVDP / FovVideoVDP 엔진을 그대로 빌려 씀
risk가 높은 영역 → PLWD 동기화 뷰를 더 넣음, t_own을 앞당김(γ_k가 더 빨리 1로), DTC 샘플 추가, LOD +1
```

(c) **카메라와 세계의 협상.** risk 맵은 DP-0 경로 탐색의 비용항이 됩니다. 비용이 크면 그 영역을 재생성하라는 트리거가 됩니다. **세계는 카메라에게 어디가 안전한지 알려 주고, 카메라는 세계에게 어디서 정직해야 하는지 알려 줍니다.**

(d) **새 지표 Material Attribution Test (MAT).** 무광으로 라벨된 표면이 오빗 중에도 무광으로 보이는지를 2AFC로 묻습니다. 목표는 ≥ 90%입니다.

## A4. 시간정지 스펙터클이 표현의 최약점과 정면충돌한다

**실패 시나리오.** 런칭 첫 컷인 매트릭스 오마주(D5: 물방울, 폭발, 유리 파편, 파도 튜브)가 회색 반투명 덩어리로 나옵니다. 물방울은 렌즈 역할을 해야 해서 뒤집힌 배경이 비쳐야 하는데 그렇지 않습니다. 유리 파편에는 굴절, Fresnel, 커스틱이 없습니다. 화염구는 주황색 솜사탕 Gaussian이 됩니다. 벤치의 "자해 카테고리"가 하필 우리 간판 데모입니다.

**기술적 원인**

1. **굴절은 SH로 표현할 수 없습니다.** 물방울은 어안렌즈입니다. 외관이 곧 기하를 통과해 굴절된 배경이므로 각주파수가 사실상 무한대입니다. PIS 원안은 이런 표현을 금지합니다.
2. **이미지 teacher에게는 일시적 현상의 3D 위상(topology) prior가 없습니다.** 뷰마다 스플래시 모양을 다르게 그리므로 공통 3D 해가 존재하지 않습니다. 이것은 위상 차이가 아니라 형태 자체의 차이입니다.
3. 반투명 Gaussian만으로 만든 볼륨은 정렬 아티팩트와 popping이 생깁니다.
4. "사진은 원래 멈춘 세계"라는 말은 외관 prior로는 맞고 형태 prior로는 틀립니다.

**업그레이드: Hero FX 프리미티브. 일시적 현상의 형태는 시뮬레이터가, 외관과 연출은 이미지 teacher가 맡는다**

- **Camera Contract를 하이브리드 프리미티브로 확장**합니다. 기본은 GaussSurfel입니다. 여기에 Dielectric(SDF/mesh, IOR, σ_a), Volume(NanoVDB: σ_t, albedo, 흑체 온도 T로 정하는 emission), Curves(머리카락, 불꽃 궤적), Avatar(SMPL-X로 리깅한 Gaussian, 멈춘 사람용)를 더합니다.
- **형태는 시점 t*에 멈춘 물리 시뮬레이션에서 가져옵니다.** 밀크 크라운과 스플래시는 FLIP/SPH(Rayleigh–Plateau 불안정성을 그대로 재현), 파도 튜브는 spectral ocean + breaking-wave FLIP, 유리는 Voronoi/FEM 파쇄, 화염구는 연소 시뮬레이션, 눈·모래·잔해는 MPM으로 만듭니다. 파라미터 ψ는 (충돌 속도, 점성, 표면장력, seed, t*)입니다.
- **Sim-in-the-loop 아트 디렉팅**:

```
ψ₀ ← 아트 디렉터 스틸(닫힌 모델)에서 FX 영역의 실루엣을 검출하고, Dielectric mesh의 미분 가능 실루엣 손실로 초기화
ψ* = argmax_ψ  E_{c,θ}[ −L_DTC( Cam_θ(R(W ⊕ FX(ψ), c)) ) ]      # 시뮬레이터는 미분 불가 → CEM 50~200 샘플
```

- **렌더**: 3DGRT/3DGUT의 2차 광선을 씁니다. 굴절 광선이 Gaussian 세계에 닿으므로 물방울 속 뒤집힌 배경이 모든 시점에서 일관됩니다. 커스틱은 선택적인 photon pass로 처리하고, 볼륨은 Gaussian 가림을 반영한 ray marching으로 그립니다.
- **멈춘 사람**(군무 점프, 관중 5만 명): Avatar 프리미티브와 ArcFace 정체성 고정을 씁니다. 군중은 인스턴싱과 변형으로 만들고, 얼굴은 수요 LOD에 맞춥니다.
- **덤: Phase 2 해동(thaw).** 멈췄던 시뮬레이션을 다시 돌리면 스펙터클이 물리적으로 움직입니다. Phase 1의 간판 에셋이 Phase 2의 첫 동적 에셋이 됩니다.
- **completion이 아닌 이유**: 시뮬레이터는 완전한 3D 형태를 한 번에 냅니다. 캔버스도, 빈 곳도 없습니다.

## A5. 물리 광학이 세계의 빈 곳을 드러내고 렌더 예산을 터뜨린다

**실패 시나리오.** T1.4 랙 포커스에서 전경 보케 가장자리 너머로 전경 뒤쪽 영역이 비칩니다(partial occlusion). 이 영역은 어떤 생성 뷰에도 없었으므로 검은 후광과 오려 붙인 듯한 가장자리가 생깁니다. 휩팬의 모션블러는 frustum 밖을 쓸고 지나가므로 검은 줄무늬가 남습니다. 렌더도 무겁습니다. 50M Gaussian × 4K × K=64 샘플이면 10분짜리 영상은 비용이 폭발합니다.

**기술적 원인.** 2.5절의 수요 D(x)는 핀홀 중심 광선만 셉니다. 실제로 보이는 집합은 조리개(50mm T1.4면 지름 35.7mm)와 셔터 구간이 만드는 광선다발 전체이고, 이는 핀홀로 보이는 집합보다 큽니다. 렌더 비용은 순진하게 K배가 됩니다.

**업그레이드: 광선다발 수요 (Ray-Bundle Demand, RBD). 보케는 비용이 아니라 할인이다**

```
Cov = ∪_t ∪_{ξ∈A} ∪_{τ∈[0,τ_sh]} Vis( ray(s(t+τ), u, ξ) )           # 이 집합은 모두 ≥ ℓ_cov 레벨로 존재해야 함 (완전성 보장)
p_eff(x,t) = max( p_px, c_px(x,t), b_px(x,t) )                      # 픽셀, CoC, 모션 스트릭(Longuet-Higgins 장 × τ)
D_eff(x)   = max_t [ f_px·cosθ / Z · vis · p_px / p_eff(x,t) ]
ℓ*(x)      = ⌈ log₂( D_eff(x) / D₀ ) ⌉ + 1
```

- **숫자 예시 1**: 50mm T1.4, 2m에 초점, 배경 10m이면 CoC ≈ 120px입니다. 배경 수요가 log₂120 ≈ **7옥타브** 줄어듭니다. 7레벨을 생성하지 않아도 됩니다.
- **숫자 예시 2**: 휩팬 스트릭 약 1,500px이면 약 **10옥타브**가 줄어듭니다.
- 랙 포커스에서는 포커스 궤적 전체에 대해 max를 취합니다. 리샷 여유분은 +1옥타브입니다.
- **해석적 블러 렌더러**: Gaussian마다 화면 공간 공분산을 키워 DOF와 모션블러를 한 번의 패스로 근사합니다.

```
Σ'_2D = Σ_2D + (κ·c_px(Z)/2)²·I + (τ²/12)·u̇u̇ᵀ        # 롤링셔터는 3DGUT의 행별 시간으로 처리
α'    = α · sqrt( det Σ_2D / det Σ'_2D )                 # 에너지 보존 (≤1로 clamp)
깊이 불연속 × 블러 크기 > 임계값인 타일(보통 10% 미만)만 MC(K = 16~64)로 처리
검증: 전 구간 MC 대비 ColorVideoVDP ΔJOD < 0.25
```

빌려 쓸 부품은 Cinematic Gaussians(3DGS 위의 DOF/HDR), 3DGUT(왜곡·롤링셔터), Mip-Splatting(footprint 필터)입니다.

## A6. 카메라 지능의 학습 신호가 틀렸다

**실패 시나리오.** ShotDNA의 BIC가 리그를 사실상 무작위로 고르고, 오퍼레이터 떨림 피팅은 SfM 노이즈를 학습합니다. 영화로 모방 학습한 DP-0은 멈춘 세계에서 무난한 push-in과 오빗만 냅니다. H1 블로그는 "VAE 디코더는 latent Nyquist 위도 합성할 수 있다"는 공개 반박을 받습니다. 시네 드론이 가속할 때 화면이 기울면, 촬영감독들이 바로 그 장면을 캡처해 돌려 봅니다.

**기술적 원인**

1. **Nyquist와 SNR.** 24fps의 Nyquist는 12Hz이므로 8~12Hz 떨림은 주기당 샘플이 2~3개뿐입니다. 숄더 리그의 회전 떨림을 0.02° RMS로 잡으면 f_px 5757 기준 약 2px인데, SfM 지터가 0.3~1px이라 SNR은 2~6에 불과합니다. 프롭 진동(100~300Hz)은 완전히 앨리어싱됩니다. 영화는 후반 스태빌라이즈, 줌, 크롭까지 거쳐 PSD가 이미 변형돼 있습니다.
2. **물리 파라미터는 식별할 수 없습니다.** 운동학만으로는 무차원 비율(ω_n, ζ)만 식별되고 질량과 감쇠를 따로 구할 수 없습니다. 짧은 샷에서 14개 클래스를 BIC로 고르는 것은 불안정합니다. 직선 구간만 보면 돌리, 슬라이더, 테크노크레인을 구별할 수 없습니다.
3. **모캡 30명 × 8리그 × 100시간**은 90일 안에 끝낼 수 없고 비쌉니다.
4. **영화의 카메라는 배우가 움직여서 움직입니다.** 멈춘 세계에는 그 동기가 없으므로 분포가 이동합니다. "실제 프레임 vs 무작위 리프레이밍"으로 학습한 구도 비평가는 안무가 아니라 크롭 검출을 배웁니다.
5. **H1의 기전.** 비디오 VAE 디코더는 latent 하나를 채널을 통해 4프레임으로 펼치는 비선형 생성기입니다. 선형 샘플러가 아니므로 latent Nyquist는 하드 리밋이 아닙니다. 게다가 Wan 2.1은 네이티브 16fps입니다. 원인 (a)는 실험으로 확인해야 할 문제입니다.
6. **사실 오류.** 짐벌이 달린 시네 드론의 카메라는 수평을 유지합니다. `tanφ = a/g`는 기체의 기울기이고 화면에 보이는 것은 FPV뿐입니다.

**업그레이드 1: ShotDNA v2, 식별 가능성 분할 (Identifiability Split)**

| 층 | 대역 | 데이터 | 식별 방법 |
|---|---|---|---|
| I (의도) | ≤ 1Hz | 영화와 다큐의 SfM(MegaSaM, VGGT-Ω, DA3), DataDoP 29K | Toric 화면 키프레임 + min-jerk 피팅 |
| R (리그 다양체) | 기하 | 합성 데이터 + IMU 라벨 | **홀로노믹 제약 지문**: 크레인은 위치가 반경 L 구면 위에 있음(구면 피팅 잔차). 돌리는 높이 σ_h < 5mm에 스플라인 경로. 트라이포드는 순수 회전에 입사동 오프셋 호(r ≈ 0.1m). 핸드헬드는 수직 PSD에 보행 피크(1.6~2.2Hz). 스테디캠은 보행 수직 성분이 억제되고 f_gait/2에서 측면 sway. 드론은 yaw 지연과 큰 고도. FPV는 롤과 횡가속이 결합(`tanφ = a_lat/g`). 출력은 클래스와 (ω_n, ζ, 한계)뿐 |
| H (손, 확률 성분) | 0.5~100Hz 이상 | **IMU가 붙은 코퍼스**: GoPro GPMF(gyro/accel 약 200Hz), Sony 카메라 gyro 메타데이터(Catalyst), DJI 텔레메트리(SRT/비행 로그), Betaflight blackbox(1~8kHz), Gyroflow 커뮤니티의 렌즈 프로파일과 로그 | 조건부 생성 모델 `p(ω_res^{200Hz} | rig, ω_n, ζ, 의도 속도 프로파일, profile)`. 소형 DiT 또는 neural SDE |

- **추출기 전달함수 보정**: gyro가 있는 GoPro 영상으로 `PSD_SfM(f) = |H(f)|²·PSD_gyro(f) + N(f)`를 측정합니다. 이를 통해 영화에서 어느 대역을 식별할 수 있는지(`|H|²·PSD > N`인 대역) 알 수 있고, 영화에서 뽑은 스펙트럼과 H1 측정을 보정할 수 있습니다.
- 모캡은 검증용으로만 작게 남깁니다(오퍼레이터 2명 × 리그 4종 × 10시간).

**업그레이드 2: DP-0 v2. 모방은 사전분포, 안무는 탐색, 취향은 세계를 고정한 선호 모델**

탐색: 의도 키프레임 위에서 CEM/MCTS. 루프 안에 Toric 솔버, 1kHz 리그 시뮬레이션, 720p 프리뷰 렌더

  PR(t)      = H( saliency 가중 깊이층별 각속도 분포 )                 # Parallax Richness: 서로 다른 속도로 흐르는 층이 많을수록

## A7. 벤치마크가 이미 끝난 싸움을 다시 이긴다

**실패 시나리오.** 얼음땡 벤치를 내고 강체성 지표에서 압승합니다. 리뷰는 이렇습니다. "GeCo가 이미 했다. WorldScore가 이미 3D 계열은 일관성에서 이기고 주관 품질에서 진다는 걸 보였다. 구조상 이기게 돼 있는 지표를 만들었을 뿐이다." 같은 시기에 Seedance 2.5와 Wan 3.0과의 T1 블라인드 선호에서는 스틸이 덜 예뻐서 집니다. T4 경로 이식은 "비강체 영상에서 뽑은 경로라 편향됐다"는 공격을 받습니다.

**기술적 원인**

1. **GeCo(arXiv 2512.22274)가 핵심과 직접 겹칩니다.** 정적 장면, 카메라 이동, 강체 잔차, spurious object motion을 이미 측정했습니다. MEt3R, ViewBench LCE, SCoPE Revisit, R2M-Bench도 있습니다.
2. **WorldScore의 구조는 두 축의 트레이드오프입니다.** 비어 있는 것은 "주관 품질도 높고 일관성도 높은" 사분면입니다. 강체성만으로는 G1을 증명할 수 없습니다.
3. Arena 평가자는 5~10초 클립을 봅니다. 짧은 클립에서는 상대의 실패가 온건합니다(GeCo 기준 Sora 2 object 0.069).
4. 비강체 영상에 BA를 돌리면 변형이 포즈로 흡수되어 경로가 편향되고, 스케일도 모호합니다.

**업그레이드: 얼음땡 v2, 빈 사분면 프로토콜 (Empty-Quadrant Protocol)**

- **축 1, SP (Still Parity)**: 무작위 시점에서 뽑은 단일 프레임끼리 블라인드로 쌍대 비교합니다. 상대 프레임과 비교하는 SP와 teacher 자신의 스틸과 비교하는 TP(Teacher Parity)를 둡니다. **게이트는 SP ≥ 50%, TP ≥ 45%**입니다.
- **축 2, MI (Motion Integrity)**: GeCo fused error를 코어로 빌려 씁니다(실제 영상 바닥값 0.02). 여기에 spurious motion energy, MEt3R, LCE, SCoPE Revisit, R2M 상대 비교를 더하고, 우리 고유의 광학 포렌식(BVC, DDC, FLT, BLI), MAT, Boiling Spectrum을 붙입니다.
- **주장은 Pareto로 합니다.** x축 SP Elo, y축 −log GeCo 평면에 WorldScore 계열과 비디오 계열을 모두 찍고, **오른쪽 위 사분면의 유일한 점**이 되는 것을 목표로 삼습니다. 최종 심판은 그다음의 VP(Arena식 비디오 선호)입니다.
- **T4± 양방향 경로 이식**
  - (+) 상대의 경로를 같은 첫 프레임에서 만든 우리 세계에 적용합니다.
  - (−) DP-0 경로를 상대의 카메라 제어 기능(Kling 3.0 motion control의 camera path, Veo/Flow의 카메라 제어)에 우리 첫 프레임과 함께 넣습니다.
  - 추출기 편향은 우리 렌더(경로를 알고 있음)에 같은 추출기를 돌려 보정합니다.
  - 상대 영상에는 GeCo 가중 robust BA와 동적 마스크를 쓰고, "전체"와 "고신뢰" 부분집합을 둘 다 보고합니다.
- **프롬프트 앙상블**: (세계, 의도) 쌍마다 세 가지 표현을 씁니다. "static scene, camera moves", "bullet time, frozen moment", "everything perfectly still". 상대에게는 GeCo 기준으로 셋 중 가장 좋은 결과를 줍니다.
- **짧은 클립 스트레스**: T1에는 큰 시차와 고주파 디테일(잎, 텍스트, 군중)을 넣어 10초 안에도 차이가 드러나게 합니다.
- **약관 점검**: 각 상대 서비스 약관에서 출력물 공개와 벤치마킹 조항을 확인하고, 학계 파트너와 진행합니다.

# Part C. 90일 결정적 실험 5개

전제: 인원 7명(세계 3, 카메라 2, 평가 1, 인프라 1), H100 32장.

### E1. 둥둥 뜨는 카메라의 진짜 원인 (H1′ 분해), 1~3주차

- **가설**: 생성 영상의 "handheld" 각속도 PSD는 실제보다 3~12Hz 대역에서 6dB 이상 부족합니다. 원인을 (a) VAE, (b) 조건부 평균, (c) 데이터 필터로 나눠 정량화할 수 있습니다.
- **셋업**
  - GPMF gyro가 있는 GoPro 영상 300개(걷기, 달리기, 핸드헬드)를 GT로 씁니다.
  - MegaSaM과 gyro를 비교해 추출기 전달함수 H(f)와 노이즈 N(f)를 측정합니다.
  - 같은 영상을 공개 비디오 VAE(Wan2.2, HunyuanVideo 1.5)로 encode-decode 왕복시켜 PSD 손실을 잽니다. 이것이 원인 (a)입니다.
  - Seedance 2.5, Wan 3.0, Kling 3.0, Veo 3.1에서 handheld 프롬프트로 각 100개를 생성하고 H(f)로 보정합니다.
  - 돌리와 크레인 프롬프트에는 저크(jerk) 스펙트럼과 오버슛 통계("질량 시그니처")도 측정합니다.
- **성공 기준**: 4개 모델 중 3개 이상에서 3~8Hz 결손이 6dB 이상(95% CI)입니다. VAE 왕복 손실이 3dB 이상이면 원인 (a)를 확인한 것입니다.
- **실패 시 다음 수**: 결손이 없다면 "둥둥 뜨는 느낌"은 저주파(가속 프로파일)에 있다는 뜻입니다. 이 경우 지표를 질량 시그니처로 바꾸고 카메라 스택의 중심을 관성과 오버슛으로 옮깁니다. 어느 쪽이든 블로그는 나갑니다("측정했다").

### E2. 오라클 세계 A/B (T0), 2~6주차

- **가설**: 완벽한 정적 세계가 주어지면, 우리 카메라 스택은 멈춘 세계 카메라 무빙에서 최상위 비디오 모델을 이기고 빈 사분면에 들어갑니다.
- **셋업**
  - 직접 촬영한 장면 20개를 씁니다. 미러리스로 400~800장, HDR 브래킷 촬영 후 3DGUT/Hierarchical 3DGS로 피팅합니다. 여기에 DL3DV 상위 품질 장면 10개를 더합니다.
  - 의도 4종 × 리그 2종이고, 경로는 촬영 커버리지 안에서만 잡습니다.
  - 상대는 우리 첫 프레임 + 텍스트 카메라 지시 + Kling motion-control 경로로 I2V를 만듭니다. 출력은 1080p로 정규화합니다.
  - 평가자는 일반 40명과 전문가 15명, 약 3,000쌍입니다.
- **성공 기준**: VP 일반 ≥ 70%, 전문가 ≥ 75%. 우리 GeCo ≤ 0.03. SP ≥ 50%.
- **실패 시 다음 수**: 완벽한 세계로도 진다면 패인은 카메라와 룩 레이어에 있습니다. 블러, 그레인, 리그, 톤의 ablation 그리드로 원인을 찾습니다. 평가자가 spurious motion을 "생명감"으로 선호한다면, 물질은 멈춘 채 매체만 살아 있게 하는 허용 미세운동(빛의 흐름 D9, 공기 중 입자)을 넣습니다. 그리고 결과 점수를 세계 팀의 목표("오라클 점수의 X% 이내")로 고정합니다.

### E3. PLWD 위상 고정 (핵심 실험), 3~10주차

- **가설**: SNF와 lockstep 동기화를 쓰면 2~4옥타브 대역에서 뷰 간 고주파 위상 상관 ρ가 독립 생성의 0.3 이하에서 0.85 이상으로 올라갑니다. 동시에 융합된 세계가 teacher 단일 뷰 고역 에너지의 80% 이상을 유지합니다.
- **셋업**
  - coarse 기하 15개: 촬영 장면을 레벨 0으로 다운샘플한 것 10개와 생성 파노라마+깊이 세계 5개.
  - teacher는 4~8스텝으로 distill한 open image model에 depth/normal control을 붙입니다.
  - 세 갈래로 비교합니다. (i) 독립 뷰 생성 + robust 3DGS 피팅(CAT3D 류), (ii) (i) + 원안의 디테일 소유권 MRF, (iii) PLWD. 장면당 약 200뷰, 1024~2048 해상도입니다.
- **지표**
  - `ρ_ℓ = corr(B_ℓ(Î_a), B_ℓ(Warp_{b→a}(Î_b)))` (co-visible 영역)
  - `HER_ℓ = E‖B_ℓ(R(W))‖² / E‖B_ℓ(I_teacher)‖²`
  - 오빗 영상의 GeCo, Boiling Spectrum, TP
  - **OIE**: 같은 두 영역을 서로 다른 순서로 정제해 비교
- **성공 기준**: (iii)에서 HER ≥ 0.8, GeCo ≤ 0.03, TP ≥ 40%, OIE ≤ 0.05. (i)은 HER 0.4~0.6 정도로 예상합니다.
- **실패 시 다음 수**
  - 동기화가 결과를 뭉갠다면 소유권(argmax 융합)을 t_mid부터 루프 안에서 적용하고, 후반 γ를 키웁니다.
  - ρ가 오르지 않는다면 latent 노이즈가 디테일 위상을 지배하지 못한다는 뜻입니다. 마지막 스텝을 픽셀 공간 또는 더 미세한 latent를 쓰는 refiner로 바꾸고, 거기에 SNF를 적용합니다.
  - 그래도 안 되면 DTC amortized 경로(세계 생성기 직접 학습)로 시간표를 앞당깁니다.

### E4. DTC 렌즈 설명소거, 4~10주차

- **가설**: 확률적 카메라를 통과시켜 장면별 증류를 하면 보케와 플레어가 구워지지 않은 HDR 세계가 나오고, teacher 수준의 미감도 유지됩니다.
- **셋업**: E3 결과물 또는 촬영 coarse 장면 10개. 세 갈래로 비교합니다. (A) "deep focus, flat" 프롬프트 + 역카메라 후처리(원안 2.2), (B) DTC (θ ~ p̂_T, lensTags 포함), (C) DTC + 샷별 조명 치팅.
- **지표**
  - Baked Bokeh Index: `BBI = mean_x[1 − sharp_pinhole(x) / sharp_ref(x)]`
  - Flare Tattoo Count: 광원 근처가 아닌데 세계 좌표에 고정된 고휘도 할로의 수
  - 복원된 동적 범위(촬영 장면의 브래킷 GT와 비교)
  - Q-Align, TP
  - 키 대 필 비율(조명이 평평해지는지)
- **성공 기준**: BBI ≤ 0.1, 플레어 문신 0개, 동적 범위 ≥ 14 stop(GT 대비 ±1 stop), (B)와 (C)의 TP ≥ 45%, 전문가 선호에서 (C)가 (B)를 60% 이상으로 이김.
- **실패 시 다음 수**: 세계가 보케를 굽는다면 p̂_T가 어긋난 것입니다. 뷰 조건부 θ를 EM으로 다시 추정하고, "초점면 선명도" 제약을 추가합니다. 미감이 떨어진다면 샷 공유 룩 LUT를 카메라 쪽 학습 파라미터로 열어 teacher의 톤 분포에 맞춥니다.

### E5. 카메라 전용 선호 모델과 손 모델, 6~12주차

- **가설**
  - (a) 세계를 고정하면 카메라 선호를 학습할 수 있습니다. 처음 보는 세계에서 CRM의 쌍대 정확도가 70% 이상입니다.
  - (b) CRM으로 탐색한 경로가 모방만 한 경로를 65% 이상으로 이깁니다.
  - (c) IMU로 학습한 손 모델이 카메라 튜링 테스트(2AFC)에서 55% 이하입니다.
- **셋업**
  - 세계 120개 × 경로 40개, 720p 8초 프리뷰로 일반 1.5만 쌍과 전문가 2천 쌍을 모읍니다.
  - 손 모델은 GoPro, Gyroflow, Betaflight 로그 300시간 이상을 200Hz로 학습합니다.
  - 튜링 테스트는 같은 세계에서 네 가지를 비교합니다: held-out 실제 gyro 재생, 모델 샘플, 절차적 Perlin 흔들림, 상대 영상에서 추출한 경로.
- **실패 시 다음 수**: CRM이 일반화하지 못하면 선호가 세계의 의미에 의존한다는 뜻입니다. 세계 토큰 조건을 걸고, 데일리 모드를 능동 학습(active learning)으로 돌립니다. 손 모델이 튜링 테스트에서 떨어지면 gyro는 회전만 담고 있으니 영상 VIO를 융합해 몸통 평행이동 성분을 추가합니다.

## 1. 진단: 왜 AI 비디오에서는 "가짜 냄새"가 나는가

### 1.1 인간의 뇌는 20와트짜리 실시간 bundle adjustment다

Kinetic Depth Effect(Wallach & O'Connell 1953), Rigidity Assumption(Ullman 1979), Motion Parallax(Rogers & Graham 1979)에 따르면 관객은 무의식중에 장면을 "카메라 6DoF 궤적 + 고정된 3D 점"으로 설명하려 합니다. 디퓨전 비디오는 이 최적화의 잔차가 0으로 떨어지지 않습니다. GeCo는 이를 실측했습니다. 정적 장면에서 Sora 2와 Veo 3.1의 fused 오차는 0.07~0.27로, 실제 영상 바닥값 0.02의 3~10배입니다.

### 1.2 귀속 실패 이론 v2

화면의 모든 변화 ΔI는 다음 셋 중 하나로 귀속되어야 합니다.

1. **카메라**: 1/Z로 스케일되는 전역 시차
2. **세계**: 사건, 그리고 *물리적으로 설명되는* 재질의 시점 의존성(specular flow)
3. **매체**: 화면에 고정되고 구조와 무관한 그레인과 노이즈

디퓨전의 끓음은 어디에도 들어가지 않습니다. 시점 의존 잔차가 무광 표면 위에 있으면 "재질" 칸에 잘못 들어가 **재질 오인**을 일으킵니다(Doerschner et al. 2011).

> **헌법 제1조.** 화면의 모든 변화는 카메라, 세계(기하·재질·조명), 매체 중 정확히 하나에 *물리적으로* 귀속되어야 한다.

**예측과 지표**: 그레인은 진폭을 키워도 거슬리지 않지만 끓음은 아주 작아도 거슬립니다(GSC로 측정). 무광 표면의 시점 의존 잔차는 깜빡임 문턱보다 낮아도 재질을 바꿉니다(MAT로 측정).

### 1.4 3대 고질병의 기계론

- **(1) 일관성 붕괴는 상태가 없어서 생깁니다.** 세계가 attention 컨텍스트 안에만 존재하기 때문입니다.
- **(2) 뭉개짐과 끓음은 posterior mean의 결과입니다.** `D* = E[x₀|x_t]`이므로 위상을 식별할 수 없는 단계에서는 진폭이 줄어듭니다. 저노이즈 스텝에서 프레임마다 위상을 따로 뽑으므로 `B(ω) ≈ A(ω)²·(1−ρ(ω))`가 됩니다. 이것이 **H2**(끓음은 공간 주파수에 대해 단조 증가)입니다.
  **v2의 핵심 전환**: 이 식은 렌더 단계뿐 아니라 *생성 단계*에도 적용됩니다. 그래서 ρ→1을 생성 중에 만듭니다(2.3).
- **(3) 이상하게 부드러운 움직임**의 원인 후보는 셋입니다. (a) 비디오 VAE의 시간 압축(디코더는 비선형이라 latent Nyquist가 하드 리밋은 아니므로, VAE 왕복 실험으로 기여도를 측정), (b) 지터의 조건부 평균 회귀("핸드헬드 샷 1000개의 평균은 짐벌 샷이다"), (c) 미적 데이터 필터.
  - **H1′**: 3~12Hz 각속도 PSD 결손이 6dB 이상이고, 원인별 기여도를 분해할 수 있습니다(E1).
  - **H3**: 정지를 요청해도 spurious motion은 0이 되지 않습니다. GeCo의 지구본 사례가 그 근거입니다. 비디오 모델한테 가만히 있으라고 하는 건 생후 3개월 골든리트리버한테 "기다려"를 시키는 것과 같습니다.

### 2.2 DTC: 세계는 렌즈 없이, teacher는 우리 렌즈를 통해 본다

```
x = Cam_θ(R(W, c));   θ ~ p̂_T(θ | c, y);   y(θ) = prompt ⊕ lensTags(θ)
∇_W L_DTC = E[ w_t·(s_fake − s_real)(x_t, t, y(θ)) · ∂x/∂W ]
```

보케, 플레어, 노출, 비네팅, 톤은 θ나 시점에 따라 변하므로 세계에 구울 수 없습니다. 그 결과 세계는 **all-in-focus, 플레어 없는 scene-referred HDR**로 수렴합니다. **룩의 절반은 렌즈와 필름에서 온다**는 말을 이렇게 구현합니다. 세계에는 미술과 조명만 남고, 렌즈와 필름은 카메라가 매 프레임 물리적으로 입힙니다.

**샷별 조명 치팅**은 `Light_shot = Light_world ⊕ ΔL_shot`(조명 최대 8개, 파라미터 약 10~50개)입니다. 샷 안에서는 고정하고, 샷이 바뀌면 바뀔 수 있습니다. 조명의 평균의 저주를 실제 조명부의 관행으로 풉니다.

**Teacher 정책**: score는 상업용 라이선스를 가진 open-weight 모델에서 얻습니다. 닫힌 최상위 모델은 아트 디렉터 역할(레퍼런스 스틸과 SP 비교 기준)을 맡습니다.

### 2.3 PLWD: 위상은 생성되는 순간 세계에 묶는다

알고리즘 전문은 A1에 있습니다. 요약하면 다음과 같습니다.

- **SNF**: 표면 백색잡음을 footprint로 적분해 정규화합니다. 뷰와 스케일이 같은 무작위성을 공유하고, 각 latent 픽셀은 정확히 N(0, I)입니다.
- **Lockstep 동기화**: 매 스텝 모든 뷰의 x̂₀를 카메라를 통과시킨 world fit에 넣고, 세계에서 재렌더해 다음 스텝으로 갑니다. γ_k는 스텝이 진행될수록 1로 갑니다.
- **소유권은 루프 안으로**: 후반 스텝의 고역에서만 적용하고, 저역은 robust 합의로 처리합니다.
- **Spectral start**: `SNR_{t_ℓ}(ω_ℓ) = 1`. Down 제약 `L_down`.
- **얇은 구조**: α와 normal을 루프 안에서 융합합니다.
- **순서 불변성**: 목표 OIE ≤ 0.05. 아웃페인팅과의 정량 경계입니다.
- **로드맵**: PLWD 결과물을 데이터로 삼아 amortized 세계 생성기(DMD2 + 이미지 teacher + 경로 인지 샘플링 + 다중 스케일)를 학습합니다.

### 2.4 PIS 2.0

- **외관 모델**: `c(x,ω) = L_d + Σ_k f_r·L_k·V_k + ∫ f_r·L_env + r`. 잔차 r은 재질별 예산 B_mat 안에서만 허용하고(matte ≈ 0.5 JND), `L_specflow`를 함께 겁니다.
- **플래너**: Ω_x에 입사동 오프셋을 넣고, 망막 속도는 Daly SPEM으로 보정합니다. ColorVideoVDP로 risk를 계산해 PLWD 뷰 수, t_own, LOD, DTC 샘플 수를 배분합니다. risk는 DP-0의 비용항으로도 들어갑니다.
- **원안의 숫자 감각은 그대로 유효합니다.** 반경 2m 오빗은 band 3이 0.12Hz라 안전합니다. FPV가 15m/s로 3m 옆을 스치면 band 3이 2.4Hz라 위험합니다. 다만 v2에서는 이 숫자를 *숨길 대역*을 정하는 데 쓰지 않고, *계산을 투자할 곳*을 정하는 데 씁니다.

### 2.5 세트장 목수 v2: Ray-Bundle Demand

```
Cov = ∪_t ∪_{ξ∈A} ∪_{τ∈[0,τ_sh]} Vis(ray(s(t+τ), u, ξ))       → 이 집합 전체를 ℓ_cov 이상으로 보장 (완전성)
p_eff = max(p_px, c_px, b_px);   D_eff(x) = max_t f_px·cosθ/Z · vis · p_px/p_eff
ℓ*(x) = ⌈log₂(D_eff/D₀)⌉ + 1;    생성 순서: 스케일 우선, 레벨 안에서는 lockstep (PLWD)
```

보케(CoC 120px)는 7옥타브, 휩팬(스트릭 1500px)은 10옥타브를 깎아 줍니다. **보케 한 번이 세계 생성비의 99%를 할인합니다.**

| | 순차 아웃페인팅 (거부) | 세트장 목수 v2 (우리) |
|---|---|---|
| 생성 축 | 시간(프레임) | 스케일 × 노이즈 레벨 |
| 문맥 | 직전 프레임 | 세계 전체의 coarse 레벨 + 같은 레벨의 lockstep 동기화 |
| 노이즈 | 프레임마다 새로 | **세계 표면 위 단일 장 (SNF)** |
| 오류 누적 | 경로 길이에 비례 | 스케일 수(log)에 비례하고 경로 길이와 무관 |
| 순서 의존성 | OIE ≫ 0 | **OIE ≈ 0** |
| 경로 변경 | 재생성 | 여유분 안에서는 재렌더, 넘으면 해당 영역 정제(순서 불변) |

### 2.6 Hero FX

프리미티브는 Dielectric, Volume, Curves, Avatar입니다. 형태는 t*에 멈춘 FLIP/SPH, 파쇄, 연소, MPM 시뮬레이션에서 가져옵니다. ψ는 아트 디렉터 스틸의 실루엣으로 초기화한 뒤 DTC 점수로 CEM 최적화합니다. 렌더는 3DGRT/3DGUT 2차 광선으로 합니다. Phase 2에서는 시뮬레이션을 다시 돌려 해동합니다.

### 2.7 사진은 원래 멈춘 세계다 (정정판)

이미지 모델은 수십억 장의 멈춘 순간으로 학습했으니 **외관** prior로는 우리 홈그라운드가 맞습니다. 하지만 일시적 현상의 **형태** prior는 없습니다. 그래서 형태는 시뮬레이터에서 빌려 옵니다. 그래야 홈그라운드가 완성됩니다.

## 3. 물리 카메라: 카메라에게 질량을 돌려주자

> "카메라는 경로만 지정하면 된다"는 절반만 맞습니다. **경로는 의도이고, 영상미는 물리가 만듭니다.**

### 3.1 상태와 노출 적분

```
s(t) = (p, R, f, d_f, N, θ_sh, fps, sensor, κ_a, 왜곡 k1..k3/p1/p2, t_ro, EI, WB, 입사동 오프셋 d_pupil(f, d_f))
I_n(u) = ∫_{t_n + r(u)·t_ro}^{+τ} ∫_A L(ray(s(t), u, ξ)) w(ξ) dξ dt,    τ = (θ_sh/360°)/fps
```

리그 시뮬레이션은 1kHz로 돌리고 렌더는 서브프레임으로 샘플링합니다. 렌더러는 **해석적 공분산 블러 + 깊이 불연속 타일만 MC**(A5)이고, 롤링셔터는 3DGUT로 처리합니다. 목표 성능은 4K에서 10fps 이상입니다.

모션블러는 Longuet-Higgins & Prazdny 장을 따릅니다. 평행이동 항은 1/Z에 비례하고 회전 항은 깊이와 무관합니다. 휩팬(S35 4K, 35mm, 0.5초에 360°)이면 블러가 약 1,500px로 화면 전체가 줄무늬가 됩니다. 진짜 휩팬과 똑같습니다.

### 3.2 렌즈

- **Thin lens CoC**: `c = A·|S−S_f|/S · f/(S_f−f)`. 50mm T1.4, 2m 초점, 배경 10m이면 0.73mm로 S35 4K에서 약 120px입니다.
- **Thick lens**: Kolb 1995와 특허에 공개된 렌즈 처방, Gyroflow 렌즈 프로파일 DB로 왜곡을 맞춥니다.
- **Focus breathing**: `f_eff = f·(1 + β·m)`
- **아나모픽**: κ_a = 2면 타원 보케, 가로 스트릭, mumps 왜곡
- **비네팅**: cos⁴에 기계적 비네팅을 더해 가장자리 보케가 고양이 눈 모양이 됩니다.
- **색수차(lateral CA)**
- **플레어** (Hullin 2011): 고스트 위치는 `g_k = c + α_k·(l − c)`로, 광학 중심과 광원을 잇는 직선 위에 있습니다.
- **버티고(돌리 줌)**: `f(t) = f₀·Z_s(t)/Z_s(0)`

### 3.3 센서, 색, 노이즈

- **센서 노이즈**: `x = Poisson(a·L·τ·gain)/a + N(0, σ_read²)`
- **파이프라인**: scene-referred → EI → log → LUT 또는 프린트 필름 에뮬레이션(2383 계열) → Rec.709 또는 PQ
- **필름 요소**: 그레인(Newson 2017), 할레이션, 게이트 위브

그레인은 화면에 고정된 iid여야 매체로 귀속됩니다. **좋은 노이즈와 나쁜 노이즈의 차이는 진폭이 아니라 귀속 가능성입니다.** 왕복 테스트에서는 그레인 시드를 포즈에 고정하거나 끕니다.

## 4. AI 촬영감독 DP-0 v2

> 월급 0원, 밥차 안 먹음. 대신 세계를 통째로 미리 답사합니다.

### 4.1 ShotDNA v2: 식별 가능성 분할

| 층 | 대역 | 데이터 | 방법 |
|---|---|---|---|
| I (의도) | ≤ 1Hz | 영화 SfM, DataDoP | Toric 키프레임 + min-jerk |
| R (리그) | 기하 | 합성 + IMU 라벨 | 홀로노믹 지문 → (클래스, ω_n, ζ, 한계) |
| H (손) | 0.5~100Hz 이상 | GoPro GPMF, Sony gyro, DJI 텔레메트리, Betaflight, Gyroflow | 조건부 생성 모델 |

추출기 전달함수 `PSD_SfM = |H|²·PSD_gyro + N`을 측정해 영화에서 식별할 수 있는 대역만 씁니다.

```
ShotDNA {
  meta, rig {class, ω_n, ζ, limits, confidence},
  intent [K × (t, framing{subject, screen_xy, screen_h} | waypoint, easing)],
  hand   {profile_embedding, imu_source?},
  lens   {f(t), focus_target(t), T-stop_est, anamorphic},
  context{장면 점구름, 피사체 트랙, 비트},
  identifiable_band [f_lo, f_hi],  residual
}
```

### 4.2 DP-0 v2: 사전분포 + 탐색 + 비평가

- **입력**: 세계 토큰(씬 그래프, 64³ 점유 격자, 광원, 파노라마 임베딩), 텍스트, z_style, 음악 비트, 편집 문맥(앞 샷의 ShotDNA와 액션 축), PIS 위험 맵
- **Prior**: 키프레임 토큰 위의 DiT입니다. 연속 값은 flow matching, 이산 값은 masked prediction으로 다루고, ShotDNA로 모방 학습합니다.
- **탐색**: CEM/MCTS. 루프 안에 Toric 솔버, 1kHz 리그 시뮬레이션, 720p 프리뷰가 들어갑니다.
- **보상**: `R = CRM + β₁·PR + β₂·Wipe + β₃·RevealBeat + β₄·Clearance − β₅·Risk − ∞·collision`
- **★ CRM**: 세계를 고정하고 경로만 바꾼 쌍으로 학습합니다(Bradley–Terry). 전문가 DPO를 더하고, 데일리 모드의 선택이 곧 능동 학습 데이터가 됩니다.

### 4.3 동기 플래너

```
N(t) = Σ_o sal_o·[d/dt vis_o(t)]₊ + η·Σ_lights 1[역광·플레어 이벤트](t) + ζ·Wipe(t)
R_rhythm = corr(peaks(N), beats) − μ₁·overload(N) − μ₂·boredom(N)
```

멈춘 스펙터클의 정점이 음악의 드롭과 같은 순간에 드러나도록 경로를 짭니다. 이게 핵심입니다.

### 4.4 스타일

z_style ∈ R²⁵⁶은 ShotDNA를 영화 단위나 감독 단위로 모은 통계로 대조학습합니다. 쓰는 통계는 초점거리 분포, 카메라 높이, 리그 구성비, 평면 대칭 점수, 평균 샷 길이, 동기성, **손 임베딩**입니다. 프리셋 이름은 사람 이름 대신 서술형으로 짓습니다(법무팀 눈물 방지).

## 6. 얼음땡 벤치 v2: 빈 사분면 프로토콜

> 세계가 "얼음!"을 외치면 카메라만 움직일 수 있습니다. 그 밖에 뭐라도 움직이면 "땡"입니다. v2에서는 **"예쁘기까지 해야 얼음"**이라는 규칙을 더합니다.

### 6.1 프레이밍

정지 세계는 정답이 정해진 비디오 평가입니다(세계 움직임 = 0). 이 아이디어의 선례는 GeCo입니다. 우리는 GeCo를 **MI(Motion Integrity)의 코어로 빌려 씁니다.** 새로 가져오는 것은 SP×MI Pareto 프레이밍, 양방향 경로 이식, 광학 포렌식, MAT, OIE입니다.

### 6.2 프롬프트 세트

- **세계**: 6개 범주 × 약 40개 = 240개. 실내+텍스트, 건축, 자연, 시간 정지 스펙터클, 재질 스트레스, 스케일 극단.
- **카메라 의도 12종**과 프롬프트 표현 3종으로 약 500쌍을 만듭니다.
- **자해 카테고리**(불, 연기, 커스틱, 털, 반투명체)를 일부러 넣고, 결과를 공개합니다.
- **차트 프롬프트**(Siemens star, ISO 12233)를 넣습니다. 차트가 녹는 장면은 그 자체로 밈이 됩니다.

### 6.3 트랙

| 트랙 | 정의 |
|---|---|
| T0 오라클 | 실제로 촬영한 세계 + 우리 카메라 스택 vs 상대 I2V → 상한선 측정 |
| T1 짧은 T2V | 상대 홈그라운드. 고시차, 고주파 스트레스 |
| T2 같은 첫 프레임 I2V | 출발선을 공정하게 |
| T3 롱폼 | 60초와 180초. 상대는 공식 extend 기능 사용 |
| **T4± 양방향 이식** | (+) 상대 경로 → 우리 세계, (−) DP-0 경로 → 상대 카메라 제어. 추출 편향은 보정하고 신뢰도로 층화 |
| T5 카메라 튜링 | 같은 세계에서 실제 gyro 재생, DP-0, 상대 추출 경로를 2AFC로 비교 |
| T6 스테레오/VR | BLI, presence, SSQ |

**비교 대상**: Seedance 2.5, Wan 3.0, Kling 3.0 Omni, Veo 3.1, Gemini Omni 1.1 Flash, MiniMax H3. 세계 모델 쪽은 Marble 1.1(Studio), Atlas, Lyra 2.0, HY-World 2.1, FlashWorld, Voyager, Gen3C, Genie 3.

### 6.4 지표

```
SP, TP       : 단일 프레임 블라인드 쌍대 비교 (Bradley–Terry, 95% CI)
MI           : GeCo fused (실제 바닥값 0.02), spurious motion energy, MEt3R, SfM 성공률
BS(ℓ,Δ)      : 끓음 스펙트럼 (BA 기하로 만든 강체 워프 후 라플라시안 밴드 잔차)
청크 지문     : 프레임 간 변화량의 주기 4 또는 8 피크
TS, TPR, IDP : 텍스처 미끄러짐, 텍스트 영속성(정규화 편집거리 < 0.1), ArcFace 정체성
LCE/PAL      : 왕복 LPIPS (우리는 그레인과 롤링셔터 off),  REV: SCoPE식 재방문 + R2M 상대 비교
D_PSD        : W₁(log S_ω^gen, log S_ω^real), f ∈ [0.5, 15] Hz,  H(f) 보정 후
Mass signature: 저크 스펙트럼, 정지 오버슛 분포,  FTD: ShotDNA 인코더 임베딩
BVC, DDC, FLT, BLI : 광학 포렌식
MAT          : 무광 라벨 표면이 무광으로 지각되는 비율 (2AFC)
GSC          : corr(고역 시간 잔차, 구조 에너지)
OIE          : 세계 생성기 비교용 순서 불변성
```

## 7. 제품

1. **샷 = 문서**: `world@hash + snf_seed + shotscript + lens + grade`로 완전히 재현할 수 있습니다. diff와 브랜치도 됩니다.
2. **커버리지가 무한이고 한계비용은 렌더뿐**입니다. 보케와 블러는 생성비를 할인해 줍니다.
3. **연속성이 공짜**이고, 조명 치팅은 샷 단위로 관리합니다.
4. **편집실에서 리샷**합니다. 여유분을 넘으면 순서 불변 정제로 처리합니다.
5. **한 세계, 모든 납품 포맷**. 포맷마다 DP-0이 구도를 다시 잡습니다.
6. **VFX용 출력**: 멀티레이어 EXR AOV(깊이, 노멀, 크립토매트)와 실제 카메라 매치무브 합성 → LED 월 없는 버추얼 프로덕션
7. **VR 로케이션 헌팅과 테크 스카우트**. 프리비즈가 곧 최종 픽셀입니다.
8. **세계 단위 과금**: 롱테이크와 커버리지가 많을수록 비디오 모델과의 비용 격차가 벌어집니다.
9. **촬영감독 스타일과 손 라이선스**: VCam 30분, 또는 본인이 찍은 gyro 로그로 DP-0과 손 모델을 적응 학습시키고 로열티를 나눕니다.
10. **새 장르**: 시간 정지 광고, FPV 뮤직비디오, 문화유산, Powers of Ten 교육, 게임 시네마틱.

## 8. Phase 2로 가는 다리

1. **빛만 흐르는 세계 (D9)**: 처음으로 시간축이 생깁니다. 물질은 멈춰 있고 빛만 흐릅니다.
2. **Hero FX 해동**: 멈췄던 시뮬레이션을 다시 돌립니다. 스펙터클이 첫 동적 에셋이 됩니다.
3. **★ Lagrangian SNF**: 노이즈를 공간이 아니라 물질점의 기준 좌표 X에 붙입니다. 변형되는 표면이 자기 노이즈를 들고 움직이므로 Phase 2에서도 끓음이 구조적으로 0입니다. **노이즈는 물질에 붙습니다.**
4. **★ 시간 피사계심도 (Temporal DoF)**:

```
rate(x)  = exp( −(Z(x) − Z_tf)² / (2σ_T²) )
t_eff(x) = t₀ + ∫ rate(x) dt
랙 타임 = Z_tf를 움직이는 것
```

   slit-scan이 화면 좌표를 시간에 대응시켰다면, 우리는 깊이를 시간에 대응시킵니다. 4D 세계를 가진 쪽만 쓸 수 있는 새 영화 문법입니다.
5. **외관과 동역학의 분리 학습**: 외관은 이미지 teacher, 동역학은 비디오 teacher의 저주파 운동 score가 맡습니다. 시간과 카메라는 BulletTime식으로 분리합니다.
6. **DP-0의 추종**: 배우를 따라갈 때 지연 δ와 오버슛을 IMU 손 모델로 냅니다. AI 카메라는 지연 0으로 추적해서 CCTV처럼 보입니다. **그 늦음이 인간성입니다.**
7. **벤치 일반화**: GeCo는 Physics Residual로, 왕복 테스트는 시간 역행 테스트로, 재방문 테스트는 사건 영속성 테스트로 확장합니다.

Phase 2의 목표는 그대로 **모든 비디오 모델을 품질로 이기는 것**입니다.

## 12. 클로징

비디오 모델은 매 프레임 세상을 다시 상상합니다. 우리는 세상을 한 번 기억하고, **그 기억의 주사위까지 세계 표면에 새겨 둡니다.** 그래서 우리 세계는 몇 번을 다시 찍어도 같은 잎맥을 그리고, 어떤 순서로 지어도 같은 집이 됩니다.

비디오 모델의 카메라는 유령입니다. 우리 카메라는 GoPro 수천 시간 분량의 손떨림을 배운 베테랑입니다. 숨을 참을 줄 알고, 10분째에는 살짝 지칩니다. teacher는 우리 렌즈를 통해 세계를 보기 때문에 보케를 세계에 칠할 수 없습니다. 보케는 오히려 생성비의 99%를 깎아 줍니다.

Phase 1의 목표는 멈춘 세계 영상에서 Seedance 2.5, Wan 3.0, Kling 3.0을 **예쁘기로도 이기고(SP), 정직하기로도 이기는 것(MI)**입니다. 둘을 동시에 이긴 시스템은 아직 없습니다. Phase 2의 목표는 그 세계를 녹여서 모든 비디오 모델을 이기는 것입니다.

매트릭스는 카메라 120대로 0.1초를 멈췄습니다. 우리는 노이즈 한 장으로 세계 전체를 멈춥니다.
