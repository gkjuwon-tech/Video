# 창업자 결정 (2026-10-10): T2V 중심에서 I2V 우선으로 — v3의 출발점

이 문서는 v2.1(`docs/PARADIGM-v2.md`) 이후에 나온 창업자 결정과 그 분석이다. v3 명세는 이 결정을 축으로 v2.1 전체를 다시 쓴다.

## 1. 결정 (창업자 원문 요지)

> "T2V 때려치고 I2V만 하자. 그러면 Soul 없이도 Z-Image가 그림 못 그리는 문제가 해결된다. 걔는 품질은 좋은데 기획을 못 한다. 사용자가 이미지를 주면 그 스타일로 이어 그리면 된다. 사용자 이미지가 Soul이든 GPT Image든 실사 사진이든 상관없다. 이건 라이선스도 필요 없다."

- **제품의 입구는 이미지 한 장**(+ 선택 텍스트: 무엇이 더 있는지, 어떤 카메라 무브를 원하는지)이다.
- **T2V 입구의 처리(기본값, 창업자가 뒤집을 수 있음):** 우리는 T2I 경쟁에 참전하지 않는다. 텍스트로 시작하려는 사용자는 아무 이미지 모델로 첫 장을 만들어 넘긴다. 즉 "T2V = 임의의 T2I + 우리 I2V(I2W)". 엔진 교사의 측량 모드 hero 생성은 벤치 기준선·내부 라이브러리용으로만 남길지 v3에서 판정한다. 열린 질문으로 남긴다.
- 목표는 낮추지 않는다. Phase 1(멈춘 세계 + 움직이는 카메라)에서 Seedance·Kling·Veo·Wan을 이기고, Phase 2에서 모든 비디오 모델을 이긴다. 순차 아웃페인팅 금지(비회귀 조항)도 그대로다.
- 하드웨어·모델 제약 그대로: **T4 두 장. 이미지 모델(빌린 교사) 외에는 전부 수십M 파라미터, from scratch.**

## 2. 왜 맞는가 (분석 요약)

### 2.1 미감 부검이 이미 답을 줬다
- A/B 5판, 50축: Soul 41승 / Z-Image 1승 / 무 8. Soul 승리 41개 중 32개(78%)는 물리 축(화면비, 렌즈 원근, 심도, 시간대·광원, 노출, 그레이딩, 필름 질감, 프레이밍). 나머지는 개념 축(미술 생활감, 인물·서사·개념 해석). Z의 1승은 이끼 판의 식물학적 디테일.
- 결론: Z-Image(엔진 교사)는 **손(재질·디테일)은 좋고 기획(개념·연출)은 못 한다.**
- I2V에서는 개념 2축이 **입력 이미지에 이미 들어 있고**, 물리 8축은 **입력 이미지에서 역추정해(InverseLook) 물리 카메라가 재현**한다. Z는 측량(재질·기하)만 한다. 미감 연방제(v2.1 §3.8)가 그대로 성립하되 "Soul 소관"이 "입력 이미지 소관"으로 일반화된다.

### 2.2 기존 부품이 거의 그대로 맞물린다
- v2.1의 S1′ Soul 판독(ExplainAway: 그레인·심도·비네팅·그레이딩 설명 제거 → MRH 판독 → DPS 관측 제약) + InverseLook(θ 역추정) + A+ 경로가 **I2V의 심장**으로 승격된다. 원래 A+ 승인이 필요하던 기능이, 사용자가 자기 이미지를 들고 오면 기본 기능이 된다.
- MRH의 전역 헤드 8개(FOV, 초점, EV, WB, 수평선 등) = InverseLook의 초기값.
- 크기 사전(약 500 클래스) + FOV 헤드 = 입력 이미지의 미터 스케일.
- MassingFM 입력에 원래 "hero lift 부분 점유 32³"이 있다 = 입력 이미지의 부분 3D를 받아 프레임 밖을 잇는다.
- FitLights(H, MRH.shading) = 입력 이미지의 빛을 물리 조명으로 역적합.
- Swatch Bank = 입력 이미지에서 직접 견본을 뜬다(사진 속 원목이 곧 견본).
- 룩 프리셋 라이브러리 → 이미지 한 장 한 장이 자기 룩 프리셋. LookPrior-S(S 승인 대기 후보)는 불필요.
- 히어로 오디션(S1: 64→16→4, 112 TFU, 4.9분) 삭제 → 세계당 교사 호출 약 16%(715 중 112) 절감.

### 2.3 라이선스
- 추론(사용자가 자기 이미지를 넣고 영상을 받는 것)에 우리가 받을 허락은 없다. Higgsfield 약관상 Soul 출력은 사용자 소유, 상업 사용 허용. 이미지를 영상 도구에 넣는 것은 콘텐츠 사용이다(크리에이터 표준 작업 흐름: 이미지 모델 → I2V). 우리는 Higgsfield 약관 당사자도 아니다.
- 남는 규칙 두 개:
  1. **사용자 업로드는 기본적으로 학습에 쓰지 않는다.** 출처 생성기(Soul, GPT Image, 미드저니 등) 약관이 출력으로 모델을 학습·개선하는 것을 막는 경우가 많고, 개인정보 문제도 있다. → **Soul 방화벽을 "사용자 콘텐츠 방화벽"으로 일반화**(계보 태그 `USER`, 기존 CI·카나리아·soul_vault 구조 재사용). 래칫 데이터는 엔진 트랙(우리가 지은 세계)에서만.
  2. 우리 서비스 약관에 "업로드 이미지 권리는 사용자에게 있다" 보증 조항(표준).
- 창업자 본인이 데모용으로 Soul 이미지를 입력으로 쓰는 것 = Plan A(콘텐츠 사용). 허용.
- 주의: "라이선스 0"이 법률 자문은 아니다. v3는 법무 검토 항목으로 남긴다.

### 2.5 전략
- **모델 중립(이미지 모델 전쟁의 스위스):** 어떤 이미지 모델이 이기든 그 출력이 우리 첫 프레임이다. 이미지 모델은 비디오 모델보다 빠르고 싸게 좋아진다 → 우리 품질이 공짜로 오른다.
- **실사 사진 시장:** 사진 한 장으로 그 방을 다시 걷기(추억, 부동산, 여행). v1 데모 "왕복 v0: 실촬영 방"과 같은 방향.
- **선행 지형 주의:** "이미지 → 탐색 가능한 3D 세계" 계열(World Labs 등)과 경쟁 I2V(Kling, Seedance, Veo, Wan, Runway)가 있다. 우리 차별점은 입력 방식이 아니라 품질 기계(대역 소유권, STRATA, 물리 카메라 스택, 8K, DP-0, 왕복 비트 동일)다. v3는 이 지형을 2026-10 기준으로 정확히 적어야 한다.

### 2.6 벤치가 공정해진다
- 같은 이미지 한 장을 Kling·Seedance·Veo·Wan의 I2V와 우리에게 넣는다("시간이 멈춘 세계, 카메라가 돈다"). 첫 프레임 미감은 모두 같다 → 승부는 "그 그림을 얼마나 무너뜨리지 않고 카메라를 움직이느냐"(일관성, 왕복, 숨 안 쉬는 정지, 진짜 손떨림, 한글, 8K).
- v1/v2의 FREEZE-TAG **T2 트랙(같은 첫 프레임)**이 주 무대로 승격된다. Day 90 게이트에 이미 "T2 최강 경쟁 대비 VP ≥70%"가 있다.
- 마케팅: "같은 사진 한 장. 누가 더 오래 버티나."

## 3. 새 보스몹과 공략 (v3가 정식화해야 할 것)

1. **뒤통수 문제(프레임 밖 발명):** 360° 오빗이면 화면의 70–90%가 입력에 없던 곳이다. 공간 기획은 Z가 아니라 MassingFM(부분 lift 조건) + 레이아웃 문법 + 사용자 텍스트가 한다.
   - **촬영 메뉴 등급:** 🟢 안전 무브(푸시인, 슬라이더, 크레인 다운, 랙 포커스, ±20° 오빗: 발명 적음, 최상 품질) / 🟡 확장 무브(90° 오빗, 워크스루) / 🔴 풀 무브(360° 오빗, 뒤돌아보기).
   - **신규 KPI: 발명 비율(Invention Ratio)** = 영상에 노출된 세계 면적 중 입력 이미지가 관측하지 않은 비율. 공개 보고.
2. **그림체 전파:** 빛·렌즈·그레이딩·필름은 물리로 재현(Z는 측량 모드 평광으로 재질만, 입력에서 역적합한 조명으로 재조명 → 프레임 밖도 같은 빛). 재질은 입력에서 뜬 견본으로 TexelFM이 잇는다. 남는 것은 그림체(애니, 유화, 수채).
   - **레벨 1: 사진형 입력**(실사, Soul Cinema, GPT 실사풍) = Phase 1 주 무대.
   - **레벨 2: 그림체 입력** = 참조 조건 교사 필요. FLUX.2 klein 4B(Apache-2.0, 멀티 레퍼런스 편집 내장)가 유력. Z-Image 계열 편집 모델도 공개·라이선스 확인되면 후보. 엔진 교사 결정식에 "참조 조건성"이 새 기준으로 들어간다.
3. **에셔 문제:** AI 이미지는 원근·구조가 3D로 성립하지 않는 경우가 있다(소실점 불일치, 이어지지 않는 계단, 층마다 다른 창 크기). 공략: 가장 가까운 일관된 3D로 **기하 화해**, 첫 프레임 오차를 측정·보고. **신규 지표: 에셔 점수**(입력의 3D 비성립 정도). 높으면 안전 무브를 추천. 덤 쇼케이스: "AI 이미지 원근 거짓말 탐지기".
4. **거짓말 조명:** AI 이미지의 물리적으로 불가능한 빛. 공략: 영화 조명도 원래 거짓말(동기 없는 키커, 반사판, 플래그). Gaffer에 **치트 라이트** 허용: 렌더는 물리적으로 정확, 배치는 예술적 거짓말.
5. **첫 프레임 충실도:** 사용자는 자기 그림 그대로 시작하길 원한다. 입력 시점에서는 입력 이미지가 레이아웃·외관 대역을 소유(프레임 안은 히어로 소유). **신규 KPI: 첫 프레임 지각 거리**(렌더 대 입력). 입력이 2K면 그 Nyquist 위는 TexelFM이 채운다(v2.1 Soul 2K 상한 설계의 일반화). Read-Only Camera 원칙은 유지(첫 프레임을 입력 이미지로 바꿔치기하거나 크로스페이드하지 않는다).
6. **얼굴:** 멈춘 세계에서 사람 주위 오빗은 가장 어려운 범주. 초기에는 얼굴 근처에서 DP-0가 각도를 제한(±30°), 얼굴이 작거나 뒷모습인 장면부터. 본격 얼굴 오빗은 Phase 2c 캐릭터 시즌.
