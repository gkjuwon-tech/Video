# 창업자 결정과 미감 A/B 결과 (렌즈 작업 이후)

## ★ 렌즈들이 작업한 뒤에 나온 창업자 결정: 닫힌 미감 교사 하이브리드 (반드시 통합하라)
- 창업자 판단: Z-Image의 이미지 품질은 나쁘지 않지만 **미감이 약하다.** 창업자가 보기에 현존 최고 미감은 **Higgsfield Soul 2.0 / Soul Cinema**(닫힌 모델)다. 창업자는 Higgsfield 구독자이고, 웹 무료 생성 약 2,900회와 크레딧을 합쳐 약 4,500회를 쓸 수 있다고 추산한다. Higgsfield MCP로 하이브리드에 넣고 싶어 한다.
- 웹 검색으로 확인된 사실(2026-10):
  - Soul 2.0: Higgsfield 자체 파운데이션 이미지 모델. 패션·에디토리얼 지향. 프리셋, 무드보드, 레퍼런스 이미지 모드, Soul ID(캐릭터 일관성), Soul HEX(색 팔레트). 품질 옵션 1.5k / 2k. 이미지는 전 플랜 2K 상한.
  - Soul Cinema: 클로즈업, 분위기, 질감 중심의 시네마틱 모델. 미감이 모델에 내장(프리셋 없음). Soul HEX, Soul ID 지원. **레퍼런스 이미지를 넣으면 프롬프트 입력이 비활성화된다.** 배치 최대 4장. MCP 지원 여부는 미확인(MCP 안내 페이지에 Soul V2만 언급).
  - 공식 MCP: https://mcp.higgsfield.ai/mcp, OAuth. Claude Code: `claude mcp add --transport http --scope user higgsfield https://mcp.higgsfield.ai/mcp`. **MCP 생성은 항상 크레딧을 쓴다. Unlimited와 무료 생성은 higgsfield.ai 웹에서만 적용된다(공식 도움말).** 3rd-party 추정: Soul V2 MCP 생성 1회 약 10 크레딧, $1 ≈ 16 크레딧(미검증).
  - **약관: "You may not use the Service or outputs to train, fine-tune, or improve any AI or machine-learning model, whether or not it competes with Higgsfield."** 예외는 Higgsfield의 서면 승인. 출력의 소유권은 사용자에게 있고 상업적 사용은 제한되지 않는다. Higgsfield는 사용자가 올린 콘텐츠(레퍼런스 이미지 포함)로 자기 모델을 학습할 수 있다(Enterprise 제외).
- 통합 지침:
  1. Soul은 **"미감 교사 = 아트 디렉터 + 최종 광택"** 역할로 넣는다. 구조·노이즈·프로브·학습 데이터용 엔진 심판은 오픈 웨이트 교사가 계속 맡는다(노이즈 통제, 중간층 프로브, 래칫 학습이 필요하므로). 오픈 교사 후보 재검토도 허용(미감보다 통제성·속도·라이선스 기준).
  2. **Soul 방화벽:** Soul 픽셀은 세계 W(콘텐츠)와 최종 렌더로만 흐르고, 어떤 데이터셋·손실·보상·보정·체크포인트로도 흐르지 않는다. STRATA의 provenance(`own`) 필드와 Merkle 태그로 Soul이 저술한 셀을 표시해 Texel Bank·BO 학습·래칫에서 자동 제외. 세계 피팅(장면 표현 최적화)이 약관상 "모델 학습"에 해당하는지는 회색지대로 명시하고 Higgsfield 서면 승인 요청을 권고.
  3. **예산:** 웹 무료/Unlimited 생성은 사람(창업자)이 웹에서 직접 뽑는 경로(히어로 스틸, 룩 레퍼런스)에만 쓰고, MCP 자동 호출은 크레딧 예산으로 따로 잡는다. 웹 앱 자동화로 무료 생성을 우회하는 방식은 쓰지 않는다. 데모·벤치·평가별 Soul 호출 배분표를 만들어라.
  4. Soul의 실제 역할 후보를 구체화: (a) 히어로 스틸을 세계의 관측 제약으로(캔버스 아님), (b) 룩 추출(팔레트·조명·그레이딩 → Gaffer, 렌즈·필름 스택, Soul HEX), (c) DP-0 경로 위 히어로 프레임의 최종 미감 대역 소유자(구조 보존 편집이 되는지 실험으로 확인; 레퍼런스 모드의 한계 고려), (d) 평가 앵커(우리 프레임 vs Soul 스틸 블라인드 비교, TP). 각 역할의 호출 수와 약관 적합성.
  5. 이 결정 때문에 바뀌는 비회귀 조항 점검, 리스크(약관 변경, 모델 버전 변경, 크레딧 소진, 2K 상한, 미감 불일치), 그리고 창업자가 결정할 질문을 추가하라.
- 추가 증거(창업자 A/B, 같은 프롬프트 "astronaut riding a horse"류): Soul Cinema 결과는 약 2.35:1 시네마스코프, 망원 압축과 얕은 심도(배경 사구가 녹음), 해 질 녘 낮은 태양·역광/림, 로우키 노출(피사체 살짝 언더, 하늘 보존), 제한된 팔레트(라벤더 회색 + 흙색)와 필름 같은 톤, 미디엄샷·말 머리 크롭·정면 응시, 낡고 먼지 묻은 우주복, 바이저 너머 수염 난 얼굴(서사). Z-Image 결과는 1:1, 한낮 플랫 조명, 하이키, 팬포커스, 고채도, 전신 측면 카탈로그 구도, 새 제품 같은 우주복, 불투명 바이저(얼굴 없음) — "스톡 사진" 룩. 창업자 결정: **Soul은 절대 버리지 않는다(핵심 자산). Higgsfield에 서면 승인/파트너십 메일을 보낼 예정.**
- 이 증거에서 나오는 설계 원칙 "미감 연방제": 위 10개 미감 축 중 약 8개(화면비, 렌즈 원근, 심도, 시간대·광원 방향, 노출, 그레이딩, 필름 질감, 프레이밍)는 우리 물리 카메라·조명(Gaffer, 태양 고도)·센서/필름·DP-0가 소유하고, 나머지(미술/의상의 생활감, 인물·서사)는 Soul(히어로 스틸, Soul ID)이 소유한다. 오픈 엔진 교사는 물리 조명 아래 정면 차트 뷰의 재질·표면만 판정하므로 "스톡 조명 룩"이 세계로 덜 새어 들어온다(이 가설을 실험으로 검증).
- 실험 "미감 부검(Look Autopsy)"을 90일 계획 초반에 넣어라: Soul 스틸의 카메라·조명·그레이딩 파라미터를 사람이 측정/매칭(약관상 안전한 수동 경로) → (i) 오픈 교사 텍스처 세계 + Soul 매칭 카메라/조명/그레이딩, (ii) Soul 히어로 스틸을 관측 제약으로 쓴 세계, (iii) Soul 원본을 블라인드 2AFC → 미감 격차 중 카메라·조명 몫과 콘텐츠 몫을 정량화. 보조: 오픈 교사에 시네마토그래피 프롬프트를 줬을 때 격차가 얼마나 줄어드는지.
- 추가 A/B 결과(간단 프롬프트 "a traditional Korean house courtyard", "an old fisherman mending a net"): Soul Cinema가 다시 압승했다. 창업자 최종 결정: **Higgsfield에 메일을 보내 허락을 받고 Soul Cinema를 반드시 쓴다.** 누적 3개 프롬프트 × 10축 = 30축 중 Soul 27승, 0패, 3무(화면비·심도). Soul 승리 27개 중 21개(약 78%)가 우리 카메라·조명·그레이딩·DP-0 스택 소관이고, 6개가 콘텐츠(미술 생활감, 인물·서사) 소관이다(축 분류는 주관적, n=3).
- 이 결과에서 나온 설계 반영 사항:
  (1) **역할 분담 반전:** Z-Image(오픈 엔진 교사)의 "지루한" 디폴트(한낮 플랫광, 팬포커스, 정면, 빈 공간, 가림 없음)는 최종 룩으로는 약하지만 3D 세계의 재질·기하 원천으로는 이상적이다(측량 기사 역할). Soul 스틸은 그림자·심도·그레인·전경 가림이 구워져 있어 세계 재료로는 다루기 어렵고 최종 룩 기준으로 이상적이다(촬영감독·미술감독 역할).
  (2) **Soul 카메라 역추정 = 룩 프리셋:** Soul 히어로 스틸을 관측 제약으로 쓸 때 그레인·심도·그레이딩·비네팅은 우리 카메라 θ로 설명해 세계 밖으로 빼고(DTC/렌즈 식별성 원리), 추정한 θ_soul을 룩 프리셋으로 저장해 모든 각도에서 재사용한다. 수동 측정은 약관상 안전, 자동 피팅은 회색지대(메일 요청 범위에 포함).
  (3) **DP-0 구도 취향:** Soul의 프레임 안의 프레임, 전경 레이어링(처마, 흐린 기둥), 타이트 크롭은 v1의 Wipe·Parallax Richness 보상과 일치한다. DP-0 보상에 "전경 레이어링"을 명시적으로 강화하라. 프레이밍(축 8)은 물리 소관이지만 공짜가 아니라 취향이 필요한 영역이며, Soul 출력으로 DP-0/CRM을 학습하는 것은 방화벽 밖(서면 승인 시 최우선 해금 대상).
  (4) **텍스트:** Z-Image는 현판·주련에 해독 불가 가짜 한자를 그렸고 Soul은 글자를 피했다. 글자는 SYMBOL 구조가 소유한다는 원칙을 재확인.
  (5) 메일 요청을 3단계로: Plan A(승인 없이: 콘텐츠·수동 룩), A+(세계 피팅 승인), S(소형 모델 학습 승인: DP-0 구도, CRM). Soul Cinema의 MCP 제공 여부 문의 포함.
- 4번째 A/B("a mossy forest floor"): Z-Image는 선명한 매크로 자연 사진(얕은 심도, 보케, 솔잎·고사리·조약돌까지 식물학적으로 정확하고 풍부) — 처음으로 Z-Image가 "미술/콘텐츠 정확도" 축에서 승리. Soul Cinema는 거의 단색 올리브 톤, 로우키, 이끼 솜털에만 걸리는 역광, 화면 가장자리의 빈티지 렌즈풍 번짐/방사형 블러(달리 인 같은 움직임의 흔적), 그레인·비네팅, 지평선 없는 극접사로 이끼가 산맥처럼 보이는 스케일 착각 — 창업자 평: "영화라고 해도 믿겠다". 누적 40축: Soul 34승 / Z 1승 / 5무, Soul 승리 중 물리 소관 27개(약 79%).
- 추가 설계 반영: (6) **"영화 같음"의 상당 부분은 스틸 속 '시간의 흔적'(카메라 이동 모션블러)과 렌즈 성격(빈티지 수차)** — 우리 셔터 적분과 렌즈 처방전 스택이 물리적으로 매 프레임 생성한다. 렌즈 라이브러리에 빈티지 렌즈(필드 커버처, 스월, 주변부 번짐) 처방을 넣어라. (7) 역광에 빛나는 솜털 = STRAND/SGGX 미세구조 + Gaffer 림 라이트. (8) DP-0 연출 옵션에 "스케일 착각(역-미니어처: 작은 것을 거대한 풍경처럼)" — 극접사 + 지평선 제거 + 얕은 심도. (9) **미감 부검(Look Autopsy) 첫 대상은 이 이끼 페어**: 콘텐츠가 가장 단순해서 카메라 몫을 가장 깨끗하게 분리할 수 있고, Z-Image 이끼 재질(정확한 식물 디테일) + Soul 룩 프리셋 합체가 Soul 원본을 넘을 수 있는지 시험(가난선 아래 BO-40 영역이기도 함).
- 5번째 A/B(야크): 가장 극단적인 격차. Soul Cinema는 프롬프트를 **해석**했다 — 거대한 신수(神獸) 스케일의 흰 야크가 작은 두 사람에게 고개를 숙이고, 양옆의 보통 크기 야크 무리가 스케일 기준점이 되며, 거대한 뿔이 하늘을 원형 액자(후광)처럼 감싸고, 털 가장자리에 역광 림/글로우, 완벽한 좌우 대칭과 V자 계곡 소실선, 깊은 편광 느낌의 파란 하늘, 대기 원근(먼 설산의 헤이즈). Z-Image는 프롬프트를 **기록**했다 — 보통 크기의 털북숭이 흰 야크 정면 증명사진, 화면 안 태양과 플레어로 흐린 노출, 줄 선 관광객, 오른쪽 마을 건물: 여행사 포스터 룩.
- 이 결과의 함의(정직): 축 개수로는 Soul 7승(물리 5, 콘텐츠 2) / 3무라 누적 50축 Soul 41승·Z 1승·8무, 물리 소관 약 78%로 유지되지만, **영향력 기준으로는 이번 격차의 대부분이 '개념 해석'(스케일 전환, 신화적 서사, 상호작용)이라는 콘텐츠 축**이다. 즉 축을 동일 가중으로 세는 방법에는 맹점이 있다. 프롬프트는 '기록형'(이끼, 어부, 한옥: 격차가 주로 카메라·조명)과 '해석형'(야크, 우주인: 격차가 주로 개념)으로 나뉜다. 결론: Soul의 가치는 둘 — (a) 물리로 복제 가능한 촬영 취향, (b) 물리로 대체 불가능한 **개념 아트 디렉션**. (b)가 Soul을 버릴 수 없는 진짜 이유다.
- 설계 반영: (10) 미감 부검을 3분해로 확장 — 카메라·조명 몫 / 연출(구도·스케일 배치) 몫 / 개념 몫. 가중치 없는 축 세기 대신 "카메라만 바꿨을 때 격차가 얼마나 닫히나"를 블라인드로 직접 측정. (11) Soul 히어로 스틸 = 세계의 **개념 아트**: 스틸을 오픈 교사에 약한 노이즈로 통과시켜 독심술사(교사 특징 헤드)가 깊이·재질을 읽게 하면 Soul 내부 접근 없이 기반암을 얻을 수 있다(추론 경로, 학습 아님 — 단 세계 피팅은 회색지대이므로 승인 범위 확인). 뒷면 등 미관측부는 BRP/오픈 교사가 Soul 개념과 일관되게 채운다.
