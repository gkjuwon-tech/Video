## 0. 결론 요약과 판결 제안

### 0.1 열 줄 요약

1. **I2V에서 교사가 하는 일이 바뀐다.** 순수 노이즈에서 그리는 일(hero search 112 TFU)이 사라진다. 남는 것은 입력 판독, 프레임 밖 발명, 입력 Nyquist 위 대역, 판정이다. 그래서 엔진 교사 선정식에 **참조 조건성**, **입력 스타일 SDEdit 충실도**, **첫 시점 재구성**, **새 시점 충실도(NVF)**가 들어간다(CT-M1).
2. **엔진 교사는 Z-Image-Turbo를 유지한다(현직).** 레벨 1(사진형 입력)이 Phase 1 주 무대이고, 재질·측량·판독에서 Z가 앞선다. FLUX.2 klein 4B는 **레벨 2(그림체) 참조 교사 후보이자 엔진 도전자**다. 결과는 4갈래(O1–O4)로 미리 정한다.
3. **파라미터 0 참조 경로 Reference Ring을 먼저 시험한다.** 입력에서 뜬 견본을 뷰 가장자리 띠에 넣고 마스크 디노이즈로 고정한다. 교사 하나로 레벨 2까지 덮을 수 있으면 두 번째 교사가 필요 없다.
4. **두 교사 병용은 카드별 배치(Mode A2)로 한다.** GPU0 = Z INT8, GPU1 = klein INT8. 장당 10–13.5 GB로 들어간다. 한 장에 둘을 올리면 14.8 GB라 여유가 없다. 호스트 pinned는 27 → 39 GB다. Kaggle은 교사 하나만 쓴다.
5. **Teacher Ceiling Test v3는 NVF 시험이다.** 같은 입력, 같은 포즈에서 교사의 새 시점 한 장과 경쟁 I2V 프레임을 붙인다. 포즈는 경쟁 영상을 고전 SfM으로 입력에 등록해 맞춘다. 판정선은 v2.1 CT2와 같은 60/55%다.
6. **카탈로그는 거의 그대로 맞물린다.** MRH가 I2V의 심장으로 승격한다(24 → 26M: InverseLook 전역 헤드, 관측 대역 헤드). MassingFM은 부분 lift 조건이 주 모드가 된다(24 → 28M). BRP는 코어로 승격한다. LookPrior-S는 삭제한다.
7. **신규 소형 모델은 0개다.** 에셔 점수는 화해 피팅의 잔차다(파라미터 0). ExplainAway는 고전 추정기 + MRH 헤드다. Ref-Adapter(25M)는 O4 경로에서만 조건부로 연다.
8. **합계(§5.6 형식).** P1 219.5M, 1세대 247–355 T4-h. P2 2a–2b 289–356 T4-h. 전체 약 386M, P1 + P2 2a–2b 536–711 T4-h(v2.1 대비 +24–35).
9. **데이터 주조소는 "우리 세계의 한 장"을 I2V 학습쌍으로 쓴다.** 엔진 트랙 세계에서 시점 하나를 렌더하면 입력과 정답 세계가 동시에 나온다. 열화·AI 아티팩트, 에셔 왜곡, 그림체 운송으로 입력 분포를 덮는다. 장부는 295–330 → **344–395 T4-h**(코어)다. 레벨 2 조건부는 +22다.
10. **사용자 업로드는 학습에 쓰지 않는다.** Soul 방화벽을 **사용자 콘텐츠 방화벽(USER)**으로 일반화한다. 세계 W 피팅은 추론이고 허용한다. 모델 가중치 갱신(LoRA, TTT, 헤드)은 USER 입력에 대해 금지한다(가중치 불변 원칙).

- klein 참조 fwd 계산: 1024² 4,096 + 텍스트 약 256 토큰에 512² 참조 2장(1,024 × 2)을 더하면 6,400 토큰이다. 선형 몫 2PN = 2 × 4×10⁹ × 6,400 = 5.1×10¹³, 어텐션 몫 약 0.5×10¹³ × (6,400/4,352)² = 1.1×10¹³. 합 6.2×10¹³ ≈ **1.0 TFU**. 참조를 넣은 klein은 Z 단독과 값이 같다.
- **klein의 약점 하나.** 4-step 증류라 신뢰 σ 점이 4개다. v2.1의 Turbo 8점보다 SDEdit 창이 거칠다. 결정 곡선(X1-slim-I)에서 한 옥타브 분리가 안 되면 SR-LoRA(klein판) 또는 klein Base 판정 병용이 필요하다(R-M3).
- **VAE 32ch의 장점.** 입력 판독과 첫 시점 재구성(K6)에서 유리할 수 있다. 다만 우리 설계에서 프레임 안 저대역은 RGB 페이지(Laplacian 저대역 교체)가 소유하므로 VAE 상한의 영향은 판독에 한정된다.

### 1.4 결정식 CT-M1 (CT35 v3)과 네 갈래 결과

$$
\mathrm{ES}_{L}(T)=\sum_{k=1}^{7}w^{L}_{k}\,z_k(T),\qquad
T_{eng}=\arg\max_{T\in\mathcal A}\frac{\mathrm{ES}_{L1}(T)}{\overline{\mathrm{T4h}}_{world}(T)}\ \ (\text{동률 } |\Delta\mathrm{ES}_{L1}|\le2\%p\text{면 빠른 쪽})
$$

$\mathcal A$는 엔진 계약(§1.9 A)과 세 게이트(라이선스, FP16, TCT-v3 녹색·황색)를 통과한 후보다. $\overline{\mathrm{T4h}}_{world}$는 사전 등록한 무브 혼합(🟢 50%, 🟡 35%, 🔴 15%)에서의 세계당 계획 T4-h다.

```text
procedure SelectTeachers_v3(candidates, E0, E1v3, E3):
  A ← {T : license_ok(T) ∧ fp16_nan(T)=0/10k ∧ TCT_C_L1(T) ≥ 0.55}
  T_eng ← argmax_{T∈A} ES_L1(T) / T4h_world(T)            # 2%p 동률이면 빠른 쪽
  # 레벨 2: 먼저 엔진 교사 + Reference Ring으로 버티는지 본다 (파라미터 0)
  if NVF_S(T_eng ⊕ Ring) passes L2-green:   return (T_eng, ref=none)                     # O1
  R ← {T ∈ A' : NVF_S(T) − NVF_S(T_eng ⊕ Ring) ≥ +5%p ∧ coresident(T, T_eng)}         # A' = 참조 계약 통과
  if R = ∅:                                   return (T_eng, ref=none, upgrade=RefAdapter)  # O4
  T_ref ← argmax_{T∈R} ΔNVF_S(T) / ΔT4h_world(T)
  if |ES_L1(T_ref) − ES_L1(T_eng)| ≤ 2%p and T4h(T_ref) < T4h(T_eng):
                                              return (T_ref, ref=none)                     # O3 단일 교사 교체
  return (T_eng, ref=T_ref)                                                                 # O2 두 교사
```

- **그림체의 물리 몫 [조합].** 미감 연방제를 그림체로 넓힌다. 셰이딩 램프(셀 셰이딩), 윤곽선, 해칭은 렌더러의 NPR 모드가 파라미터 0으로 소유한다. 교사가 맡는 것은 표면의 붓 질감과 팔레트뿐이다. 붓질이 시점마다 달라지는 회화성(시점 의존 붓터치)은 `장기`다.

### 1.6 Reference Ring: 파라미터 0 참조 조건 [조합]

v2.1의 Context Ring(뷰 바깥 64 px에 인접 차트를 더 거친 레벨로 채움)을 입력 참조로 넓힌다.

1. **캔버스.** 판정 뷰를 1024×1152로 넓힌다. 위쪽 128 px 띠가 참조 띠다. 이 띠는 소유하지 않는다.
2. **띠 내용.** 입력에서 뜬 정류 견본 2–4개다(MRH 법선으로 정류하고 MRH shading으로 탈조명). 대상 표면과 MRH sem이 같거나 TE 공간에서 가장 가까운 재질을 고른다. 없으면 입력의 지배 팔레트 크롭을 쓴다.
3. **마스크 디노이즈.** 매 스텝 띠 latent를 $z_{strip}\leftarrow\sqrt{\bar\alpha_\sigma}\,\mathrm{Enc}(\mathrm{ref})+\sigma\,\epsilon_{\mathrm{WNF}}$로 바꿔 넣는다(RePaint식 [부품]). 본문은 정상 진화한다. 어텐션이 띠를 보고 팔레트와 붓 질감을 잇는다.
4. **비용.** 토큰 +12.5%, FLOPs +13–15% → 뷰당 약 1.14 TFU.
5. **비회귀.** 띠 내용은 입력 이미지(y의 일부)에서 온다. 다른 영역에서 먼저 생성된 렌더 픽셀이 아니다(조항 2 통과). 모든 뷰는 lockstep이다(조항 1 통과).
6. **가설 H-RR.** Ring은 plain SDEdit 대비 L2에서 NVF-S를 ≥10%p, L1에서 ≥3%p 올리고 DR AUC를 0.02 넘게 떨어뜨리지 않는다. 선례는 in-context(diptych) 생성과 RePaint이고, 결합 대상이 band-iso 차트 뷰라는 점이 새롭다.

### 1.9 교사 계약 v3

**(A) 엔진 교사 계약.** v2.1 A1을 고친다. 나머지는 유지한다.

1. 시스템 경로의 오픈 교사는 **최대 둘**이다. 엔진 교사는 하나이고 동결한다. 참조 교사는 (A′) 조건에서만 둔다.
2. 붙일 수 있는 것: 우리가 처음부터 학습한 어댑터(합 ≤ 엔진 교사의 2%), 자체 양자화, FP16 Rescue, VAE fp16 자체 수리. 제3자 LoRA·ControlNet·편집 어댑터·사전 양자화 가중치는 금지(Q7).
3. f8 공간 정렬 latent, σ 접근, 상업 사용 라이선스.
4. TCT-v3 레벨 1에서 녹색 또는 황색.
5. 선택식: ES_v3(L1) / 수용 세계당 T4-h(CT-M1).
6. **입력 이미지로 가중치를 바꾸지 않는다**(CT-M5).

**(A′) 참조 교사 계약 [신규].**

1. 레벨 2 영역의 외관 대역만 소유한다. 기하 판독과 저대역 구조 판정은 엔진 교사가 한다.
2. 자기 소유 대역의 DR 판정은 참조 조건 아래에서 자기가 한다.
3. Exhaust에 teacher id로 구분한다. **P1 래칫 데이터로 쓰지 않는다**(엔진 교사 분포와 섞지 않는다. `P1-확장` 이후 재검토).
4. 어댑터를 붙이지 않는다(LatentDown/Up-S-k만 예외).
5. Mode A2 메모리 상주를 E0에서 증명한다.
6. **제거 가능성.** 참조 교사를 빼면 레벨 2는 Z + Reference Ring으로 떨어진다. 레벨 1 경로는 영향이 없다.

**(B) 입력 이미지 계약 [신규, v2.1 (B) 미감 교사 계약을 대체].**

1. 입력은 출처와 무관하게 같은 경로를 탄다(모델 중립). 출처 메타(EXIF, 사용자가 밝힌 생성기)는 기록만 하고 분기 조건으로 쓰지 않는다. 예외는 EXIF 초점거리처럼 **물리 측정값**뿐이다.
2. 입력과 그 파생은 `USER`/`USER-DERIVED`다. 세계 W와 그 사용자의 렌더로만 흐른다(§4.7).
3. 입력은 관측 제약이다. 프레임 안 관측 대역을 소유하지만 렌더 픽셀을 바꿔치기하지 않는다(Read-Only Camera).
4. Soul은 이 계약 아래의 한 출처(`USER/src=soul`)다. 창업자의 데모 입력은 Plan A 콘텐츠 사용이다. v2.1의 미감 교사 슬롯(SC9)은 **입력 이미지 슬롯**으로 바뀐다.

### 2.3 프로토콜

```text
for I in inputs:
   L ← MRH_read(I) ⊕ InverseLook(I)          # 깊이, 법선, θ̂_in, 관측 대역 마스크 (판독 2 NFE)
   poses ← (R-real, R-syn): GT 시점 중 IR 등급별 1개씩   # 🟢 IR 0.1–0.3, 🟡 0.3–0.6, 🔴 0.6–0.9
           (그 외): 경쟁 I2V 클립 프레임을 SIFT + GLOMAP으로 입력에 등록 → 등급별 1개씩
   for c in poses:
      (Ĩ_c, M_obs) ← ForwardWarp(ExplainAway(I, θ̂_in), depth, c)       # 관측 영역만 채워진 목표 시점
      for arm in {Z-plain, Z-Ring, klein-plain, klein-ref, (Z-Base: Q1)}:
         for seed in {1, 2}:
            F ← MaskedDenoise(arm, Ĩ_c, M_obs, σ: 구멍은 1.0부터, 관측부는 σ_obs 스냅부터)
            F ← CameraStack(θ̂_in)(F)                 # 'E1-v3+θ' arm은 이 줄을 켜고, 대조 arm은 원본 I로 직접 채운다
      competitor frame at c (포즈 일치)
```

- **포즈 일치.** 경쟁 클립 프레임을 고전 SfM으로 입력 사진에 등록한다. 등록에 실패한 비율 자체가 보고 항목이다(경쟁 모델이 공간을 얼마나 지어냈는지의 지표).
- **arm 비교 대상.** 사람 2AFC는 교사 arm 상위 2개만 경쟁 프레임과 붙인다. 나머지 arm은 자동 지표로 순위를 매긴다.
- **비회귀.** 측정 절차다. 각 포즈는 입력(y)에서 독립적으로 채운다. 채운 결과를 다른 포즈의 조건으로 쓰지 않는다(연쇄 없음).

### 2.4 지표

| 지표 | 정의 | 종류 |
|---|---|---|
| **NVF-H_C**(등급) | $P(F\succ C)$: "원본에 더 충실하고 더 좋은 쪽", 경쟁 프레임 C와 블라인드 2AFC | 사람 |
| NVF-R | R-real에서 $P(F$가 실제 사진으로 판정$)$, GT 사진과 2AFC. 50%면 구별 불가 | 사람(진단) |
| **NVF-obs** | 관측 마스크 안에서 저역(가우시안 σ=4 px) ΔE00 중앙값 ≤2.0 ∧ 에지 위치 드리프트 ≤1 px인 시점 비율 | 자동, 파라미터 0 |
| **z_style** | $z=\big(d_{SSV}(F|_{M_{inv}},I)-\mu_{self}\big)/\sigma_{self}$. SSV = Lab 팔레트 히스토그램(EMD), 방사 PSD 기울기, 평탄부 그레인 PSD, 구조 텐서 방향 히스토그램 16빈, 에지 밀도, 채도 분포. μ_self, σ_self는 입력 자신의 겹치지 않는 크롭 사이 거리 분포 | 자동, 파라미터 0 |
| **Δ_photo** | $\mathrm{DCA}(F;c_{photo},c_{style})-\mathrm{DCA}(I;c_{photo},c_{style})$, $\mathrm{DCA}(x;c_a,c_b)=\mathbb E_t\big[\lVert\epsilon-\hat\epsilon(x_t,t,c_b)\rVert^2-\lVert\epsilon-\hat\epsilon(x_t,t,c_a)\rVert^2\big]$. 양수면 사진풍으로 끌렸다 | Teacher-DCA 재사용, 이미지당 4 fwd @512² ≈ 1 TFU |
| 이음매 | 관측 경계 8 px 띠의 T-LPIPS-S ÷ 내부 T-LPIPS-S ≤1.3 | 자동 |
| 기하 | 가림 해제 영역의 MRH 깊이 vs GT(R-real, R-syn) AbsRel. 프레임 밖 원거리는 정답이 하나가 아니라 재지 않는다 | 자동 |

### 2.5 판정선과 BT 회계

| 판정 | 엔진 교사 (L1, 등록 무브 혼합) | 레벨 2 경로 |
|---|---|---|
| **녹색** | NVF-H_C ≥60% ∧ NVF-obs ≥95% | NVF-H_C(L2) ≥55% ∧ z_style ≤1.5 ∧ Δ_photo ≤ τ_p(τ_p = 입력 자신의 겹치지 않는 크롭끼리 잰 Δ_photo의 2σ, 측정 잡음 바닥) |
| **황색** | 55–60% → 의무: Reference Ring 상시, DTC, Gaffer 치트 라이트, 측량 LoRA(A1) 검토. 🔴 무브는 기본 메뉴에서 빼고 선택 시 경고 | 50–55% → L2는 🟢 무브만 기본 |
| **적색** | <55% → 황색 의무 + 몫 분해(관측 보존 / 가림 해제 / 프레임 밖 / 조명) + Q3 승급 검토 | <50% → O4(Ref-Adapter) 착수, L2 공개 데모 보류 |
| 진단 | NVF-R(🟢) 계획 가정 ≥35%, 등급별 표 공개 | Δ_photo 등급별 |

$$
\mathrm{logit}(\mathrm{SP}_{I2V})=\mathrm{logit}(\mathrm{NVF\text{-}H}_C)+\mathrm{logit}(\mathrm{TP}_{I2V}),\qquad \mathrm{SP}_{I2V}\ge0.5\iff \mathrm{TP}_{I2V}\ge1-\mathrm{NVF\text{-}H}_C
$$

- TP_I2V는 같은 포즈에서 **우리 시스템 렌더 vs 교사 한 장**이다(세계 일관성의 세금). NVF-H_C 60%면 TP_I2V ≥40%, 55%면 ≥45%(v1 TP 목표와 같다)로 충분하다. CT2와 같은 구조다.
- 승리 조건 자체(같은 입력의 경쟁 I2V 대비 무작위 시점 ≥50%)는 바꾸지 않는다. TCT-v3는 그 조건이 기계적으로 가능한지를 3주차에 알려 준다.

### 3.4 MassingFM 부분 lift 조건 학습: Render-Hide-Complete [조합]

우리 세계에서 한 시점을 렌더하고 나머지를 가린 뒤 완성시킨다. 문법 장면이 곧 정답이라 라벨이 공짜다.

```text
procedure RHC_Sample(P ~ 레이아웃 문법, rng):
  W  ← Instantiate(P)                                   # 문법 장면 = 라벨
  c0 ← SampleInputCamera(W, rng)                         # 눈높이 70%, 로우·하이 앵글 30%, FOV 24–90°, 벽 코앞 제외
  (D, S, V) ← RayCast(W, c0, 64×64)                      # 깊이, sem, 가시 slot id (CPU numba, 장면당 약 1–3 ms)
  mode ← rng.choice{GT+잡음 50%, MRH-lift 30%, 에셔 교란 10%, 저해상·원경 컷 10%}
  if mode = MRH-lift:  (D, S) ← MRH(Realify(Render(W, c0)))        # Realify 15만 풀의 탭 재사용
  if mode = GT+잡음:  D ← D·(1+ε_scale) + affine 잡음;  S ← 혼동 행렬 잡음
  if mode = 에셔:     D ← PiecewisePerspective(D, rng)              # 영역별로 다른 소실점·스케일 (§4.5)
  O ← Carve(D, c0) → 32³ × {관측 점유, 관측 빈 공간, 미관측}        # 시선 위 빈 공간도 정보다
  H ← ObservedSlots(S, D, V)                             # class, 부분 OBB, truncated 플래그
  y ← CaptionComposer(P, view=c0, mode ∈ {전체 40%, 프레임 밖 힌트만 40%, 없음 20%})   # "무엇이 더 있는지"
  return cond = {O, H, cam(c0), TE(y)},  target = {shell ≤32, slot ≤64, 광원 ≤16, matter, occ/sem 32³ 전체}

loss   = FM(연속) + masked CE(이산) + λ_obs·‖(occ_pred − O)⊙M_obs‖₁
sample = 집합 공간 inpainting: 매 스텝 관측 slot·점유를 관측값으로 되돌린다 (가중치는 MRH 판독 신뢰도·에셔 잔차로)
```

- **크기.** 3D patchify 인코더(32³×4ch → 4³ 패치 → 512 토큰, 약 3M) + 입력 카메라 토큰 + 3상태 임베딩 = 24 → **28M**.
- **연산.** 시퀀스가 약 880 → 1,390 토큰(×1.58)이 된다. 6 × 28×10⁶ × 4.86×10⁹(v2.1 토큰) × 1.58 ≈ **1.3×10¹⁸ FLOPs**. v2.1의 실효(2.8–4.4×10¹⁶ FLOPs/T4-h)로 **30–46 T4-h**다.
- **데이터 규모.** 600만 샘플 × 1,390 토큰 = 8.3×10⁹ 토큰. 28M의 Chinchilla 점(5.6×10⁸)의 약 15배다. 소형 모델의 과잉 학습 구간이라 데이터가 병목이 아니다.
- **비회귀.** 집합 디퓨전이고 픽셀 캔버스가 없다. 전역 1-pass bedrock 예외 안이다. 입력 lift는 y(관측)다.
- **게이트(X-MFL).** RHC 홀드아웃에서 관측 일치 IoU ≥0.9, 프레임 밖 레이아웃 사람 선호가 무조건 MassingFM 대비 ≥60%, 입력 시점 재렌더 깊이 AbsRel ≤0.08.
- **BRP도 같은 절차를 쓴다.** 64³ 부분 관측 = 입력 frustum 카빙. 지형·자연은 Warp GPU ProcGen 20만에서 시점을 뽑는다.

## 4. 데이터 주조소 v3: "우리 세계의 한 장"

### 4.1 원칙 v3

> **"기하는 코드에서, 외형은 교사에서, 라벨은 구성에서. 입력은 우리 세계의 한 장에서. 사용자의 이미지는 데이터로 들어오지 않는다."**

- 한 샘플은 여섯 겹이다: (절차·센서 GT 기하) ⊗ (엔진 교사 photoreal 외형) ⊗ (교사 내부 특징) ⊗ (결정 곡선 대역 마스크) ⊗ **(입력 시점과 θ_look·열화·에셔·스타일 교란 파라미터)** ⊗ (계보 태그).
- 다섯 번째 겹이 I2V의 핵심이다. 우리는 정답 세계를 갖고 있으므로 **입력 한 장과 그 입력이 숨긴 모든 것의 정답**을 동시에 만든다. 경쟁자는 인터넷 비디오에서 학습 모델로 포즈·깊이를 추정해 이 쌍을 근사한다(SpatialVID, Lyra 2.0 계열). 우리 라벨은 구성상 정확하다.
- 주조소는 Soul 없이, **USER 없이** 돈다. 사용자 업로드가 아무리 쌓여도 데이터 자산은 한 바이트도 그 계보를 갖지 않는다.

### 4.2 I2V 학습쌍

**(a) 합성 쌍 (엔진 트랙 세계, D0 + D2-T).**

```text
I2VPair = {
  input   : Degrade_d( Escher_e( Style_s( Lens·Sensor·Film_θ( Render(W, c0) ) ) ) )   # 각 교란은 확률적으로 켠다
  labels  : θ_look, c0(내부·외부 파라미터), d·e·s 파라미터, @c0의 depth/normal/albedo/shading/sem(GT),
            MRH.obs 정답 마스크(d와 θ의 전달함수), 정답 세계 W(Merkle 루트),
            새 시점 R(W, c_k), 궤적별 IR(c, c0), 3상태 점유 32³/64³(RHC)
  lineage : GT-proc | solver-W*(gen k) | teacher-transport(t, 대역) ...,  prov.user = none, prov.soul = none, bench-holdout 여부
}
```

**(b) 실사 쌍 (자체 촬영, D0 + D1).** 오라클·MVS 장면 300–500개 × 장면당 사진 40–100장. 한 장을 입력으로, 나머지를 정답 새 시점으로 쓴다(COLMAP SIFT + GLOMAP 포즈, PatchMatch 깊이). 1.2–5만 쌍이 추가 촬영 없이 나온다. 진짜 렌즈·센서·ISP의 입력 분포를 덮는 유일한 소스다. **평가에서 실사 쌍 비중 ≥30%**를 규칙으로 둔다(우리 렌더러 룩 과적합 방지, R-M5).

**(c) I2V 자기 대국 왕복(Render-Lift-Rerender) [조합, 신규 운용].**

```text
for W in EngineTrackLibrary (prov.user = none ∧ prov.soul = none ∧ ¬bench-holdout):
   c0 ← SampleInputCamera(W);  I ← Degrade(Render(W, c0; θ_rand))
   Ŵ ← I2V_Pipeline(I, text = CaptionComposer(W, 프레임 밖 힌트, p = 0.5))
   보고: 첫 프레임 지각 거리, 관측 대역 충실도(Ŵ vs W, R0 영역), θ̂ 오차, E_esc(정답 0),
         IR 등급별 발명 영역의 DR·사람 표본 타당도, 레이아웃 차이(정보용)
   큐:   실패 사례 → MassingFM·MRH 하드 네거티브. Ŵ의 발명 영역은 라벨로 쓰지 않는다(정답 W가 있다)
```

- 비용은 I2V 세계 솔브 1회(약 1–1.5 T4-h)다. 90일에 20–40 세계 = 30–50 T4-h를 **세계 솔브(개발) 버킷**에서 쓴다.
- 이것이 I2V의 회귀 테스트이자 플라이휠의 측정기다. 사용자 데이터 없이 I2V 품질을 매일 잰다.

### 4.5 에셔 합성 [신규]

AI 이미지의 원근 거짓말을 우리 세계에 일부러 심는다. 정답(가장 가까운 일관 세계)은 원본 W다.

| 교란 | 방법 | 라벨 |
|---|---|---|
| 조각 원근 | MassingFM shell·평면 단위로 영역을 나누고 영역마다 다른 카메라(초점거리, 소실점)로 렌더해 합성 | 영역 맵, 영역별 카메라 |
| 층별 스케일 | 파사드 층마다 창 크기를 ±10–30% 바꿔 렌더 | 위반 크기 |
| 끊긴 위상 | 계단·난간 메시를 자르고 어긋나게 다시 붙임 | 끊긴 위치 |
| 크기 거짓말 | 물체 크기를 크기 사전 밖으로(×0.5–2) | 위반 물체 |
| 거짓 조명 | 물체마다 다른 광원 방향으로 셰이딩 | 물체별 광원(치트 라이트 학습·평가에 사용) |

- 2만 장(렌더 1–2 T4-h + Realify 약 11 T4-h). 용도: E_esc 보정(주입 크기 대 점수 Spearman ≥0.8), 화해 피팅 평가, MassingFM RHC의 에셔 모드 10%, (조건부) MRH.esc 학습.
- 덤: "AI 이미지 원근 거짓말 탐지기" 쇼케이스의 정량 근거가 된다.

### 4.6 스타일 운송과 스타일 세계 (레벨 2)

- **스타일 운송 [조합].** 엔진 트랙 렌더를 그림체 캡션(애니 셀, 유화, 수채, 잉크, 3D 툰 × 변형)으로 엔진 교사 SDEdit한다. σ는 결정 곡선상 기하 대역이 보존되는 점으로 스냅한다. 기하 라벨은 그 대역 안에서 유효하다. 1만 장은 코어(MRH 그림체 판독 견고성), 4만 장은 레벨 2 조건부다.
- **NPR 렌더 [파라미터 0].** 툰 램프, 윤곽선(깊이·법선 불연속), 해칭을 렌더러 모드로 만든다. 라벨은 정확하다.
- **스타일 세계 (O4 조건부).** 재질 패스를 그림체 캡션 + 측량 모드로 돌려 표면 페이지 자체를 그림체로 만든 세계 20개. 여러 시점에서 렌더하면 **다시점 일관 그림체 쌍**이 나온다. Ref-Adapter의 학습 데이터다(세계당 2 T4-h, 40 T4-h).

## 5. Phase 2 모델의 I2V 영향: 입력 이미지 + 사건

### 5.1 발상: 입력 이미지는 사건의 t₀ 단면이다

Phase 2의 입구는 "이미지 한 장 + 사건 텍스트"다("잔이 떨어진다", "그녀가 돌아본다"). I2V 세계는 t₀ 상태이고, 사건은 그 상태에서 굴러간다. 상상하지 않고 굴려 본다는 v2.1 원칙이 그대로 맞물린다.

| 새로 생기는 일 | 방법 | 종류 |
|---|---|---|
| t₀ 위치 | I2V 세계(MassingFM·BRP 완성 + 입력 lift) | 기존 |
| t₀ 속도 | **모션블러가 곧 속도계다.** 블러 커널 길이·방향 ÷ 셔터(θ̂_in) × 깊이 → 화면 속도와 3D 속도 성분. 블러가 없으면 정지 또는 EPD-S 사전분포 | 고전(Blur-as-Measurement의 단일 사진판) |
| 사건 한가운데의 입력(물보라가 공중에 뜬 사진) | **양방향 사건 추론**: SMC 제약 "x(t₀) = lift 상태"(불확실성 가중)를 걸고 과거(t<t₀)와 미래를 함께 푼다 | 기존 SMC + 제약 |
| 인물의 t₀ 자세 | R-Kpt 2D + lift + 크기 사전 → MoPri-S 키프레임 마스크(이미 있는 입력) | 기존 |
| 사용자 인물의 정체성 | **Avatar-Fit(맞추되 배우지 않는다)** | §5.3 |

### 5.3 캐릭터: Avatar-Fit (맞추되 배우지 않는다) [운용/조합]

사용자 사진 속 인물을 움직이려면 정체성을 지켜야 한다. 경쟁 I2V는 조건화로 지킨다. 우리는 identity LoRA를 쓸 수 없다(USER 학습 금지).

1. **형상.** MakeHuman(CC0) 체형 PCA + 얼굴 형상 계수를 입력 lift와 R-Kpt에 맞춰 **피팅**한다(TTO, 장면 파라미터).
2. **외관.** 관측된 피부·의상 텍스처는 입력 컷 견본으로 아바타 UV에 투영한다. 미관측부(뒤통수, 반대편 얼굴)는 엔진 교사 + Reference Ring(입력 얼굴·의상 견본)으로 채운다.
3. **표정·입.** Expr-S가 블렌드셰이프만 낸다. 정체성은 가중치가 아니라 **세계 W의 아바타 파라미터**에 산다.
4. **제한.** 얼굴 근처 DP-0 각도 제한(±30°)과 2c 일정은 그대로다. 미관측 얼굴 반쪽을 크게 드러내는 무브는 🔴로 분류하고 발명 비율과 함께 표기한다.
