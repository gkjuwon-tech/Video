## P. 건설적 프리모템: Day 90에 이 렌즈 때문에 v3가 실패했다

### P.0 가정과 방법

- **가정.** 오늘은 Day 90이다. 같은 사진 대결(T2)에서 🟢는 이겼지만 🟡🔴와 4K/8K 쇼케이스에서 졌고, 공개 벤치는 "홈 경기"라는 비판을 받았고, 레벨 2(그림체) 데모는 나가지 못했다. 원인을 추적하니 이 렌즈 영역(교사, 수십M 모델, 데이터 주조소)이 나왔다.
- **방법.** 원 메모의 모든 수치를 v2.1 원문, 자매 렌즈(파이프라인·벤치·권리) 메모, T4 리서치와 대조해 다시 계산했다. 실패 지점마다 (무엇이, 왜, 어떤 숫자에서)를 적고, 목표를 낮추지 않는 업그레이드(설계 변경, 실험, 가드, 폴백 사다리)를 붙였다.
- **결론 한 줄.** 원 메모의 뼈대(Z 유지, Reference Ring, NVF 천장, 가중치 불변, "우리 세계의 한 장")는 맞다. 무너진 곳은 **판독기가 거짓말을 고쳐 읽는 것, 문법 밖 입력, 푸시인의 대역 발명, 우리 교사 출력으로 만든 홈 경기, 교사 선정에 경쟁 출력을 쓴 방화벽 구멍, 세 렌즈에 흩어진 숫자**였다.

#### F-M2. 교사 메모리

- **GPU.** 원 메모 Mode A2는 "GPU1의 Z 복제본 6.2 GB를 klein 4.0 GB로 바꿔 2.2 GB 가볍다"고 했다. 메모리는 맞지만 **L1 세계의 lockstep 구간에서 Z 처리량이 절반**이 된다. v2.1 Mode A는 lockstep 구간에 두 장 모두 Z를 돌린다. 또 메모리 맵의 MRH 0.1 GB는 v2.1 카탈로그의 "추론 1.5 GB"와 모순이고, I2V 판독은 1024² 타일과 MRH.obs 정밀화를 더한다. 교정: GPU0 Mode A = 6.2 + 활성 2.0–2.25(Ring 프로파일) + 1.0 + VAE 0.3–1.0 + MRH 0.6–1.5 + 0.07 + 링버퍼 0.5(USER·EXTGEN 세계는 0) + ctx 0.5 = **11.2–13.0 GB**(15 GB 안).
- **호스트.** 원 메모 pinned 39 GB(TE가 다르면 47). 여기에 Ledger hot 10–13, 세계 피라미드 2–6, EXR 큐 4를 더하면 55–70 GB다. 최소 사양 64 GB 호스트는 OS와 CPU 농장 여유 없이 넘친다.
- **Kaggle.** RAM 약 30 GB라 교사 둘을 못 둔다. 원 메모는 "레벨 2는 Kaggle에서 돌리지 않는다"로 끝냈다. 그러면 공개 재현(Kaggle 노트북)에 L2가 없다.
- **TRT.** Ring 캔버스(1024×1152)와 참조 토큰(6.4k)은 별도 최적화 프로파일이 필요하다. 활성 메모리는 최대 프로파일 기준(+12.5%, 2.0 → 2.25 GB)이다. 참조를 1024²로 2장 넣으면 토큰 12.5k로 활성이 약 4배가 되어 GPU1 15 GB를 넘는다.
- **업그레이드.** (1) 카드당 상주 교사 하나. L1은 항상 Mode A. L2 세계의 외관 단계에서만 GPU1의 Z 복제본을 klein INT8로 교체한다(pinned 재적재 4 GB ≈ 0.7 s, 단계 단위). 기하 판독과 MRH는 Z만 쓴다. 이것이 파이프라인 렌즈의 반대 근거 둘("Mode A를 깬다", "MRH가 교사별로 필요하다")을 모두 해소한다(CT-M2 개정). (2) pinned = Z INT8 6.2 + klein INT8 4.0 + Z FP16 12.3 = **22.5 GB**. TE는 CPU에서 세계당 한 번 인코딩하고 내린다(일시 8 GB). klein FP16은 NVMe mmap(L2 commit 때만, 8 GB ÷ 2–3 GB/s ≈ 3–4 s). 호스트 정점 = 22.5 + 10–13 + 2–6 + 4 + 8 = **46.5–53.5 GB**. (3) 참조는 512² 2장 또는 768² 1장이 상한이다. (4) Kaggle L2 = Z + Ring-R(O1 경로). klein 결과는 "상시 전용"으로 표기한다. (5) E0 (h)에 "cgroup 60 GB 상한에서 L2 세계 1개 완주"를 넣는다.

#### F-M3. 에셔형 입력: 판독기가 거짓말을 고쳐 읽는다

- **무엇이.** Esc의 평면 성분(파이프라인 §2.9.2, w 0.10)과 화해 비용 성분은 MRH 깊이를 쓴다. MRH 깊이 헤드는 일관된 세계(우리 렌더, 실사 MVS)로만 학습됐다. 그러면 헤드는 "이 그림이 말하는 깊이"가 아니라 "이 그림에 가장 가까운 일관된 깊이"를 낸다. 모순이 판독 단계에서 지워진다. 결과는 Esc 과소 추정이다.
- **어떤 숫자에서.** X-ESC β 게이트(합성 주입 크기 대 Esc Spearman ≥0.8)는 합성 교란 5종이 우리 렌더러로 만든 것이라 MRH가 그 교란을 그대로 읽기 쉽다. 생성기의 실제 실수는 다르다. 휜 "직선", 층마다 바뀌는 반복 주기, 반사가 다른 카메라에서 온 것 같은 불일치, 다른 화각으로 붙인 물체다. 실제 입력은 X-ESC α에서 출처당 10장이다. 오지목률 20%를 n = 10으로 재면 95% 구간이 대략 3–56%다.
- **업그레이드 1: 국소 진실 학습 [개정, 신규 운용].** 에셔 합성 샘플에서 MRH 기하 헤드의 라벨을 **영역별 렌더 카메라의 깊이**(그 영역이 국소적으로 말하는 깊이)로 둔다. 정답 일관 세계(원본 W)는 화해기의 정답으로만 쓴다. 판독기는 충실한 서기, 화해기는 판사가 된다. MRH 기하 학습 샘플의 5%다. 데이터는 이미 장부에 있다(추가 0 T4-h).
- **업그레이드 2: 판독 불일치 성분 r_dis [개정, 파라미터 0].** 판독은 이미 전역 뷰(σ 2점)와 1024² 타일 4장(2K)을 돈다. 전역 깊이와 타일 깊이를 affine 정렬한 뒤의 상대 잔차, 두 σ 판독의 차이를 Esc 성분으로 더한다. 모순된 그림은 크롭에 따라 다른 3D를 말한다. 일관된 그림은 크롭에 무관하다. 파이프라인 Esc 표에 w 0.10으로 제안한다(화해 비용 0.10 → 0.05, 평면 0.10 → 0.05로 재배분).
- **업그레이드 3: 에셔 합성 v2 [개정].** 기존 5종(조각 원근, 층별 스케일, 끊긴 위상, 크기 거짓말, 거짓 조명)에 4종을 더한다. (6) 휜 직선(직선 영역에 화면의 0.3–2% 진폭 저주파 워프), (7) 반복 드리프트(창·타일 주기를 화면 가로질러 5–20% 변화), (8) 반사 불일치(거울·수면 반사를 다른 카메라로 렌더), (9) 붙여넣은 원근(화각·수평선이 다른 물체 합성). 2만 장을 9계열로 다시 나눠 추가 비용은 0이다.
- **업그레이드 4: 실제 입력 사람 주석 X-ESC-H [개정].** 300장(I-OWN 60, I-CC0 60, OPEN dev 생성기 90, OPEN 홈 30, EXTGEN 내부 60) × 주석자 2명 × 8–10분. 성분별 심각도 0–3과 VP 선분. 보정은 EXTGEN을 뺀 240장으로만 한다(권리 렌즈 BLOCK_DEV). 게이트: Esc 대 사람 심각도 Spearman ≥0.6, 성분별 AUC ≥0.75. 비용 사람 약 100시간, $2–3K, GPU 0(판독 재사용).
- **업그레이드 5: 의도된 거짓말 [개정, 조합].** 크기 거짓말 중 일부는 예술이다(야크 판의 신수 스케일, 이끼 판의 역-미니어처). 크기 잔차가 **한 객체에 집중**되고(같은 클래스 다른 개체는 사전 안) 그 객체가 MRH saliency 최상위면 "저술된 스케일"로 표시해 E_size에서 뺀다. 그 객체는 세계에 그 크기로 짓는다. 세계는 여전히 일관된다.

- **무엇이.** Reference Ring은 RePaint식 띠 치환이다. RePaint는 수십–수백 스텝과 재샘플링에서 조화를 얻는다. Z-Image-Turbo는 8 스텝이라 스텝당 σ 이동이 크다. 띠의 팔레트·붓 질감이 본문으로 스미기 전에 궤적이 끝난다.
- **레벨 판정기 이중화.** 파이프라인 렌즈는 PCI(로지스틱 10여 파라미터, 0.7/0.4 경계)를, 원 메모는 Δ_photo(Teacher-DCA)를 레벨 판정기로 썼다. 두 판정이 엇갈리는 입력(사진풍 회화, 강한 그레이딩 일러스트)에서 세계 안 경로가 갈라졌다.
- **역추정 공백.** 셀 애니·플랫 일러스트는 툰 램프 단계 수, 램프 경계, 윤곽선 굵기·색, 팔레트 크기로 대부분 설명된다. 이 파라미터를 읽는 헤드가 없었다. 그래서 물리(NPR) 몫으로 처리할 수 있는 것까지 교사에게 맡겼다.
- **일정.** O4(Ref-Adapter 42–110 T4-h + 스타일 세계 40)가 X-REF(D30) 뒤에야 시작돼 L2 데모가 D90을 넘겼다.
- **업그레이드 1: L2 분할 [개정, CT-M12].** **L2a 평면 채색**(셀 애니, 플랫 일러스트, 3D 툰: PCI의 flat_frac·outline_frac 높음) = 렌더러 NPR 모드(툰 램프, 윤곽선, 팔레트 양자화) + **InverseNPR**(MRH.glob 하위 헤드 6출력: 램프 단계 수, 램프 경계 2, 윤곽선 굵기, 윤곽선 명도, 팔레트 크기) + 고전 추정(k-means 팔레트, 윤곽선 검출). 교사는 프레임 밖 알베도 패턴만 측량 모드로 그리고 입력 팔레트로 포스터화한다. **L2b 매체 질감**(유화, 수채, 잉크, 파스텔) = Ring-R → klein-ref → Ref-Adapter 사다리. InverseNPR 학습 데이터는 엔진 세계의 NPR 렌더 2만(라벨 공짜) + 탭 1 NFE @512²로 약 5 T4-h다.
- **업그레이드 2: Ring-R [개정, 조합].** 중간 σ 스냅(8점 중 3–5번째)에서 한 스냅 위로 재노이즈하고 다시 내려오는 재샘플링을 r = 2회 한다. L2 뷰에만 쓰고 뷰당 8 → 10 NFE(+25%)다. 가설 H-RR-R: Ring-R은 Ring 대비 L2 NVF-S를 +5%p 이상 올린다.
- **업그레이드 3: 판정기 단일화.** PCI가 1차 판정기다(파이프라인 정본). Δ_photo는 사진풍 드리프트 감사 지표로만 쓴다. 레벨은 세계 단위로 한 번 정하고, 경계(0.4–0.7)는 L1 경로 + 안전 메뉴 + 경고로 고정한다(히스테리시스: 재판독으로 바뀌려면 경계에서 0.1 이상 벗어나야 한다).
- **업그레이드 4: 옵션 프리미엄.** D15에 X-REF 예비 판독(L2b 입력 60장, Ring-R, 자동 지표 z_style·Δ_photo)을 한다. z_style >3인 입력이 절반을 넘으면 스타일 세계 20개(40 T4-h)를 D20에 선착수한다. O1/O2로 끝나면 그 세계는 L2 평가·데모 자산으로 돌린다(낭비 0).

#### F-M6. 첫 프레임 충실도와 푸시인 역설

- **무엇이.** 촬영 메뉴는 IR_geo로 등급을 매긴다. 푸시인은 IR_geo 0.01–0.03이라 🟢다. 하지만 파이프라인 IR_info(관측 면이라도 입력 해상도를 넘으면 κ = (φ_k/φ_eff)²만 관측으로 센다)로 보면 다르다.
- **어떤 숫자에서.** 2K 입력(2048 px), 1080p 납품, m = 1 → 1.5 ease 푸시인: κ(m) = min(1, (1.067/m)²). 끝 프레임 κ = 0.51(IR_info 0.49), m 균등 평균 IR_info = **0.25**. 4K 납품이면 m = 1에서 κ = (2048/3840)² = 0.28(IR_info **0.72**), 푸시인 평균 IR_info **0.81**. 8K 납품 m = 1은 κ = 0.07(IR_info 0.93)이다. 대역 발명량으로 보면 8K 푸시인은 1080p 90° 오빗보다 많이 발명한다.
- **왜 졌나.** TexelFM-35는 band-iso 교사 페이지(깨끗한 부모)를 키우도록 배웠다. 2K AI 입력은 JPEG, 리샘플, VAE 왕복, 생성 미세 질감이 섞인 부모다. 열화 30%는 견본과 부모에 걸었지만 "2K 등가 입력이 부모이고 8K가 정답인" 쌍이 없었다.
- **업그레이드 1: 공개 [CT-M13].** 메뉴와 리포트에 IR_geo와 함께 **납품 해상도의 IR_info와 유효 배율 m_eff = (W_out/W_in)·m**을 싣는다. 🟢 조건에 "IR_info 평균 ≤0.30, 아니면 '대역 발명 X%' 표기"를 더한다. 등급을 숨기지 않고 정직하게 붙인다.
- **업그레이드 2: TexelFM 입력 부모 모드 [개정].** 학습 샘플의 30%를 "부모 = Degrade_2K(정답) ⊕ AI 코덱, 정답 = 자체 RAW 매크로·CC0 8K·엔진 8K 렌더"로 바꾼다. 샘플 수와 FLOPs는 같다(4.8×10¹⁸, 세대당 90 T4-h).
- **업그레이드 3: X-SR 실험 [개정, D20–35].** 자체 45–61 MP 미러리스 촬영 40장면 × 3장 = 120장을 2048 px로 내리고(Lanczos + JPEG q90) 입력으로 쓴다. 원본이 정답이다. arm: (i) 우리 F_0 4K·8K + m 1.5 푸시인, (ii) Lanczos + 언샤프 마스크, (iii) 교사 SDEdit SR 한 장(σ 스냅 0.3). 게이트: GT 대비 2AFC ≥40%(50% = 구별 불가), (ii) 대비 ≥70%, (iii) 대비 ≥50%(우리가 더 싸고 일관됨). 비용 2–3 T4-h + 사람 $0.5–1K.
- **업그레이드 4: 첫 프레임 자 교정.** 내부 최적화 자 T-LPIPS-S의 θ 불변 헤드는 "같은 이미지, 다른 그레인 seed" 쌍의 거리를 0으로 학습한다(그레인 재실현은 FFD의 B 블러가 지우는 것과 같은 성분). 내부 문턱은 "입력의 JPEG q90 재인코딩과 입력 사이 거리"를 1단위로 쓴다(q90 동등). 공개 판정은 벤치 렌즈 FFD·OIR 그대로다.

#### F-M7. InverseLook: 비물리 룩

- **무엇이.** AI 이미지의 보케는 깊이를 따르지 않을 때가 많다(배경 일부만 녹음, 전경 가장자리가 선명). 그레이딩이 영역마다 다르다(하늘만 청록). 그레인이 신호 의존 Poisson-Gauss가 아니다. 원 메모 θ̂_in은 28개 물리 출력이다. 물리로 설명 못 하는 몫을 억지로 맞추면 ExplainAway가 잘못 빼고, 같은 θ̂을 모든 시점에 입히면 오빗에서 원본과 다른 룩이 된다.
- **판독 분포 불일치.** 파이프라인 렌즈는 "교사는 Ĩ(설명 제거본)를 본다"고 정했다. MRH 기하 헤드는 중립 룩 렌더·실사로 학습됐다. 불완전한 역그레이딩·잔여 그레인이 남은 Ĩ는 분포 밖이다.
- **업그레이드 1: θ 확장 [개정].** 렌즈 처방에 틸트·스윙 초점면(2), 상면 만곡(1)을 더한다. 실제 렌즈도 가진 성질이라 물리다. 깊이를 따르지 않는 보케의 상당 부분이 기울어진 초점면으로 설명된다.
- **업그레이드 2: 룩 잔차 [개정, 운용].** 물리 θ̂로 설명하고 남은 것을 카메라 고정 3D LUT 잔차(17³, 매끈함 prior, TTO)와 화면 저주파 이득 8×8로 맞춘다. 둘 다 시점과 무관하게 모든 프레임에 같은 값으로 걸린다(비네팅과 같은 지위). 일관성을 깨지 않는다. 남은 잔차 에너지를 **r_look**(비물리 룩 잔차)으로 리포트한다. r_look >τ면 🟢를 추천한다.
- **업그레이드 3: 판독기를 추론 분포로 학습 [개정].** θ-Realify 7.5만을 4만(θ 적용본, 전역 헤드용) + **3.5만(θ 적용 → ExplainAway 통과본, 기하 헤드용)**으로 나눈다. 비용은 같다(약 14 T4-h). 10%에는 비물리 증강(깊이 무관 블러 맵, 영역 그레이딩, 비물리 그레인)을 넣고 "비물리 성분 맵"을 라벨로 준다. 판독기는 그것을 θ에 억지로 넣지 않고 잔차로 보고한다.
- **게이트(E3 (d′)).** 비물리 합성 홀드아웃에서 물리 성분 오차가 물리 전용 대비 ≤1.3배, 주입한 비물리 성분의 r_look 검출률 ≥80%.
- **Phase 2 함의.** "모션블러가 곧 속도계"는 블러가 물리일 때만 성립한다. r_look이 그린 블러를 지목하면 t₀ 속도는 EPD-S 사전분포로 떨어진다.

#### F-M8. 얼굴: 검출기가 실제 얼굴을 본 적이 없다

- **무엇이.** 얼굴 봉투(파이프라인 §10: F2 yaw ±30°, F3 ±15°, 미관측 얼굴면 생성 금지)는 MRH sem 얼굴 클래스와 그 영역 법선 평균으로 켠다. 원 메모의 게이트는 "MakeHuman 렌더 + 운송 홀드아웃 재현율 ≥0.95"였다. 실제 얼굴이 하나도 없다.
- **어떤 숫자에서.** 2K(2048×1152) 입력에서 h_f = 3% 얼굴은 약 35 px다. MRH 출력은 H/4라 약 9 px다. 판독 타일 1024²는 원해상이지만 얼굴 클래스 경계는 H/4에서 정해진다. 작은 얼굴, 측면(yaw 60–90°), 마스크·선글라스, 초상화 속 얼굴, 동물 얼굴에서 재현율을 모른다. 얼굴 방향 MAE가 15°면 ±30° 봉투의 절반이다.
- **업그레이드 1: X-FACE 평가셋 [개정].** 동의서를 받은 캐스트 30명 × 60장(yaw 0–180°, h_f 1–40%, 조명·가림 변화) = 1,800장(`CAPTURE`) + PD/CC0 초상 300(회화·사진) + 운송 홀드아웃 2,000. 게이트: h_f >3% 재현율 ≥0.98, 1–3% ≥0.90, yaw MAE ≤12°, 비얼굴 오검출 ≤5%. 실패 시 봉투 여유를 2×MAE로 넓힌다(목표는 같고 안전 여유만 커진다).
- **업그레이드 2: 얼굴 원해상 판독.** 얼굴 후보(sem 얼굴·피부 확률 >0.1)가 있는 1024² 타일은 MRH 얼굴 헤드를 H/2로 한 번 더 돈다(교사 탭 재사용, 추가 NFE 0, 헤드만 수 ms).
- **업그레이드 3: 이중 검출 OR 융합 [파라미터 0].** 자체 템플릿(피부 색도 타원 + 좌우 대칭 + 눈 위치 어두운 점 쌍)을 두 번째 투표로 둔다. 외부에서 학습된 검출 캐스케이드는 쓰지 않는다. 둘 중 하나라도 얼굴이면 얼굴이다. 확률 0.2–0.5는 얼굴로 취급한다. 오검출의 대가는 카메라 제한뿐이라 보수가 맞다.
- **업그레이드 4: 거울 견본 [조합, 파라미터 0].** 정면 입력의 양 뺨은 비스듬히 관측돼 저대역만 있다. ±30° 오빗은 그 뺨을 정면으로 돌린다. 이때 고대역은 반대편 뺨(얼굴 좌우 대칭)의 정면 관측 패치를 MakeHuman 얼굴 UV에서 거울로 옮겨 견본으로 쓴다. 미관측 면을 생성하지 않는다는 파이프라인 규칙과 맞는다(관측된 면의 대역 채우기다).
- **평가.** 정체성 측정(ArcFace류)은 평가 전용(R-EVAL)이다. 사람 2AFC "같은 사람인가" ≥90%를 F2 클립 공개 조건으로 둔다.

#### F-M10. 벤치 공정성: 홈 경기

- **무엇이.** 벤치 렌즈 표에서 I-OPEN 64장은 Z 40 + klein 24다. 원 메모 TCT-v3의 O-photo 40과 O-style 60도 "화이트리스트 오픈 모델 출력"이고 실제 후보는 Z·klein이다. 주조소 D2-O 4천도 Z 2천 + klein 2천이다.
- **왜 홈인가.** (i) 우리 교사 VAE 왕복은 자기 디코더 출력에서 거의 무손실이다(K6가 부풀려진다). (ii) MRH는 그 교사의 탭으로 그 교사의 출력을 읽는다(분포 안). (iii) D2-O로 같은 생성기 지문을 학습했다. (iv) X-REF에서 klein-ref arm이 klein이 그린 그림을 잇는다.
- **업그레이드 1: 생성기 역할 분리 [CT-M11].** 학습·개발 생성기 = Z, klein, G3(라이선스 확인된 제3 오픈 생성기 1종). dev 평가 전용 = G3b(학습 0, LOGO 측정용). **벤치 전용 생성기** = G4, G5(라이선스 확인된 오픈 생성기 2종, 학습·개발·보정 금지, `HOLDOUT`). 후보: Qwen Image Max 2512, Lumina-Image-2.0, HiDream-I1, CogView4 계열 [2차, 라이선스 원문 확인 필요].
- **업그레이드 2: 주장 규칙.** T2 공개 승리 주장은 **어웨이 집합 = I-OWN ∪ I-CC0 ∪ OPEN-away(G4, G5)**에서 성립해야 한다. 홈(Z, klein) 결과는 따로 공개한다. 홈–어웨이 승률 차가 5%p를 넘으면 원인을 보고서에 쓴다. 벤치 렌즈 표의 I-OPEN을 "Z 40(T1-E 연동, 홈 표기) + G4·G5 24 → 어웨이"로 바꾸기를 제안한다. T1-E의 Z 40장은 제품 경로(텍스트 → 입구 생성 → I2V) 그대로라 홈이 정당하다. 다만 T2 주장에서는 빠진다.
- **업그레이드 3: 선정 입력.** 교사 선정(ES_v3)과 X-REF는 홈 출력을 쓰지 않는다. L2b 입력은 G3 출력 + PD 회화 + **의뢰 일러스트 20장**(작가에게 평가·학습 사용권을 서면으로 받음, $50–150/장)이다.
- **업그레이드 4: 경쟁에게 최선.** 경쟁 네이티브 카메라 도구 허용, 문장 3종 파일럿에서 경쟁에게 가장 유리한 문장, 20장 부분집합 best-of-4(벤치 렌즈 §2.5)를 TCT-v3에도 같은 원칙으로 적용한다.

#### F-M11. 생성기 지문 분포 갭

- **무엇이.** 사용자 입력은 수십 개 생성기와 후처리 사슬을 거친다. 원 메모 L-open은 Z·klein 2종이다. AI 업스케일러(2K → 4K)가 만든 가짜 고주파, SNS 재압축(1080·2048 상한), 워터마크 제거 흔적은 열화 라이브러리에 일부만 있다.
- **어떤 숫자에서.** 파이프라인 §2.10은 업스케일 이미지의 "선명함"을 r_eff로 걸러 소유권을 주지 않는다. r_eff 추정은 방사 PSD 절단에 기댄다. 생성 업스케일러는 PSD 꼬리를 그럴듯하게 채워 절단점이 안 보인다. 그러면 MRH.obs가 그 대역을 관측으로 오인하고 TexelFM이 남의 환각을 이어 그린다.
- **업그레이드 1: AI 업스케일 열화 계열 [개정].** 우리 TexelFM 프리뷰판과 교사 SDEdit SR(σ 스냅 0.3)로 2K → 4K 업스케일을 재현해 열화 라이브러리에 넣는다(D2-T, 5천 장, 2–3 T4-h). 라벨은 "원 2K Nyquist 위 = 관측 아님"이다. 생성 고주파를 관측이 아니라고 배우게 한다.
- **업그레이드 2: 생성기 확장.** L-open 4천 = Z 1천 + klein 1천 + G3 2천(비용 16–25 T4-h, G3 속도는 E0에서 실측).
- **업그레이드 3: LOGO 게이트 [개정, E3 (f)].** **dev 평가 전용 생성기 G3b**(학습에 넣지 않고 벤치에도 쓰지 않는 네 번째 오픈 생성기)의 표본 200장에서 MRH 깊이 AbsRel, θ 오차, MRH.obs 컷오프 오차가 분포 안 대비 ≤1.25배. 실패 시 운송 캡션 다양화, 열화 계열 확대, G3 비중 상향.

#### F-M14. TCT-v3 측정 편향

- **등록 실패 제외 편향.** 경쟁 클립을 SIFT + GLOMAP으로 입력에 등록하지 못하면 그 클립은 비교에서 빠졌다. 실패 클립은 경쟁이 공간을 크게 지어낸(그래서 우리 발명과 비교해야 할) 사례다. 빼면 경쟁의 쉬운 프레임만 남는다.
- **업그레이드.** 등록 실패 시 **의도 포즈 폴백**: 요청 무브(예: 주 피사체 둘레 180°)의 같은 진행률 t/T 포즈에서 우리 교사 프레임을 만들어 경쟁 프레임과 붙인다. 1차 수치(등록 성공만)와 폴백 포함 수치를 함께 낸다. 무브 이행률 MC(벤치 CT-B6)도 붙인다.
- **비용 재산정(교정: NC-M6).** 원 메모 "200 입력 × 3 모델 × 2 × 5 s × $0.05–0.4/s = $0.3–2.4K"는 모델 3개, 5 s다. 벤치 렌즈 정본은 4모델, 8 s, $0.05–0.20/s다. 330 입력 × 4모델 × 8 s(🟢) + 165 입력 × 4 × 8 s(🔴) = 15,840 s → **$0.8–3.2K**.

## 0. 결론 요약과 판결 제안 (개정 본문)

### 0.1 열네 줄 요약

1. **I2V에서 교사가 하는 일이 바뀐다.** 순수 노이즈에서 그리는 일(hero search 112 TFU)이 사라진다. 남는 것은 입력 판독, 프레임 밖 발명, 입력 Nyquist 위 대역, 판정이다. 엔진 교사 선정식에 **참조 조건성(K1)**, **입력 스타일 SDEdit 충실도(K2)**, **첫 시점 재구성(K6)**, **새 시점 충실도(K7: GT·교사 간)**가 들어간다(CT-M1).
2. **엔진 교사는 Z-Image-Turbo를 유지한다(현직).** 레벨 1(사진형 입력)이 Phase 1 주 무대이고, 재질·측량·판독에서 Z가 앞선다. FLUX.2 klein 4B는 **레벨 2b(매체 질감) 참조 교사 후보이자 엔진 도전자**다. 결과는 4갈래(O1–O4)로 미리 정한다.
3. **파라미터 0 참조 경로 Reference Ring(+Ring-R 재샘플)을 먼저 시험한다.** 교사 하나로 레벨 2b까지 덮으면 두 번째 교사가 필요 없다. 레벨 2a(셀 애니, 플랫 일러스트)는 NPR 렌더러 + InverseNPR 헤드로 물리 몫에 넣는다 **[개정]**.
4. **교사 상주는 카드당 하나다 [개정].** L1은 항상 Mode A(Z 복제). L2 외관 단계에서만 GPU1을 klein INT8로 교체한다(0.7 s). 호스트 pinned는 22.5 GB다(TE·klein FP16 비상주).
5. **Teacher Ceiling Test v3는 NVF 시험이다.** **선정은 GT(실사·렌더)와 교사 간 비교로, 경쟁 I2V(COMP)는 잠근 교사의 천장 게이트로만** 쓴다 **[개정]**. 판정선은 v2.1 CT2와 같은 60/55%다.
6. **홈/어웨이를 나눈다 [개정].** 우리 교사(Z, klein)의 출력은 홈이다. 교사 선정·X-REF·T2 공개 승리 주장은 어웨이(자체 촬영, CC0, 벤치 전용 생성기)에서 성립해야 한다.
7. **카탈로그는 거의 그대로 맞물린다.** MRH가 I2V의 심장으로 승격한다(24 → 26M: 전역 28출력, 관측 대역 헤드, 정밀화, NPR·룩 잔차 하위 헤드). MassingFM은 부분 lift 조건이 주 모드다(24 → 28M, OOG 문법 20% 혼합). BRP는 코어로 승격한다. LookPrior-S는 삭제한다.
8. **신규 정본 소형 모델은 0개다.** Esc는 화해 잔차(파라미터 0) + 판독 불일치 성분이다. ExplainAway는 고전 추정기 + MRH 헤드다. Ref-Adapter(25M)는 O4에서만 연다.
9. **합계(교정).** P1 219.5M, 1세대 **249–359 T4-h**. P2 2a–2b 289–356. 전체 약 386M, P1 + P2 2a–2b **538–715 T4-h**(v2.1 대비 +26–39).
10. **데이터 주조소는 "우리 세계의 한 장"을 I2V 학습쌍으로 쓴다.** 열화·AI 아티팩트(업스케일 포함), 에셔 9계열, 그림체 운송으로 입력 분포를 덮는다. 생성기는 학습용 3종과 벤치 전용 2종으로 나눈다. 장부는 **350–407 T4-h**(코어), 버킷 410이다.
11. **사용자 업로드와 외부 생성기 출력은 학습·개발에 쓰지 않는다.** 권리 렌즈 태그(USER, EXTGEN, COMP, HOLDOUT, TEL)와 가중치 불변 원칙을 따른다. 집계 통계는 **우선순위는 정해도 분포를 맞추지는 않는다**. 개선 루프는 Failure Twin으로 돈다 **[개정]**.
12. **푸시인 역설을 공개한다 [개정].** 2K 입력의 1080p m 1.5 푸시인은 IR_geo 0.01–0.03이지만 IR_info 평균 0.25, 4K 납품이면 0.81이다. TexelFM은 입력 부모 모드로 배우고 X-SR로 판정받는다.
13. **판독기는 충실한 서기다 [개정].** 에셔 입력에서 MRH는 그림이 국소적으로 말하는 깊이를 읽는다. 모순을 판정하는 것은 화해기다.
14. **숫자는 수치 원장 하나에 산다 [개정].** 세계·버킷·태그는 자매 렌즈가, 교사·카탈로그·데이터 장부는 이 렌즈가 소유한다. CI가 합계를 다시 계산한다.

- **VAE 32ch.** 판독과 K6에서 유리할 수 있다. 다만 프레임 안 저대역은 RGB 페이지(Laplacian 저대역 교체)가 소유하므로 VAE 상한의 영향은 판독에 한정된다.

### 1.4 결정식 CT-M1 (CT35 v3)과 네 갈래 결과 (개정: 입장 조건, 선정 입력)

$$
\mathrm{ES}_{L}(T)=\sum_{k=1}^{7}w^{L}_{k}\,z_k(T),\qquad
T_{eng}=\arg\max_{T\in\mathcal A}\frac{\mathrm{ES}_{L1}(T)}{\overline{\mathrm{T4h}}_{world}(T)}\ \ (\text{동률 } |\Delta\mathrm{ES}_{L1}|\le2\%p\text{면 빠른 쪽})
$$

$\mathcal A$는 엔진 계약(§1.9 A)과 네 게이트(라이선스, FP16, 메모리, NVF-R 입장)를 통과한 후보다. $\overline{\mathrm{T4h}}_{world}$는 사전 등록한 무브 혼합(🟢 50%, 🟡 35%, 🔴 15%)의 세계당 계획 T4-h다(파이프라인 정본 1.0 / 1.6 / 1.9 → 혼합 1.35).

```text
procedure SelectTeachers_v3(candidates, E0, E1v3, E3):
  # 선정 단계: COMP 사용 0, 홈 출력 사용 0  (CT-M3, CT-M11)
  A ← {T : license_ok(T) ∧ fp16_nan(T)=0/10k ∧ mem_ok(T) ∧ NVF_R_green(T) ≥ 0.30}
  T_eng ← argmax_{T∈A} ES_L1(T) / T4h_world(T)                 # 2%p 동률이면 빠른 쪽
  freeze(T_eng)                                                  # D15
  # 레벨 2b: 엔진 교사 + Ring-R로 버티는지 먼저 본다 (파라미터 0)
  if NVF_S(T_eng ⊕ RingR) passes L2b-green:   ref ← none                              # O1
  else:
    R ← {T ∈ A' : NVF_S(T) − NVF_S(T_eng ⊕ RingR) ≥ +5%p ∧ swap_ok(T, GPU1)}      # A' = 참조 계약
    if R = ∅:                                 ref ← none, upgrade ← RefAdapter      # O4
    else:
      T_ref ← argmax_{T∈R} ΔNVF_S(T) / ΔT4h_world(T)
      if |ES_L1(T_ref) − ES_L1(T_eng)| ≤ 2%p and T4h(T_ref) < T4h(T_eng):
                                              T_eng ← T_ref, ref ← none              # O3 단일 교사 교체
      else:                                   ref ← T_ref                            # O2 교체형 참조 슬롯
  # 게이트 단계: 잠근 구성 하나에 대해서만 COMP 천장을 잰다 (사람 판독 보고서)
  report ← TCT_v3_COMP(T_eng, ref)            # D18. 녹·황·적은 §2.5. 적색이면 사람이 Q3 승급을 결정
  return (T_eng, ref, report)
```

### 1.6 Reference Ring과 Ring-R: 파라미터 0 참조 조건 [조합]

v2.1 Context Ring(뷰 바깥 64 px에 인접 차트를 더 거친 레벨로 채움)을 입력 참조로 넓힌다.

1. **캔버스.** 판정 뷰를 1024×1152로 넓힌다. 위쪽 128 px 띠가 참조 띠다. 이 띠는 소유하지 않는다.
2. **띠 내용.** 입력에서 뜬 정류 견본 2–4개다(MRH 법선으로 정류하고 MRH shading으로 탈조명). 대상 표면과 MRH sem이 같거나 TE 공간에서 가장 가까운 재질을 고른다. 없으면 입력의 지배 팔레트 크롭을 쓴다.
3. **마스크 디노이즈.** 매 스텝 띠 latent를 $z_{strip}\leftarrow\sqrt{\bar\alpha_\sigma}\,\mathrm{Enc}(\mathrm{ref})+\sigma\,\epsilon_{\mathrm{WNF}}$로 바꿔 넣는다(RePaint식 [부품]). 본문은 정상 진화한다. 어텐션이 띠를 보고 팔레트와 붓 질감을 잇는다.
4. **Ring-R 재샘플 [개정].** 8점 σ 스냅 중 3–5번째에서, 한 스냅 위로 재노이즈($z\leftarrow\sqrt{\bar\alpha_{s+1}/\bar\alpha_s}\,z+\sqrt{1-\bar\alpha_{s+1}/\bar\alpha_s}\,\epsilon_{\mathrm{WNF}}$)하고 다시 내려오기를 r = 2회 한다. 증류 교사의 큰 스텝에서 띠 정보가 본문에 스밀 시간을 준다. L2 뷰에만 쓴다.
5. **비용.** Ring: 토큰 +12.5%, 뷰당 약 1.14 TFU. Ring-R: L2 뷰 NFE 8 → 10(+25%).
6. **비회귀.** 띠 내용은 입력 이미지(y의 일부)에서 온다. 다른 영역에서 먼저 생성된 렌더 픽셀이 아니다(조항 2). 모든 뷰는 lockstep이다(조항 1). 재샘플은 같은 뷰 안의 σ 왕복이라 뷰 간 연쇄가 없다.
7. **가설.** H-RR: Ring은 plain SDEdit 대비 L2b NVF-S를 ≥10%p, L1에서 ≥3%p 올리고 DR AUC를 0.02 넘게 떨어뜨리지 않는다. **H-RR-R [개정]:** Ring-R은 Ring 대비 L2b NVF-S를 +5%p 이상 올린다. 선례는 in-context(diptych) 생성과 RePaint이고, 결합 대상이 band-iso 차트 뷰라는 점이 새롭다.

### 1.9 교사 계약 v3

**(A) 엔진 교사 계약.** v2.1 A1을 고친다. 나머지는 유지한다.

1. 시스템 경로의 오픈 교사는 엔진 교사 하나(동결)와, (A′) 조건의 **교체형 참조 슬롯** 하나다. 카드마다 동시에 상주하는 교사는 하나다.
2. 붙일 수 있는 것: 우리가 처음부터 학습한 어댑터(합 ≤ 엔진 교사의 2%), 자체 양자화, FP16 Rescue, VAE fp16 자체 수리. 제3자 LoRA·ControlNet·편집 어댑터·사전 양자화 가중치는 금지(Q7).
3. f8 공간 정렬 latent, σ 접근, 상업 사용 라이선스.
4. 선정은 ES_v3(L1) / 수용 세계당 T4-h(CT-M1). **선정 신호에 COMP와 홈 출력을 쓰지 않는다**(CT-M3, CT-M11).
5. 잠근 뒤 COMP 천장 게이트에서 녹색 또는 황색. 적색이면 황색 의무 + 몫 분해 + 사람의 Q3 판단.
6. **입력 이미지로 가중치를 바꾸지 않는다**(CT-M5).
7. **교체 창 [개정].** 엔진 교체는 D45 창에서 ES_v3 +5%p 이상일 때만. D60 이후 Day 90까지 엔진 동결. D75 창은 참조 슬롯만.

**(A′) 참조 교사 계약 [신규].**

1. 레벨 2b 영역의 외관 대역만 소유한다. 기하 판독과 저대역 구조 판정은 엔진 교사가 한다.
2. 자기 소유 대역의 DR 판정은 참조 조건 아래에서 자기가 한다.
3. Exhaust에 teacher id로 구분한다. **P1 래칫 데이터로 쓰지 않는다**(`P1-확장` 이후 재검토).
4. 어댑터를 붙이지 않는다(LatentDown/Up-S-k만 예외).
5. A2-swap 메모리와 교체 시간을 E0에서 증명한다.
6. **제거 가능성.** 참조 교사를 빼면 L2b는 Z + Ring-R로, 그다음 2.5D 레이어 카드로 떨어진다. L1과 L2a 경로는 영향이 없다.

**(B) 입력 이미지 계약 [신규, v2.1 (B) 미감 교사 계약을 대체].**

1. 입력은 출처와 무관하게 같은 경로를 탄다(모델 중립). 출처 메타(EXIF, 사용자가 밝힌 생성기, C2PA)는 기록만 하고 분기 조건으로 쓰지 않는다. 예외는 EXIF 초점거리 같은 **물리 측정값**뿐이다.
2. 계보는 권리 렌즈 태그를 따른다. 사용자 업로드 = `USER`, 그 파생 = `USER-DERIVED`, 회사 계정 외부 생성기 출력 = `EXTGEN:<g>`(창업자 Soul 데모 입력 포함), 자체 촬영 = `CAPTURE`. 학습·개발 금지 집합은 `BLOCK_TRAIN`·`BLOCK_DEV`(§4.7)다.
3. 입력은 관측 제약이다. 프레임 안 관측 대역을 소유하지만 렌더 픽셀을 바꿔치기하지 않는다(Read-Only Camera).
4. v2.1의 미감 교사 슬롯(SC9)은 **입력 이미지 슬롯**으로 바뀐다. Soul은 `EXTGEN:soul`(회사 데모) 또는 `USER`(사용자가 가져온 경우)의 한 출처다.

```text
         F ← MaskedDenoise(arm, Ĩ_c, M_obs, σ: 구멍 1.0부터, 관측부 σ_obs 스냅부터; 큰 σ 절반은 W4A4)
         F ← CameraStack(θ̂_in ⊕ look_residual)(F)       # '+θ' arm. 대조 arm은 원본 I로 직접 채운다
   if input.tag ∈ EXTGEN: run in clean-room lane (Tap Bus off, ext_vault)
```

- **선정 단계 사람 평가.** NVF-R(GT 대비)은 상위 2 arm, NVF-TT(교사 간 BT)는 후보 쌍 능동 샘플링. 나머지 arm은 자동 지표로 순위를 매긴다.
- **게이트 단계.** 잠근 구성(엔진 + 참조 슬롯 결과) 하나만 경쟁 4모델 프레임과 붙인다. 등록 성공 수치와 폴백 포함 수치, 무브 이행률 MC(벤치 CT-B6)를 함께 낸다. 등록 실패율 자체가 보고 항목이다.
- **비회귀.** 측정 절차다. 각 포즈는 입력(y)에서 독립적으로 채운다. 채운 결과를 다른 포즈의 조건으로 쓰지 않는다.

### 2.7 실패하면 (목표 유지, 업그레이드)

1. **NVF-obs <95%.** 교사가 관측 영역을 다시 그린다. 관측부 σ_obs를 한 스냅 낮추고, 관측 대역 마스크 밖으로 소유권을 넘기지 않게 Router를 고친다.
2. **L1 NVF-H_C 적색.** 몫 분해에서 프레임 밖이 원인이면 MassingFM 부분 lift(§3.4)와 OOG 문법·원경 셸 우선 투자, 가림 해제가 원인이면 Ring 폭 128 → 192 px와 G-Adapter 앞당김, 조명이 원인이면 FitLights + 치트 라이트.
3. **L2b 적색.** Ring → Ring-R → klein → Ref-Adapter → NPR 몫 확대 → 2.5D 카드 순으로 올린다.
4. **에셔 고점수 입력에서만 지면.** Esc별 무브 추천(🟢 강제)을 제품 규칙으로 두고 IR_geo·IR_info와 함께 공개한다. 판독기 국소 진실 학습 비중을 5 → 10%로.
5. **홈–어웨이 차 >5%p [개정].** 홈에서만 이기는 것은 승리가 아니다. 원인(VAE 왕복, 판독 분포, D2-O 지문)을 분해하고 LOGO 대책(§4.3)을 앞당긴다.
6. **NVF-R은 녹색인데 NVF-H_C가 적색 [개정].** 교사는 실사를 잘 잇지만 경쟁이 더 잘 잇는다는 뜻이다. 선정을 다시 하지 않는다(COMP로 선정하지 않는다). 사람이 보고서를 읽고 Q3(Qwen Image Max 2512 INT4 승급)를 판단한다.

**ExplainAway 연산자 (파라미터 0, θ̂ 주어지면).**

$$
\tilde I=\mathrm{Undistort}_{k}\Big(\mathrm{CA}^{-1}\big(\Gamma^{-1}_{tone}\circ M^{-1}\circ\mathrm{LUT}^{-1}_{pca}\circ\mathrm{LUT}^{-1}_{res}\big(I/(V(r)\,G_{8\times8})\big)\Big)-\mathrm{Halation}(\hat\theta)
$$

역변환이 안 되는 셋은 소유권으로 처리한다. 그레인은 판독 σ를 σ_read ≥ σ_grain으로 잡아 노이즈가 가린다(노이즈 마스킹 규칙의 재사용). 디포커스와 모션블러는 MRH.obs 마스크로 그 대역의 관측을 포기한다. 입력은 자기가 실제로 관측한 대역만 소유한다.

**r_look (비물리 룩 잔차) [개정].** $r_{look}=\lVert I-\mathcal R_{\hat\theta,\,LUT_{res},\,G}(\tilde I)\rVert_{lowpass}\,/\,\lVert I\rVert_{lowpass}$. 물리 θ̂과 룩 잔차로 재현한 입력과 실제 입력의 저역 차다. r_look >τ_look이면 🟢를 추천하고 리포트한다. τ_look은 자체 촬영 실사의 95분위로 정한다.

**MRH.obs 관측 대역 헤드 [신규, 0.8M] + 정밀화 [개정, 0.5M].** 픽셀마다 4개 대역(입력 픽셀 기준 옥타브 0–3)에 진짜 정보가 있는지 낸다. 라벨은 열화 전달함수에서 정확히 나온다. $\mathrm{obs}_b(x)=\mathbb 1\big[\min_{d}|H_d(\nu_b;x)|^2\,S_b(x)/N(x)>\tau\big]$. d는 디포커스(θ), 모션블러, JPEG 블록 양자화, 리샘플 체인, 교사 VAE 왕복(f8 latent Nyquist 위는 "관측 아님"), 잡음 제거 번짐, **AI 업스케일(원 해상도 Nyquist 위는 "관측 아님")**이다. 국소 스펙트럼 기울기(고전)는 "흐린 벽돌"과 "매끈한 벽"을 못 가른다. 교사 탭은 그것이 벽돌인지 안다. 헤드 출력은 H/4이고, 옥타브 0–1은 입력 RGB를 가이드로 하는 경량 conv 정밀화(0.5M)가 입력 해상도로 올린다. 같은 정밀화가 얼굴 경계에도 쓰인다.

**학습 라벨.** (i) θ-Realify 7.5만: Realify 출력에 무작위 θ_look(우리 렌즈·센서·필름 스택, 파라미터 0)을 입힌 4만, 그것을 ExplainAway로 되돌린 3.5만(기하 헤드가 추론 때 보는 분포), 비물리 증강 10%. 판독 1 NFE @512²(약 14 T4-h). (ii) 실사 θ-탭 3만: 자체 RAW를 무작위 θ로 현상해 실사 노이즈 탭 패스에 태운다(추가 TFU 0). (iii) EXIF가 남은 자체 촬영 JPEG 초점거리(실측 라벨). (iv) NPR 렌더 2만(L2a). `BLOCK_TRAIN`은 0이다.

**게이트(E3 (d)(d′)(e)(f)).** θ-렌더 홀드아웃에서 초점거리 오차 ≤8%, EV ≤0.3 EV, 톤 커브 재현 ΔE00 ≤3. EXIF 실사 200장 FOV 오차 ≤10%. MRH.obs 컷오프 오차 ≤½ 옥타브. **(d′)** 비물리 합성에서 물리 성분 오차 ≤1.3배, r_look 검출률 ≥80%. **(f) LOGO**: dev 평가 전용 생성기 G3b 표본 200장(학습 0, 벤치 0)에서 깊이 AbsRel·θ 오차·obs 오차가 분포 안 대비 ≤1.25배.

### 3.4 MassingFM 부분 lift 조건 학습: Render-Hide-Complete [조합] (개정: OOG, 저술된 스케일)

우리 세계에서 한 시점을 렌더하고 나머지를 가린 뒤 완성시킨다. 문법 장면이 곧 정답이라 라벨이 공짜다.

```text
procedure RHC_Sample(rng):
  G  ← rng.choice{문법 안 80%: RoomGen, StreetGen, 한옥, 을지로, 바, Infinigen 실내;
                  OOG 20%: G-STUDIO, G-DUNE, G-COAST, G-VALLEY, G-FLOOR, G-PLAZA, Infinigen 자연, ProcGen 지형}
  W  ← Instantiate(G, rng)                               # 문법 장면 = 라벨
  if rng < 0.05: W ← ScaleAuthor(W, hero, ×2–5)          # 저술된 스케일(야크형 거대화), 플래그 라벨 [개정]
  c0 ← SampleInputCamera(W, rng)                         # 눈높이 70%, 로우·하이 앵글 30%, FOV 24–90°, 벽 코앞 제외
  (D, S, V) ← RayCast(W, c0, 64×64)                      # 깊이, sem, 가시 slot id (CPU numba, 장면당 약 1–3 ms)
  mode ← rng.choice{GT+잡음 50%, MRH-lift 30%, 에셔 교란 10%, 저해상·원경 컷 10%}
  if mode = MRH-lift:  (D, S) ← MRH(Realify(Render(W, c0)))        # Realify 15만 풀의 탭 재사용
  if mode = GT+잡음:  D ← D·(1+ε_scale) + affine 잡음;  S ← 혼동 행렬 잡음
  if mode = 에셔:     D ← EscherFamily_k(D, rng), k ∈ 9계열 중 기하 6계열     # §4.5
  O ← Carve(D, c0) → 32³ × {관측 점유, 관측 빈 공간, 미관측}        # 시선 위 빈 공간도 정보다
  H ← ObservedSlots(S, D, V)                             # class(또는 freeform), 부분 OBB, truncated, scale_authored 플래그
  y ← CaptionComposer(G, view=c0, mode ∈ {전체 40%, 프레임 밖 힌트만 40%, 없음 20%})
  return cond = {O, H, cam(c0), TE(y)},  target = {shell ≤32, slot ≤64, 광원 ≤16, matter, occ/sem 32³ 전체}
           # 실외: 원경 셸(하늘·지형·수평선)은 target에서 빼고 cond로 준다 [개정]

loss   = FM(연속) + masked CE(이산) + λ_obs·‖(occ_pred − O)⊙M_obs‖₁
sample = 집합 공간 inpainting: 매 스텝 관측 slot·점유를 관측값으로 되돌린다 (가중치는 MRH 판독 신뢰도·Esc 잔차로)
```

- **크기.** 3D patchify 인코더(32³×4ch → 4³ 패치 → 512 토큰, 약 3M) + 입력 카메라 토큰 + 3상태 임베딩 = 24 → **28M**.
- **연산(교정: NC-M8).** 시퀀스 약 880 → 1,390 토큰. 600만 샘플 × 1,390 = 8.34×10⁹ 토큰. 6 × 28×10⁶ × 8.34×10⁹ = **1.40×10¹⁸ FLOPs**. v2.1 실효(2.8–4.4×10¹⁶ FLOPs/T4-h)로 **32–50 T4-h**다.
- **데이터 규모.** 8.34×10⁹ 토큰은 28M의 Chinchilla 점(5.6×10⁸)의 약 15배다. 과잉 학습 구간이라 데이터가 병목이 아니다. OOG 20%는 총량 안에서 혼합만 바꾼다.
- **개방 어휘.** 사용자 명사구 TE 임베딩의 800 클래스 최근접 코사인이 0.5 미만이면 `freeform` 슬롯이다. 학습에서는 클래스 라벨의 10%를 `freeform`으로 가려 이 경로를 배운다.
- **비회귀.** 집합 디퓨전이고 픽셀 캔버스가 없다. 전역 1-pass bedrock 예외 안이다. 입력 lift는 y(관측)다.
- **게이트(X-MFL, 개정).** RHC 홀드아웃 관측 일치 IoU ≥0.9, 입력 시점 재렌더 깊이 AbsRel ≤0.08. 프레임 밖 레이아웃 사람 선호: **문법 안** 무조건 MassingFM 대비 ≥60%, **OOG** "텍스트만" 대비 ≥55%. 벤치 후보 풀 문법 커버리지 ≥90%(D45).
- **BRP도 같은 절차를 쓴다.** 64³ 부분 관측 = 입력 frustum 카빙. 지형·자연은 Warp GPU ProcGen 20만에서 시점을 뽑는다. 원경 셸의 지형 높이장을 BRP가 낸다.

## 4. 데이터 주조소 v3: "우리 세계의 한 장"

### 4.1 원칙 v3

> **"기하는 코드에서, 외형은 교사에서, 라벨은 구성에서. 입력은 우리 세계의 한 장에서. 사용자의 이미지는 데이터로 들어오지 않는다."**

- 한 샘플은 여섯 겹이다: (절차·센서 GT 기하) ⊗ (엔진 교사 photoreal 외형) ⊗ (교사 내부 특징) ⊗ (결정 곡선 대역 마스크) ⊗ **(입력 시점과 θ_look·열화·에셔·스타일 교란 파라미터)** ⊗ (계보 태그).
- 다섯 번째 겹이 I2V의 핵심이다. 우리는 정답 세계를 갖고 있으므로 **입력 한 장과 그 입력이 숨긴 모든 것의 정답**을 동시에 만든다. 경쟁자는 인터넷 비디오에서 학습 모델로 포즈·깊이를 추정해 이 쌍을 근사한다(SpatialVID, Lyra 2.0 계열). 우리 라벨은 구성상 정확하다.
- 주조소는 `BLOCK_TRAIN` 없이 돈다. 사용자 업로드가 아무리 쌓여도 데이터 자산은 한 바이트도 그 계보를 갖지 않는다.
- **[개정] 교란 분포는 사전 등록한다.** 사용자 분포에 맞추지 않는다. 물리 범위와 자체·CC0·오픈 dev 데이터에서 정한다(CT-M15).
- **[개정] 생성기 역할을 나눈다.** 학습 Z·klein·G3, dev 평가 G3b, 벤치 전용 G4·G5(CT-M11).

### 4.2 I2V 학습쌍

**(a) 합성 쌍 (엔진 트랙 세계, D0 + D2-T).**

```text
I2VPair = {
  input   : Degrade_d( Escher_e( Style_s( Look_θ( Render(W, c0) ) ) ) )   # 각 교란은 사전 등록 분포에서 확률적으로 켠다
            # Look_θ = 렌즈·센서·필름(틸트·만곡 포함) ⊕ 비물리 증강(10%) ; Style_s ∈ {운송, NPR(L2a)}
  labels  : θ_look, 비물리 성분 맵, NPR 파라미터, c0(내부·외부), d·e·s 파라미터,
            @c0의 depth/normal/albedo/shading/sem(GT), 에셔 샘플이면 영역별 국소 깊이(CT-M14),
            MRH.obs 정답 마스크(d와 θ의 전달함수), 정답 세계 W(Merkle 루트),
            새 시점 R(W, c_k), 궤적별 IR_geo·IR_info(c, c0), 3상태 점유 32³/64³(RHC)
  lineage : GT-proc | solver-W*(gen k) | teacher-transport(t, 대역) ..., BLOCK_TRAIN ∩ taint = ∅, HOLDOUT 여부
}
```

**(b) 실사 쌍 (자체 촬영, D0 + D1).** 오라클·MVS 장면 300–500개 × 장면당 사진 40–100장. 한 장을 입력으로, 나머지를 정답 새 시점으로 쓴다(COLMAP SIFT + GLOMAP 포즈, PatchMatch 깊이). 1.2–5만 쌍이 추가 촬영 없이 나온다. 진짜 렌즈·센서·ISP를 덮는 유일한 소스다. **평가에서 실사 쌍 비중 ≥30%** 규칙(R-M5). **[개정] 고해상 정답 쌍:** 45–61 MP 원본을 2K로 내린 입력과 원본 정답(X-SR, TexelFM 입력 부모 모드 평가).

**(c) I2V 자기 대국 왕복(Render-Lift-Rerender) [조합, 운용].**

```text
for W in EngineTrackLibrary (taint ∩ BLOCK_TRAIN = ∅ ∧ ¬HOLDOUT):
   c0 ← SampleInputCamera(W);  I ← Degrade(Look_θrand(Render(W, c0)))
   Ŵ ← I2V_Pipeline(I, text = CaptionComposer(W, 프레임 밖 힌트, p = 0.5))
   보고: 첫 프레임 지각 거리, 관측 대역 충실도(Ŵ vs W, R0), θ̂ 오차, r_look, Esc(정답 0),
         IR 등급별 발명 영역 DR·사람 표본 타당도, 레이아웃 차이(정보용), IR_info 대비 X-SR 지표
   큐:   실패 사례 → MassingFM·MRH 하드 네거티브. Ŵ의 발명 영역은 라벨로 쓰지 않는다(정답 W가 있다)
```

- 비용은 I2V 세계 솔브 1회(파이프라인 정본 안전 1.0 / 확장 1.6 T4-h)다. 90일에 20–40 세계 = 30–50 T4-h를 **세계 솔브 버킷**(벤치 정본 510, 자기 대국 40 포함)에서 쓴다.
- I2V의 회귀 테스트이자 플라이휠 측정기다. **[개정] 자기 대국만으로는 우리 렌더러 룩에 과적합한다(R-M5).** 주간 측정에 Failure Twin 회귀셋(§4.13)과 실사 쌍을 같이 돌린다.

### 4.4 열화·AI 아티팩트 라이브러리 (파라미터 0 + 교사 VAE + 자체 SR)

| 군 | 연산 | 파라미터 범위 | MRH.obs 라벨 |
|---|---|---|---|
| 압축 | JPEG(4:2:0, 이중 압축), WebP, AVIF | q 50–95 | 블록 양자화 전달함수 |
| 리샘플 체인 | bicubic/lanczos/area, SNS 상한(1080, 2048) 재압축 | 배율 0.25–2, 1–3회 | 컷오프 = 최저 배율의 Nyquist |
| 샤프닝 | unsharp mask | 반경 0.5–3 px, 양 0.3–1.5 | 헤일로 대역 = "관측 아님" |
| 센서·NR | Poisson-Gauss, 고전 NL-means·bilateral 번짐 | ISO 100–12800 | NR 컷오프 |
| 양자화 | 8-bit 그라디언트 밴딩 | — | — |
| **AI 코덱** | **교사 VAE 왕복**(Z 16ch, klein 32ch), 저 NFE 생성 질감 | f8 latent | latent Nyquist 위 = "관측 아님" |
| **AI 업스케일** [개정] | 자체 TexelFM 프리뷰 SR, 교사 SDEdit SR(σ 스냅 0.3), ×2–×4 | 원 해상도 1–2K | 원 Nyquist 위 = "관측 아님" |

| 비물리 [개정] | 깊이 무관 블러 맵, 영역 그레이딩, 신호 무관 그레인 | 사전 등록 범위 | 해당 영역 대역 = "관측 아님", 비물리 성분 맵 |

- AI 아티팩트를 따로 흉내 내지 않는다. **허용된 교사·우리 모델 자신의 경로로 진짜 생성 아티팩트를 만든다**(D2-T).
- 대부분은 학습 로더에서 실시간(CPU)으로 건다. GPU가 드는 것은 VAE 왕복 5만 장(3–8 T4-h)과 AI 업스케일 5천 장(2–3 T4-h)뿐이다.

### 4.5 에셔 합성 v2 [신규, 개정]

AI 이미지의 원근 거짓말을 우리 세계에 일부러 심는다. 정답(가장 가까운 일관 세계)은 원본 W다. **판독기 라벨은 영역 국소 깊이**다(CT-M14).

| # | 교란 | 방법 | 라벨 |
|---|---|---|---|
| 1 | 조각 원근 | MassingFM shell·평면 단위로 영역을 나누고 영역마다 다른 카메라(초점거리, 소실점)로 렌더해 합성 | 영역 맵, 영역별 카메라·깊이 |
| 2 | 층별 스케일 | 파사드 층마다 창 크기 ±10–30% | 위반 크기 |
| 3 | 끊긴 위상 | 계단·난간 메시를 자르고 어긋나게 붙임 | 끊긴 위치 |
| 4 | 크기 거짓말 | 물체 크기를 크기 사전 밖으로(×0.5–2). 5%는 **저술된 스케일**(×2–5, 주 피사체, 플래그) | 위반 물체, 저술 플래그 |
| 5 | 거짓 조명 | 물체마다 다른 광원 방향 | 물체별 광원(치트 라이트 학습·평가) |
| 6 | **휜 직선** [개정] | 직선 영역에 화면 0.3–2% 진폭 저주파 워프 | 워프장 |
| 7 | **반복 드리프트** [개정] | 창·타일 주기를 화면 가로질러 5–20% 변화 | 주기장 |
| 8 | **반사 불일치** [개정] | 거울·수면 반사를 다른 카메라로 렌더 | 반사 카메라 |
| 9 | **붙여넣은 원근** [개정] | 화각·수평선이 다른 물체 합성 | 물체별 카메라 |

- 2만 장을 9계열로 나눈다(렌더 1–2 T4-h + Realify 약 11 T4-h, 원 메모와 같다). 용도: Esc 보정(주입 크기 대 점수 Spearman ≥0.8, 계열별 보고), 화해 피팅 평가, MassingFM RHC 에셔 모드 10%(기하 6계열), MRH 기하 학습 5%(국소 진실), (조건부) MRH.esc.
- **합성만으로 보정하지 않는다 [개정].** X-ESC-H(실제 240장 사람 주석, Spearman ≥0.6)를 함께 통과해야 τ_c를 확정한다.
- 덤: "AI 이미지 원근 거짓말 탐지기" 쇼케이스의 정량 근거가 된다.

### 4.6 스타일 운송, NPR, 스타일 세계 (레벨 2, 개정)

- **스타일 운송 [조합].** 엔진 트랙 렌더를 그림체 캡션(애니 셀, 유화, 수채, 잉크, 3D 툰 × 변형)으로 엔진 교사 SDEdit한다. σ는 결정 곡선상 기하 대역이 보존되는 점으로 스냅한다. 기하 라벨은 그 대역 안에서 유효하다. 1만 장은 코어(MRH 그림체 판독 견고성), 4만 장은 L2 조건부(22 T4-h)다.
- **NPR 렌더 [파라미터 0].** 툰 램프, 윤곽선(깊이·법선 불연속), 해칭, 팔레트 양자화를 렌더러 모드로 만든다. 라벨(NPR 파라미터)은 정확하다. **[개정] L2a InverseNPR 학습용 2만(약 5 T4-h).**
- **스타일 세계 (O4 조건부, 또는 D20 옵션 프리미엄).** 재질 패스를 그림체 캡션 + 측량 모드로 돌려 표면 페이지 자체를 그림체로 만든 세계 20개. 여러 시점에서 렌더하면 **다시점 일관 그림체 쌍**이 나온다. Ref-Adapter 학습 데이터다(세계당 2 T4-h, 40 T4-h). O1/O2로 끝나면 L2 평가·데모 자산으로 돌린다.
- **의뢰 일러스트 [개정].** 작가 의뢰 20장(L2a 10, L2b 10, 평가·학습 사용권 서면, $1–3K). 선정·X-REF 입력이다. 학습에는 쓰지 않는다(평가 순도 유지).

### 4.13 Failure Twin 프로토콜 [개정, 운용]

- **목적.** 사용자 실패를 사용자 바이트 없이 고친다.

- **절차.** 주 1회 사람이 상위 실패 코드 k개를 고른다(우선순위). 각 코드에 대해 dev 풀(자체 촬영, CC0 dev 2,000, 학습 생성기 출력)을 판독 코드로 색인해 같은 코드의 입력 20장 이상을 찾는다. 모자라면 엔진 세계에 사전 등록 범위의 교란을 걸어 합성한다. 결과를 `TWIN(code)` 회귀셋에 넣는다.
- **금지.** USER·EXTGEN 바이트, 그 파생 분포(θ̂ 히스토그램 등)를 쌍둥이 생성 파라미터로 복사하는 것.
- **지표.** 코드별 회귀셋 실패율의 주간 추세. 4주 연속 개선이 없으면 해당 부품의 "실패하면" 업그레이드를 앞당긴다.

## 5. Phase 2 모델의 I2V 영향: 입력 이미지 + 사건

### 5.1 발상: 입력 이미지는 사건의 t₀ 단면이다

Phase 2의 입구는 "이미지 한 장 + 사건 텍스트"다("잔이 떨어진다", "그녀가 돌아본다"). I2V 세계는 t₀ 상태이고, 사건은 그 상태에서 굴러간다. 상상하지 않고 굴려 본다는 v2.1 원칙이 그대로 맞물린다.

| 새로 생기는 일 | 방법 | 종류 |
|---|---|---|
| t₀ 위치 | I2V 세계(MassingFM·BRP 완성 + 입력 lift) | 기존 |
| t₀ 속도 | **모션블러가 곧 속도계다.** 블러 커널 길이·방향 ÷ 셔터(θ̂_in) × 깊이 → 화면 속도와 3D 속도 성분. 블러가 없으면 정지 또는 EPD-S 사전분포. **[개정] r_look·비물리 플래그가 "그린 블러"를 지목하면 측정으로 쓰지 않고 EPD-S 사전분포로 떨어진다** | 고전(Blur-as-Measurement의 단일 사진판) |
| 사건 한가운데의 입력(물보라가 공중에 뜬 사진) | **양방향 사건 추론**: SMC 제약 "x(t₀) = lift 상태"(불확실성 가중)를 걸고 과거(t<t₀)와 미래를 함께 푼다 | 기존 SMC + 제약 |
| 인물의 t₀ 자세 | R-Kpt 2D + lift + 크기 사전 → MoPri-S 키프레임 마스크 | 기존 |
| 사용자 인물의 정체성 | **Avatar-Fit(맞추되 배우지 않는다)** | §5.3 |

### 5.3 캐릭터: Avatar-Fit (맞추되 배우지 않는다) [운용/조합]

사용자 사진 속 인물을 움직이려면 정체성을 지켜야 한다. 경쟁 I2V는 조건화로 지킨다. 우리는 identity LoRA를 쓸 수 없다(USER 학습 금지).

1. **형상.** MakeHuman(CC0) 체형 PCA + 얼굴 형상 계수를 입력 lift와 R-Kpt에 맞춰 **피팅**한다(TTO, 장면 파라미터).
2. **외관.** 관측된 피부·의상 텍스처는 입력 컷 견본으로 아바타 UV에 투영한다. 비스듬히 관측된 면의 고대역은 **거울 견본**(F-M8)으로 채운다. 미관측부(뒤통수, 반대편 얼굴)의 생성은 **Phase 2c부터**다(P1은 파이프라인 얼굴 봉투가 막는다). 2c에서는 엔진 교사 + Reference Ring(입력 얼굴·의상 견본)으로 채운다.
3. **표정·입.** Expr-S가 블렌드셰이프만 낸다. 정체성은 가중치가 아니라 **세계 W의 아바타 파라미터**에 산다.
4. **제한.** P1 얼굴 봉투(F2 ±30°, F3 ±15°)와 2c 일정은 그대로다. 미관측 얼굴 반쪽을 크게 드러내는 무브는 🔴로 분류하고 IR과 함께 표기한다.
