# BUC 하네스 헌법 v1 (15일 스프린트)

> 구현은 하위 모델이, 설계와 검사는 상위 모델이. 기계로 거를 수 있는 건 모델 토큰을 쓰지 않는다.

## 1. 계층과 역할

| 역할 | 모델 · effort | 언제 |
|---|---|---|
| 오케스트레이터 | Opus 5.5 (이 세션) | 교대조(shift) 가동, 막힌 작업 판단, 5시간 보고. 턴 수를 최소로 |
| 선택기·게이트 실행·커밋 | **Haiku 5.5** low | 명령 실행과 JSON 반환만. 판단하지 않는다 |
| 계약서 + 테스트 작성 | **Sonnet 5.5** high. 난이도·위험 ≥4 또는 Opus 구현 단위만 **Opus 5.5** medium | 구현 전에. 구현자와 다른 에이전트 |
| 구현 | 백로그의 `impl_model`(Sonnet 132 / Haiku 31 / Opus 4) | 계약서와 동결 테스트를 통과할 때까지 |
| 수리 1차 | **Sonnet 5.5** high | 게이트 실패 시 |
| 수리 2차 (승격) | **Opus 5.5** high | 1차 수리 후에도 실패 시. 1회 |
| 검토 | **Opus 5.5** low | 위험 ≥4 또는 원래 Fable 검토로 분류된 단위만. 1회 |
| 최후 심판 | **Fable 5.1** | 교대조에서는 쓰지 않는다. 임계 경로 단위가 막혔을 때 오케스트레이터가 직접, 하루 2회 이하 |

Opus·Fable 비중 목표: 에이전트 호출의 20% 이하, Fable 1% 이하.

## 2. 작업 흐름 (단위 하나)

```
선택(Haiku) → 계약서+테스트(Sonnet/Opus) → 테스트 해시 동결
  → 구현(하위) → 독립 게이트(Haiku가 gate.py 실행)
     ├ 실패 → 수리 Sonnet → 게이트 → 실패 → 수리 Opus → 게이트 → 실패 → blocked
     └ 통과 → (위험 ≥4) 검토 Opus → 수정 요청 시 Sonnet 수리 → 게이트
  → 배치 끝에 커밋(Haiku): update.py, 하트비트, persist.sh(비밀 검문소 포함)
```

## 3. 게이트 (`ops/harness/gate.py`)
- 동결 테스트 해시 일치 (구현자는 테스트를 바꿀 수 없다)
- 소유 경로 존재, 문법(py_compile), ruff 치명 규칙(E9, F63, F7, F82)
- pytest (`-m "not gpu"`, CPU에서 60초 안에 끝나는 결정론 테스트). GPU 테스트는 `@pytest.mark.gpu`로 표시하고 GPU 러너가 따로 돈다

## 4. 규칙
1. **소유 경로만 고친다.** 각 단위는 백로그의 `paths`, `tests/<id>/`, `ops/harness/contracts/<ID>.md`만 만든다. 의존성 추가가 필요하면 결과에 적는다(pyproject는 FND 단위만).
2. **테스트를 고쳐서 통과시키지 않는다.** 동결 해시가 지킨다. 테스트가 틀렸다고 판단되면 blocked로 보고한다.
3. **성공을 지어내지 않는다.** 독립 게이트 결과만 믿는다.
4. **계약서 우선.** 하류 단위는 상류의 계약서와 코드를 읽고 맞춘다. 이음매가 진짜 적이다.
5. **비밀 금지.** 키·토큰을 파일·로그·커밋에 쓰지 않는다. 레포는 공개다.
6. **사양 출처:** `work/wf5/r-inventory.md`(단위 설명, ID로 grep), `docs/PARADIGM-v2.md`, `work/wf3/lens/*.upg.md`(I2V v3 설계), `work/wf3/inputs/07-founder-decision-i2v.md`.

## 5. 안전장치
- **GPU 데드맨 스위치:** GPU 서버는 `ops/gpu/heartbeat.json`이 2.5시간 넘게 갱신되지 않으면 스스로 정지한다. 오케스트레이터가 사용량 한도로 멈춰도 미터기가 새지 않는다.
- **교대조 크기 제한:** 한 교대조는 배치 4개(최대 8단위). 끝나면 오케스트레이터가 다음 교대조를 띄운다.
- **멈춘 작업 복구:** 교대조 시작 시 `doing` 상태로 남은 단위를 `todo`로 되돌린다.
- **보고:** 5시간마다(창업자 질문 시 즉시). 보고가 일을 잡아먹지 않게 한다.
