# TCH-01 교사 로더 v0 — Z-Image-Turbo BF16 · TE encode-only 캐시 · VAE 코덱 · 결정론 모드

**목적.** 엔진 교사(Z-Image-Turbo, 동결)를 한 곳에서 안전하게 적재한다. 가중치는 오프라인 HF 캐시(RUN-05 prefetch)에서만 읽고, 정밀도는 BF16으로 고정하며, Qwen3-4B 텍스트 인코더는 **세계당 1회 인코딩 후 캐시하고 해제**한다. 이후 TCH-02(샘플러)·TCH-03(탭)·TCH-04(원장)·INV-06·DAT-10·MDL-01이 이 객체를 받아 쓴다.
**소유.** `buc/teacher/zimage.py`, 테스트 `tests/tch_01/`(동결). 의존: RUN-05(`HF_HOME` 캐시 레이아웃), FND-03(`buc.core.det`: `wnf`, `hash_parts`, `hash_array`, `merkle_root_keyed`, `enable_determinism`). import는 CUDA·diffusers·transformers·huggingface_hub 없이 되고 부작용이 없다(전부 지연 import).
**소유 밖 요청.** 없음(`gpu` extra에 diffusers·transformers가 이미 있다). `buc/teacher/__init__.py`는 없어도 namespace로 동작.

## 공개 API (`buc.teacher.zimage`)
- 예외: `TeacherError(RuntimeError)` ⊃ `TeacherDependencyError(+ImportError)`, `TeacherSpecError(+ValueError)`, `TeacherWeightsMissing(+FileNotFoundError)`, `TEUnloadedError`, `TeacherNumericError(+FloatingPointError)`.
- `ZIMAGE_REPO="Tongyi-MAI/Z-Image-Turbo"`, `OFFICIAL_REPOS=frozenset({ZIMAGE_REPO})`, `REQUIRED_SUBDIRS=("transformer","vae","text_encoder","tokenizer")`.
- `@dataclass(frozen=True) TeacherSpec(repo=ZIMAGE_REPO, revision=None, num_layers=30, hidden_dim=3840, latent_channels=16, vae_scale=8, patch_size=2, text_dim=2560, max_text_len=512, unofficial_ok=False)`.
  `validate()`: repo가 `OFFICIAL_REPOS`가 아니고 `unofficial_ok`가 거짓이면(제3자 파생물 금지, PARADIGM §6.6) `TeacherSpecError`; 정수 필드 ≤0 또는 revision이 `[0-9A-Za-z._-]+`가 아니면 `TeacherSpecError`. `check_image_size(h,w)`: 둘 다 `vae_scale*patch_size`(16)의 양의 배수 아니면 `ValueError`. `latent_shape(h,w,batch=1)->(B,C,h/8,w/8)`.
- `hub_cache_dir(env=None)->Path`: 우선순위 `HF_HUB_CACHE` > `$HF_HOME/hub` > `$BUC_ROOT/hf/hub` > `/workspace/buc/hf/hub`. `snapshot_dir(spec, hub_cache=None, env=None)->Path`: `models--{org}--{name}/snapshots/{rev}`, rev = `spec.revision` 또는 `refs/main` 내용. 네트워크 접근 0. 폴더·`REQUIRED_SUBDIRS` 중 없는 것이 있으면 `TeacherWeightsMissing`(메시지에 없는 경로).
- `enable_determinism_mode(seed=None)->dict`: `det.enable_determinism(seed)` + TF32(matmul·cudnn) 끄기 + bf16/fp16 reduced-precision reduction 끄기. 반환 키 `seed, deterministic_algorithms, cudnn_deterministic, cudnn_benchmark, tf32_matmul, tf32_cudnn, bf16_reduced_precision_reduction, fp16_reduced_precision_reduction, cublas_workspace_config`(적용 후 실제 값). `seed=None`이면 RNG 상태 불변.
- `make_noise(seed, shape, *, level=0, k=0, dtype=torch.float32, device="cpu")->Tensor`: **정의** = `det.wnf(seed, level, arange(prod(shape),int64), k, channels=1, dtype=float32)[...,0].reshape(shape)` 후 `.to(dtype, device)`. 장치·전역 RNG·배치 크기와 무관(배치 앞부분 접두 불변). 범위 위반은 det의 `ValueError`, 차원 ≤0은 `ValueError`.
- `module_bytes(module)->int`(파라미터 numel×element_size). `module_fingerprint(module)->bytes(32)` = `merkle_root_keyed({f"{name}:{dtype}": hash_array(arr)})`, `state_dict()` 전체, bf16은 int16 비트 뷰로 해시. 딕셔너리 순서·인스턴스 동일성과 무관.
- `TextEmbedCache(encode_fn, *, namespace, max_len, text_dim=None, cache_dir=None, release_fn=None)`: `key(prompt)->str` = `det.hash_parts("buc.tch01.te.v1", namespace, max_len, prompt).hex()`. `encode(prompts, *, device=None, dtype=None)->list[Tensor[L_i,D]]`: 입력 순서대로, 중복·히트는 인코딩하지 않고 **미스만 중복 제거해 `encode_fn(list[str])`을 한 번** 호출. 반환은 항상 새 복사본(변경해도 캐시 무영향), `requires_grad=False`. `str`이 아니면 `TypeError`, 빈 리스트→`[]`. 인코더 출력의 개수 불일치·2D 아님→`TeacherError`, 마지막 축≠`text_dim`→`TeacherSpecError`, 비유한→`TeacherNumericError`. `cache_dir`이면 `{key}.pt`에 원자적(tmp+replace)으로 저장하고, 다른 인스턴스·프로세스도 디스크에서 비트 동일하게 읽는다(깨진 파일은 미스). `unload()`(멱등): `release_fn`을 정확히 1회 호출, 이후 히트는 계속 제공하고 미스는 `encode_fn` 호출 없이 `TEUnloadedError`. `stats`={hits, disk_hits, misses, encode_calls}(호출당 고유 프롬프트 기준: 메모리 히트→hits, 디스크 히트→disk_hits, 인코딩→misses), `unloaded`.
- `VaeCodec(vae, *, scaling_factor, shift_factor=0.0, vae_scale=8, latent_channels=16)`(속성 `vae, scaling_factor, shift_factor`): `encode(x[B,3,H,W], *, out_dtype=float32)` = `(vae.encode(x).latent_dist.mode() - shift)*scale` (**`.sample()` 금지**, 결정론), `decode(z, *, clamp=True, out_dtype=float32)` = `vae.decode(z/scale + shift).sample`, clamp면 [-1,1]. 입력을 VAE 파라미터 dtype·장치로 캐스트, 출력 `requires_grad=False`. H,W가 8의 배수 아님·채널 불일치·ndim≠4·비유한 입력은 `ValueError`, 출력 비유한은 `TeacherNumericError`(검은 이미지 방지).
- `Loaders(tokenizer, text_encoder, transformer, vae, encode_prompts)` 콜러블 묶음: `tokenizer(path)`, `text_encoder(path, dtype)->nn.Module`(`config.hidden_size`), `transformer(path, dtype)->nn.Module`(`layers`: 길이 `num_layers`), `vae(path, dtype)->nn.Module`(`config.latent_channels/scaling_factor/shift_factor(None→0)`), `encode_prompts(tokenizer, te, prompts, max_len)->list[Tensor[L,text_dim]]`. `default_loaders()`: diffusers·transformers 지연 import, 없으면 `TeacherDependencyError`.
- `load_teacher(spec=None, *, device="cuda", dtype=torch.bfloat16, te_device="cpu", seed=None, deterministic=True, hub_cache=None, te_cache_dir=None, loaders=None, fingerprint=False, allow_fp16=False, env=None)->ZImageTeacher`. 순서: `spec.validate()` → dtype 정책(fp16은 `allow_fp16`이 아니면 `TeacherSpecError`, 수술은 TCH-09 몫) → `snapshot_dir` → (옵션) `enable_determinism_mode(seed)` → transformer·vae 적재. **TE·토크나이저는 첫 캐시 미스에서 지연 적재**(전부 캐시 적중이면 영영 안 읽는다). 로더가 돌려준 부동소수 파라미터 dtype ≠ `dtype`이면 `TeacherSpecError`(조용히 캐스트하지 않는다). `layers` 없음/길이 불일치, VAE `latent_channels` 불일치, TE `hidden_size`≠`text_dim`은 `TeacherSpecError`. 모든 모듈 `.eval()` + `requires_grad_(False)`. transformer·VAE는 `device`, TE는 `te_device`.
- `ZImageTeacher`: 속성 `spec, device, dtype, snapshot, transformer, layers, vae(VaeCodec), text(TextEmbedCache), determinism(dict|None: `deterministic=False`면 None), fingerprints(`fingerprint=True`면 {transformer, vae}→bytes(32), 아니면 None)`. 메서드 `encode_text(prompts)`(device·dtype 적용), `encode_image(x)`, `decode_latent(z, clamp=True)`, `make_noise(seed, batch, height, width, *, level=0, k=0)`(`spec.latent_shape`, float32, `device`), `release_text_encoder()`(=`text.unload()`; 해제 후 TE 모듈에 대한 강한 참조 0), `info()->dict`(JSON 직렬화 가능: repo, revision, dtype(`str(dtype)`), device(`str(device)`), snapshot, weights_bytes(= transformer + VAE `module_bytes`), te_unloaded, determinism, fingerprints(hex 또는 None)).

## 불변식
가중치 읽기에 네트워크 0 · 전부 BF16(기본)·동결·eval · 같은 입력의 `make_noise`/`encode_image`/캐시 임베딩은 비트 동일 · TE는 GPU 상주 안 함(기본 CPU, 인코딩 후 해제) · 제3자 파생 가중치 거부 · 검증 실패는 로더 호출/적재 전에 난다 · import 부작용 없음.

## 수용 기준
`tests/tch_01/` 전부 통과(CPU, 가짜 로더, <60 s): 스펙·경로 해석, 결정론 플래그, 노이즈 오라클·접두 불변·통계, 지문 오라클, TE 캐시(중복 제거·디스크 재사용·해제·약한 참조), VAE 스케일·왕복·NaN 거부, 적재 순서·dtype·동결·지연 TE·오프라인. `@pytest.mark.gpu`: 5090에서 실제 가중치 적재(BF16, <14 GB), VAE 왕복 PSNR, 캐시 적중.
