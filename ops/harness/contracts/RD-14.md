# RD-14 R10 관측 대역 지도 — 화소 풋프린트 φ_eff · l_obs 경/부분 · w(ν)·ν_obs · 관측 집합 O

**목적.** 입력이 어디서 어느 레벨까지 "진짜 정보"를 갖는지 숫자로 낸다(PARADIGM §2.10, 2단 소유). 경소유 `τ_l ≥ 2φ_eff`, 부분 소유 `φ_eff ≤ τ_l < 2φ_eff`(주파수별 신뢰 `w(ν)`), 텍셀 피치 `τ_l = 8·2^-l` m. 소유권 수학의 단일 출처: WLD-02·WLD-14가 이 모듈의 지도·집합만 본다.
**소유.** `buc/read/obs_map.py`, 테스트 `tests/rd_14/`(동결 `RD-14.tests.json`). numpy·scipy(`scipy.special.j1`)만, **torch·cv2·skimage·yaml 금지**, import 부작용·전역 RNG 변경 없음, 순수·결정론·입력 불변. `buc.world`는 import하지 않는다(아래 격자 상수는 `world/strata.py`와 같은 값을 복제하고 테스트가 대조). 의존: RD-01(`r_eff/r_in`→`r_ratio`, `jpeg.quality`), RD-08(`MetricScale.to_meters`, `sigma_s`). MRH.obs(MDL-05)는 **소프트**: 없으면 `None`.

## 규약·상수
`LEVEL_RANGE=(-8,24) H0_M=64.0 BLOCK_CELLS=16 OCT_HI=(.5,.25,.125,.0625) OCT_CENTER=OCT_HI/√2 NU_GRID_N=512 W_TRUST=0.5 NO_LEVEL=-128 OWN_INPUT=1 OWN_INPUT_PART=2 OWN_INPUT_REFL=3`(= `strata.OWNERS`). 셀 변 `cell_size_m(l)=64·2^-l`(정확), `texel_pitch_m=cell/8`, `block_extent_m=16·cell`. ν는 입력 화소 기준 cycles/px(0–0.5). 카메라 OpenCV, 화소 중심 정수 `(u,v)=(열,행)`, `X_w=(X_c−t)@R`(`geom.unproject_world`와 같다). 레벨 계산은 float64, 저장만 float32. 오류: `ObsMapError(ValueError)`; 잘못된 타입 `TypeError`(ndarray 아님·bool/complex dtype·`valid`가 bool 아님 등), 값·모양 `ValueError`. 검증은 계산 전에 끝낸다.

## 공개 API (`__all__`)
```python
footprint_m(depth_m, f_px, cos_theta=1.0)       # φ_in = z/(f·cosθ). z 비유한·≤0 → NaN(오류 아님). f≤0, cosθ∉(0,1] ValueError
jpeg_band_factor(quality|None) -> float          # None 또는 ≥90 → 1, 아니면 min(4, 2^((90-q)/40)). q∉[1,100] ValueError (v0 휴리스틱, 미보정)
effective_footprint(phi_in, *, r_ratio=1.0, coc_px=0.0, motion_px=0.0, q_jpeg=1.0, nu_cap=None)
    # φ_eff = φ_in·max(1, 1/r_ratio, c/1.5, m/1.5, q_jpeg, 0.5/nu_cap). NaN 전파, φ≤0 ValueError. r_ratio∈[1/16,1], c,m≥0, q_jpeg≥1, nu_cap∈(0,.5]
levels_from_footprint(phi_eff, *, part_extra=0.0) -> (hard, part)   # a=log2(4/φ); hard=⌊a+1e-9⌋, part=⌊a+1+extra+1e-9⌋, LEVEL_RANGE로 자름. part_extra∈[0,1]
owner_of_level(level, phi_eff, *, part_extra=0.0) -> uint8          # 1: τ≥2φ, 2: τ≥φ·2^-extra, 0 (동률은 소유, 상대 1e-9)
defocus_mtf(nu, coc_px) = |2J1(πcν)/(πcν)|;  motion_mtf(nu, length_px) = |sinc(Lν)|     # RD-04와 같다
NoiseModel(nsr_ref=0.01, nu_ref=0.25, alpha=2.0, jpeg_gain=0.04)    # frozen; .nsr(nu,q_jpeg)=(nsr_ref+jpeg_gain·(q-1))·(ν/ν_ref)^α
w_of_nu(nu, *, r_ratio, coc_px, motion_px, q_jpeg, noise=None)      # w=|H|²/(|H|²+NSR), H=defocus·motion; ν>0.5·r_ratio → 0 (r_eff 절단). ν∈[0,.5]
nu_obs_cutoff(*, r_ratio, coc_px, motion_px, q_jpeg, noise=None)    # min(0.5·r_ratio, w_smooth=0.5 의 첫 교차). 512점 격자+선형 보간. 방송, 스칼라면 float
mrh_nu_cap(mrh_obs (4,h,w) float∈[0,1], tau=0.5) -> (h,w)          # 옥타브 b 관측 ⇔ p_b>tau. 가장 낮은 대역(b=3)부터 연속 관측인 최소 b*: cap=0.5·2^-b* (전무 → 1/32)
ObsOpts(block_px=16, block_quantile=0.1, cos_min=0.1, part_extra=0.0, scale_margin_k=0.0, mrh_tau=0.5, noise=NoiseModel())

              valid=None, mrh_obs=None, sigma_log_s=0.0, opts=None) -> ObsMap
build_obs_set(obs_map, depth_m, K, R, t, *, k1=0.0, k2=0.0, levels=None, stride=1, kind="direct") -> ObsSet
```
## ObsMap (frozen, 배열은 새 것)
`size=(H,W)`; 화소 `valid(bool) phi_in phi_eff(f32, 무효 NaN) l_hard l_part(int16, 무효 NO_LEVEL) nu_obs(f32)`; 블록(`block_px`, 격자 ⌈H/bp⌉×⌈W/bp⌉) `blk_valid blk_l_hard blk_l_part(int16) blk_nu_obs(f32) blk_w(4,gh,gw) f32`; `r_ratio q_jpeg sigma_log_s l_sigma_octaves(=σ/ln2) used_mrh warnings`. 메서드 `owner_at(l)->uint8(H,W)`(1 `l≤l_hard`, 2 `l≤l_part`, 무효 0), `block_owner_at(l)`, `obs_levels()->(hard,part)`(유효 화소 중앙값, hard≥0, part=max(hard,·), 유효 없음 (0,0)), `to_obs_fields()->{"l_obs_hard","l_obs_part"}`(→ `contracts.Obs`), `to_meta()`(JSON `allow_nan=False`, 키 ⊇ size, block_px, valid_frac, r_ratio, q_jpeg, mrh, sigma_log_s, l_sigma_octaves, warnings).
**화소 규칙.** 유효 = 깊이 유한·>0 ∧ `valid`. `cosθ=|n·d̂|/‖n‖`(`d̂`=K로 만든 단위 시선, 법선은 카메라 좌표·부호/크기 무관, 유효 화소의 영벡터·비유한은 ValueError)를 `[cos_min,1]`로 자름, 법선 없으면 1. `f=(fx+fy)/2`. `φ_in=z/(f·cosθ)·exp(scale_margin_k·σ_log_s)`. `φ_eff`는 위 식(`nu_cap`=MRH 캡을 최근접 사상 `⌊(i+.5)·h/H⌋`로 올린 것). `c,m` 지도는 (H,W) 또는 스칼라. MRH는 **소유를 줄이기만** 한다(전부 관측이면 비트 동일). `nu_obs=min(nu_obs_cutoff(c,m,...), cap)`; `w_oct[b]=w_of_nu(OCT_CENTER[b],...)`이되 `OCT_CENTER[b]>cap`이면 0. 구현은 (c,m)을 1/64 px로 양자화한 고유 쌍만 평가해도 된다(허용 오차: ν_obs `max(3e-3, 3%)`, w 0.02).
**블록 규칙.** 유효 화소 값 오름차순 `v_(0..n-1)`에서 `v_(⌊q(n-1)⌋)`(l_hard·l_part·ν_obs), `blk_w`는 유효 화소 평균, 유효 없는 블록은 `blk_valid=False`, 레벨 NO_LEVEL, w 0.
**경고(정렬·중복 없음).** `no_valid_depth`, `scale_uncertain`(σ>0.35), `mrh_veto`(MRH 캡이 고전 ν_obs보다 낮춘 화소 있음).

## ObsSet (O)
`levels`(정렬 int 튜플, 기본 `range(0, max l_part+1)`, 명시 시 중복·LEVEL_RANGE 밖 ValueError, 비정수 TypeError), `kind∈{"direct","refl"}`, `stride`, `blocks: dict[(l,i,j,k)->ObsBlock(hard,part: uint64[64])]`. 표본 = `obs_map.valid`인 `(stride·a, stride·b)` 화소, 세계점 `geom.unproject_world(K,R,t,uv,z,k1,k2)`. 레벨 l의 표본은 `l≤l_part`일 때만 기여. 셀 `c=⌊X/cell_size_m(l)⌋`, 블록 `c//16`, 로컬 `c%16`, **비트 = x+16y+256z**(워드 `idx//64`, 비트 `idx%64`). 셀은 기여 표본이 **모두** `l≤l_hard`일 때만 hard, 아니면 part(hard∩part=∅; 빈 블록은 만들지 않는다). 메서드: `keys(l=None)`(정렬), `n_cells(l=None, state=None|"hard"|"part")`, `cell_state(points(N,3), l)->uint8`(0/1/2; 만들지 않은 레벨은 0), `block_own(key)`(direct: part 셀 있으면 INPUT_PART 아니면 INPUT; refl: INPUT_REFL; 없는 키 KeyError), `union(other)`(hard=a|b, part=(a|b)&~hard; kind·levels 다르면 ValueError), `digest()`(sha256 hex, 키 정렬), `to_meta()`.

## 불변식·수용 기준 (`tests/rd_14/`, CPU, <60 s 합)
PARADIGM 표(1K–8K, z=3 m, 60°) 레벨 10/11 · 11/12 · 12/13 · 13/14 정확 일치; 전수 탐색 오라클과 레벨 일치(무작위 3000점); `part=hard+1`; 동률 소유; 열화는 합이 아니라 최대; w·ν_obs 미세 격자 오라클(≤1e-3), ν_obs는 c·m에 단조 비증가; 블록 하위 분위수 정렬 규칙; MRH 거부권(소유 불증가, 전부 관측 시 비트 동일, 4 단·1 단 하락 정확); 스케일 여유; 정면 평면 O 손계산(셀 수·블록 키·비트); O 전수 오라클(stride, 왜곡, 무효 화소, 부분집합 성질); `strata.block_of` 키 일치; 결정론·입력 불변·전역 RNG 불변·torch 미로드; 720p 지도 <12 s.
