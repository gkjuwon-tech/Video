# TCH-08 참조 교사 슬롯 — klein 4B 로더 · Reference Ring / Ring-R · 교체형 슬롯

**목적.** L2b(매체 질감: 유화·수채·잉크·파스텔) 외관 단계의 참조 조건 사다리 `Ring-R(엔진 교사, 파라미터 0) → klein 참조 → Ref-Adapter → 2.5D 카드`(models.upg §1.5–1.7, CT-M2/CT-M12, pipeline.upg §4.3)의 부품. P1-확장, 15일 경로 밖.
**소유.** `buc/teacher/ref_slot.py`, 테스트 `tests/tch_08/`(동결). 의존: TCH-01(`zimage`: 예외, `snapshot_dir`, `make_noise`, `TextEmbedCache`, `VaeCodec`, `enable_determinism_mode`, `module_bytes`), TCH-02(`sample`: `SigmaTable`, `TeacherSampler`, `add_noise`, `SigmaError`), FND-03(`det.derive_seed`). import는 diffusers·CUDA 없이 되고 부작용이 없다. **소유 밖 요청: 없음.**
**[2차]/미확인.** klein 저장소 이름, VAE 32ch, TE 차원, 4스텝 σ 표, 변환기 호출 규약은 원문 미확인이라 기본값은 잠정이고 GPU 테스트가 확인한다. 라이선스 원문 확인 전까지 N 클래스(r-inventory 6항): **로더는 사람의 확인 플래그 + 스냅샷의 라이선스 원문을 둘 다 요구한다.**

## 공개 API (`buc.teacher.ref_slot`)
- 예외: `RefSlotError(TeacherError)` ⊃ `RefLicenseError(+PermissionError)`, `RefBudgetError(+ValueError)`.
- 상수: `KLEIN_REPO="black-forest-labs/FLUX.2-klein-4B"`(잠정), `KLEIN_OFFICIAL_REPOS=frozenset({KLEIN_REPO})`, `FORBIDDEN_REPO_MARKERS=("9b",)`, `KLEIN_MAX_REFS=4`, `REF_TOKEN_BUDGET=2304`(=768²/256: 512² 2장 또는 768² 1장), `RING_STRIP_PX=128`, `RING_CANVAS_HW=(1152,1024)`, `RINGR_K_BASE=1<<20`, `KLEIN_TABLE=SigmaTable.from_flow_shift(4,3.0,name="klein-4b-n4-provisional")`(=(1,0.9,0.75,0.5)).
- `@dataclass(frozen=True) KleinSpec(repo=KLEIN_REPO, revision=None, latent_channels=32, vae_scale=8, patch_size=2, text_dim=2560, max_text_len=512, license_verified=False, unofficial_ok=False)`. `validate()->self` 순서: repo 이름(소문자)에 금지 표지 → `TeacherSpecError`(unofficial_ok로도 못 푼다); 공식 아님∧¬unofficial_ok → `TeacherSpecError`; 정수 필드 ≤0·revision 형식 → `TeacherSpecError`; `license_verified` 거짓 → `RefLicenseError`. `check_image_size`, `latent_shape`는 TCH-01 `TeacherSpec`과 같은 의미(TCH-02 샘플러가 그대로 쓴다).
- `check_license(snapshot)->"Apache-2.0"`: `LICENSE|LICENSE.md|LICENSE.txt`가 있으면 "Apache License"와 "Version 2.0"을 모두 포함해야 하고, `README.md` YAML 머리말에 `license:`가 있으면 값이 `apache-2.0`(대소문자 무시)이어야 한다. 하나라도 어긋나거나 긍정 근거가 0이면 `RefLicenseError`.
- `ref_tokens(h,w)=(h//16)*(w//16)`. `check_ref_budget(sizes)->int`(총 토큰): 개수 >`KLEIN_MAX_REFS`, 변이 16의 양의 배수 아님, 총 토큰 >`REF_TOKEN_BUDGET`이면 `RefBudgetError`. 0장은 0.
- `KleinLoaders(tokenizer, text_encoder, transformer, vae, encode_prompts, forward)`: 앞 다섯은 TCH-01 `Loaders`와 같다. `forward(raw_transformer, x_list, t, cap_list, refs)`는 TCH-02 규약(`x_list[i]=[C,1,h,w]`, `t=1-σ`, 반환은 **-v** 원소의 list)에 참조 잠재 `refs: list[Tensor[C,h,w]]`를 더한 것. `default_klein_loaders()`는 지연 import, 없으면 `TeacherDependencyError`.
- `load_klein(spec=None, *, device="cuda", dtype=torch.bfloat16, te_device="cpu", seed=None, deterministic=True, hub_cache=None, te_cache_dir=None, loaders=None, allow_fp16=False, env=None)->KleinRefTeacher`. 순서: `spec.validate()`(파일시스템·로더 전) → dtype 정책(TCH-01과 동일) → `snapshot_dir`(TCH-01 레이아웃, `TeacherWeightsMissing`) → `check_license` → (옵션) 결정론 → transformer·vae 적재. VAE `latent_channels` 불일치, 부동소수 파라미터 dtype≠`dtype`은 `TeacherSpecError`. 전부 eval+동결. TE·토크나이저는 첫 캐시 미스에 지연 적재(TCH-01 `_LazyTE`와 같은 규칙), 캐시 namespace에 klein repo가 들어가 Z 캐시와 키가 겹치지 않는다.
- `KleinRefTeacher`: 속성 `spec, device, dtype, snapshot, license, raw_transformer, transformer, vae(VaeCodec), text(TextEmbedCache), refs(tuple)`. `transformer(x_list,t,cap_list,return_dict=False)->(list,)`는 `loaders.forward(raw, …, list(refs))`로 넘기는 래퍼라 `TeacherSampler(klein, table=KLEIN_TABLE)`가 그대로 돈다. `set_refs(latents|None)`: 각 `[C,h,w]`, C=latent_channels, 유한, 개수 ≤4(아니면 `RefBudgetError`/`ValueError`); 분리·`dtype`·`device`로 저장, None/[]은 비움. `encode_refs(images[3,h,w]…)->list[float32[C,h/8,w/8]]`: **VAE 호출 전에** `check_ref_budget`. `encode_text, encode_image, decode_latent, make_noise, release_text_encoder`는 TCH-01 의미. `to(device)->self`(transformer·VAE·refs 이동, `device` 갱신). `info()`(JSON): repo, revision, dtype, device, snapshot, license, weights_bytes, n_refs, te_unloaded.
- Ring: `compose_strip(swatches, *, strip_px=128, width=1024)->float32[3,strip_px,width]`: 1–4장, 슬롯 j = 열 `[j*width//n, (j+1)*width//n)`, 각 견본은 슬롯 크기로 bilinear(align_corners=False, antialias=False) 리사이즈, 크기가 이미 같으면 비트 복사. 견본 0장·5장 이상, 3채널 아님, 비유한, `strip_px`/`width`가 16의 양의 배수 아님은 `ValueError`. `ring_canvas(view[B,3,H,W]|[3,H,W], strip)->[B,3,s+H,W]`(띠는 위). `split_canvas(x, strip_rows)->(strip, body)`(축 -2). `strip_hook(ref_latent, strip_rows)->hook(x0,info)`: 새 텐서에 `[..., :strip_rows, :] = ref_latent`(배치 브로드캐스트), 입력 불변.
- `renoise_up(z, sigma_from, sigma_to, noise)= a·z + b·noise`, `a=(1-σt)/(1-σf)`, `b=√(σt²-(a·σf)²)`; `0<σf<σt≤1` 아니면 `SigmaError`. 문서의 VP식 재노이즈를 TCH-02 flow 규약으로 옮긴 것: `z=(1-σf)x+σf·ε`이면 결과는 `(1-σt)x+σt·ε'` 분포.
- `@dataclass(frozen=True) RingRConfig(resample_at=(3,), r=2)`: 생성 시 검증(인덱스 고유·≥1, `0≤r≤64`, 아니면 `ValueError`). `extra_nfe(start_index)=r·#{s∈resample_at : s>start_index}`.
- `ring_sample(sampler, x0, cond, *, ref_latent, strip_rows, sigma, seeds, ring_r=None, steps=None, level=0, k=0, observer=None)->RingResult(z, strip, body, calls, nfe, sigmas, start_index, table_key)`. **정의**(`s0=snap(σ).index`, `steps` 기본 `len(table)-s0`, 시드는 TCH-02 규칙): `x←x0`의 띠를 `ref_latent`로 → `z←add_noise(x,σ_s0,ε)`(ε는 `sdedit`과 같은 노이즈) → `s=s0..s0+steps-1`마다: `ring_r`이고 `s∈resample_at`이고 `s>s0`면 `j<r`마다 `η=teacher.make_noise(seed_i,1,8h,8w,level,k=k+RINGR_K_BASE+64s+j)`, `z←renoise_up(z,σ_s,σ_{s-1},η)`, `z←denoise(start=s-1, steps=1, x0_hook=strip_hook)`; 그다음 `z←denoise(start=s, steps=1, hook)`. `strip_rows`는 양의 짝수 `<h`, `ref_latent`는 `[C,strip_rows,w]` 또는 `[B,…]`(아니면 `ValueError`, 변환기 호출 전). `calls`=변환기 호출 수, `nfe`=forward σ 수, `sigmas`=forward마다의 σ, `strip,body=split_canvas(z,strip_rows)`.
- `choose_l2b_path(level, *, ring_r_green, klein_ok, adapter_ok)->str`: level ∉ {L1,L1.5,L2a,L2b} → `ValueError`; L2b가 아니면 `"none"`; 아니면 `"ring_r"`>`"klein_ref"`>`"ref_adapter"`>`"cards_2_5d"` 순 첫 가능.
- `RefSlot(resident, ref_factory, *, device, park_device="cpu", mover=None)`: 카드당 상주 교사 하나(CT-M2). `state∈{"resident","ref"}`, `ref`(지연), `stats={loads,swaps_in,swaps_out}`. `swap_in()->ref`: 상주를 park로 **먼저** 옮긴 뒤 ref(첫 회 `ref_factory()` 1회)를 device로; 이미 ref면 `RefSlotError`; 도중 예외면 상주를 복구하고 다시 던진다. `swap_out()`: 역순, resident 상태면 `RefSlotError`. `use()` 컨텍스트(예외에도 복구). `close()`: ref면 swap_out 후 ref 해제(다음 swap_in은 재적재). 기본 mover는 `obj.to(device)`.

## 불변식
라이선스 플래그·원문 없이는 가중치를 읽지 않는다 · 9B 등 비상업 변형 거부 · 한 장치에 교사 둘이 동시에 있지 않다 · Ring 띠는 입력 견본에서만 온다(비회귀 조항 2), 표 끝까지 가면 띠 잠재 = `ref_latent` 비트 동일 · 뷰 i 결과는 배치 구성과 무관(lockstep) · 같은 입력 → 비트 동일 · `ring_r=None`이면 `sampler.sdedit(띠 덮은 x0, …, x0_hook=strip_hook).z`와 비트 동일 · Ring-R NFE = steps + extra_nfe(기본 8→10).
