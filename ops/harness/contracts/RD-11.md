# RD-11 에셔 점수: 7성분 + r_dis + r_refl (파라미터 0 잔차 합)

**목적.** 입력이 3D로 성립하지 않는 정도(파이프라인 §2.9.2)를 `Esc = Σ_c w_c·min(1, r_c/τ_c) ∈ [0,1]`로 계산한다. 학습·적합 없음. 상류 판독(RD-02/07/08/10)이 낸 잔차를 표의 τ·w로 묶을 뿐이고, 메뉴 등급(안전/확장/풀)의 근거가 된다. 잔차를 못 재면 **0으로 두고 "측정 못 함"으로 표시**한다(모르는 것을 위반으로 세지 않는다. Esc는 하한이 된다).
**소유.** `buc/read/escher_score.py`, 테스트 `tests/rd_11/`(동결). numpy·표준 라이브러리만(import 시 torch·scipy·yaml 미로드; 텐서는 `.detach().cpu().numpy()` 덕 타이핑), 순수·결정론·입력 불변·전역 RNG 불변. 상류 모듈은 import하지 않는다(덕 타이핑). 소유 밖 요청: 없음.

## 상수 (정확히 이 값)
`COMPONENTS=("vp","multi_vp","size","plane","light","topo","reconcile","r_dis","r_refl")`
`WEIGHTS = {vp .20, multi_vp .15, size .15, plane .05, light .15, topo .10, reconcile .05, r_dis .10, r_refl .05}` (합 1)
`TAU = {vp 2.0°, multi_vp 0.10, size 0.25, plane 0.05, light 15.0°, topo 2.0, reconcile 4.0 px@1080p, r_dis 0.05, r_refl 4.0 px@1080p}`
`GREEN_MAX=0.15, RED_MIN=0.35, CARDS_MIN=0.6, CHEAT_SHARE_MAX=0.35(=fit_lights와 같음), PX_REF_HEIGHT=1080`. `EscherError(ValueError)`.

## 규칙
1. **합.** 측정된 성분 c의 `x_c=min(1,r_c/(τ_c·scale))`, `contrib=w_eff·x`, `esc=Σcontrib`. 측정 못 한 성분은 `w_eff=0, r=None, x=0, contrib=0`. 입력을 바꾸지 않는다. 어느 r이든 커지면 esc는 줄지 않는다(단조). 전부 0이면 0, 전부 측정·포화면 정확히 1.
2. **반사 가중 이월.** `r_refl_px1080 is None`(반사 영역 없음)이면 `r_refl`의 w_eff=0, `vp`의 w_eff=0.20+0.05=0.25, `refl_redirected=True`. VP도 측정 못 했으면 이월분은 사라진다.
3. **빛.** `r_light(°) = light_sd_deg + 15·max(0, cheat_share-0.35)/0.35`. `light_sd_deg`·`cheat_share` 중 하나라도 있으면 측정됨(없는 쪽은 0).
4. **크기.** `fits`(RD-08 `ObsFit`)에서 `status=="used"`이고 `log_size_resid`가 있는 것만, 클래스(`name` 없으면 `cls`)별로 모은다. 저술·미지 클래스 제외. 개수 ≥ `min_group`인 클래스의 `1.4826·MAD(log_size_resid)`가 클래스 SD, 성분 r은 클래스 중 **최대**. 해당 클래스가 없으면 `sd=None`(측정 못 함).
5. **평면.** `log_depth`(RD-07, 스케일 전용 게이지, (H,W)|(1,1,H,W))의 영역(`plane_labels` int ≥0, 음수=평면 아님, bool/float 라벨 TypeError, 모양 불일치 ValueError)마다 `w=1/exp(log_depth)`를 화소 좌표(열, 행)의 아핀으로 최소제곱 적합(핀홀에서 평면의 역깊이는 아핀). 화소별 `rel=|w-ŵ|/max(|ŵ|,1e-3·median(w))`(=상대 깊이 오차). 화소 수 `<min_pixels`인 영역은 무시, `rel`은 남은 영역 전체 화소의 **중앙값**, 없으면 None. `log_depth`에 상수를 더해도 불변.
6. **빛 방향 SD.** `R=‖Σ w·û‖/Σw`, `sd=degrees(√(-2 ln R))`, 상한 180°, 단서 <2개(빈 배열 포함)면 0. 영벡터·비유한·모양 불일치·음수 가중치는 EscherError. `light_cue_dirs(fit)`: `status=="ok"`이면 **첫** 동기 광원(키 하나)의 방향 + `fit.priors` 중 `source=="shadow"`의 방향(`status=="fallback_bake"`면 사전만).
7. **px@1080p.** `px_at_1080p(px,H)=px·1080/H`; `rms_px1080(d,H)`=`√mean(|d|²)·1080/H`(`d`는 (N,)|(N,2), 빈 배열·비유한·높이 ≤0·음수 px는 EscherError). `light_residual_deg`는 sd≥0, share∈[0,1] 아니면 EscherError.
8. **어댑터.** `geom`: `r_vp_deg`(nan→None), `orphan_frac`. `mrh`: `r_dis`; `plane_labels`가 있으면 `mrh.outputs["log_depth"]`로 `plane_residual`(mrh 없이, 또는 `log_depth` 없이 라벨만 주면 EscherError). `scale`(RD-08): `size_residual(scale.fits).sd`. `lights`(RD-10): `cheat_share`와 `light_cue_dirs(lights)+light_dirs`의 SD. `topo_count`, `ffg_px1080`(RD-12 이후), `refl_px1080`은 그대로.

## 수용 기준 (`tests/rd_11/`, CPU, <60 s)
표(w·τ) 정확값과 합 1; 손계산 오라클(시나리오 3종: 깨끗/반쯤/에셔); 성분별 선형·포화·단일 성분 한계(=w); 단조성 무작위 스윕; 반사 이월·측정 못 한 성분·`with_reconcile`; 띠 경계(0.15/0.35 양끝, `nextafter`)·메뉴·카드 폴백(>0.6); 계산기 오라클(크기 MAD, 정확한 평면 1e-9·곡면·꺾인 면·잡음 중앙값·게이지 불변, 원형 SD 닫힌형); 검증 오류; RD-07/08/10/02 필드 이음매(실제 dataclass 필드 존재, 실제 `estimate_metric_scale`·`DirectionPrior`·`fit_lights`로 어댑터); torch/scipy/yaml 미로드·전역 RNG 불변·결정론·`to_meta` JSON.
