# RD-18 R13 경계 분해 v0 — 깊이 불연속 trimap · Levin 닫힌형 매팅 · 전경/배경 색 분리

**목적.** 실루엣 혼합 화소(F-P5 고무 시트)를 풀어 낸다: 깊이 불연속(상대 점프 >10%)의 ±3 px 띠와 가는 구조 마스크로 trimap을 만들고, Levin 닫힌형 매팅으로 α를, 평활 최소제곱으로 전경색 F·배경색 B를 푼다. `I = αF + (1−α)B`. 매팅은 I(와 깊이)만의 함수(원천)이며 화면 공간 합성이 아니다(pipeline.upg §2.12).
**소유.** `buc/read/edge_unmix.py`, 테스트 `tests/rd_18/`(동결 `RD-18.tests.json`). **의존.** numpy·scipy(`ndimage`, `sparse`, `sparse.linalg`)만. **torch import 금지**, import 부작용·전역 RNG 변경 없음, 입력 배열 불변, 결정론(같은 입력 → 비트 동일). RD-01 `image_lin`·RD-07/RD-08 깊이는 값으로 받을 뿐 import하지 않는다. 소유 밖 요청: 없음.

## 상수·예외
`BG=0, UNKNOWN=128, FG=255`(trimap uint8 코드). `EdgeUnmixError(ValueError)`.
`UnmixConfig(frozen, kw_only)`: `rel_jump=0.10`(>0), `band_px=3`(int ≥1), `eps=1e-7`(>0), `win_r=1`(int ≥1), `ridge=1e-9`(>0), `gamma=0.1`(>0), `delta=1e-6`(>0), `clip_tau=0.2`, `recon_tau=0.02`(≥0). 위반은 생성 시 `ValueError`.

## 공개 API (배열은 numpy; 실수 아닌 dtype `TypeError`, 모양·비유한·범위 위반 `ValueError`)
- `depth_edges(depth (H,W), *, rel_jump=0.10) -> (near bool, far bool)`: 유효(유한·>0) 4-이웃 쌍 (p,q) 중 `|z_p−z_q| > rel_jump·min(z_p,z_q)`인 쌍마다 작은 z 쪽 `near`, 큰 z 쪽 `far`. 한 화소가 둘 다일 수 있다. 무효 화소는 쌍에 참여하지 않는다(NaN 허용).
- `upsample_depth(depth (h,w), hw=(H,W)) -> (z (H,W) float64, stride:int)`: `ceil(H/s)==h`이고 `ceil(W/s)==w`인 가장 작은 정수 s≥1을 찾아 `np.repeat`(두 축 s배) 뒤 `[:H,:W]` 크롭(최근접, 흐림 없음). 그런 s가 없으면 `ValueError`.
- `make_trimap(depth (H,W), *, rel_jump=0.10, band_px=3, thin=None) -> uint8 (H,W)`: `E = near|far`. 미지 띠 `U = binary_dilation(E, 한 변 2·band_px−1 정사각형)`(곧은 경계면 양쪽 band_px 화소씩, 폭 2·band_px) ∪ `thin`(bool (H,W), 아니면 TypeError/ValueError). U 밖은 `scipy.ndimage.distance_transform_edt(~E, return_indices=True)`의 최근접 E 화소가 `near`면 FG, 아니면 BG. E가 비면 U 밖 전부 FG.
- `matting_laplacian(image (H,W,3), *, eps=1e-7, win_r=1, centers=None) -> scipy.sparse.csr_matrix (HW,HW) float64`(행 우선 화소 번호): 창 w_k = 중심 k의 (2r+1)² 정사각형, 중심은 `r ≤ y < H−r, r ≤ x < W−r`만(그리고 `centers` bool 마스크가 주어지면 그 안만). n=(2r+1)², μ_k 창 평균, Σ_k = 창 공분산(1/n 정규화).
  `L_ij = Σ_{k: i,j∈w_k} [δ_ij − (1/n)(1 + (I_i−μ_k)ᵀ(Σ_k + (eps/n)·I₃)⁻¹(I_j−μ_k))]`. 대칭·PSD·`L·1 = 0`.
- `solve_alpha(image, trimap, *, eps=1e-7, win_r=1, ridge=1e-9) -> (alpha, alpha_raw)` float64 (H,W): 하드 제약. K = trimap≠UNKNOWN, b = (trimap==FG). `(L_UU + ridge·I) α_U = −L_UK b_K`, α_K = b_K **정확히**. L은 위 정의의 전체 라플라시안과 수치적으로 같아야 한다(창 중심을 `dilate(U, 2r+1 정사각형)`로 제한해도 결과는 같다). `alpha = clip(alpha_raw, 0, 1)`. trimap 코드가 {0,128,255} 밖이면 ValueError, 알려진 화소가 하나도 없으면 `EdgeUnmixError`, U가 비면 α=b.
- `solve_fg_bg(image, alpha, trimap, *, gamma=0.1, delta=1e-6) -> (fg, bg)` float64 (H,W,3), 채널별 같은 선형계. Ω = U ∪ (U의 4-이웃). 고정: FG 화소의 F = I, BG 화소의 B = I. 자유 변수: Ω∖FG의 F, Ω∖BG의 B. 다음 2차 에너지의 유일 최소점:
  `E = Σ_{x∈Ω} (α_x F_x + (1−α_x) B_x − I_x)² + gamma·Σ_{4-이웃 x,y∈Ω} [(F_x−F_y)² + (B_x−B_y)²] + delta·Σ_{자유 변수 v} (v − I_x)²`.
  Ω 밖: F = I(FG)·0(그 외), B = I(BG)·0(그 외). 마지막에 `max(·,0)`. alpha ∉ [0,1]·모양 불일치 ValueError.
- `edge_unmix(image_lin (H,W,3) ≥0 유한, depth (H,W) 또는 (ceil(H/s),ceil(W/s)), *, thin=None, cfg=None) -> UnmixResult`: 검증 → `upsample_depth` → `make_trimap` → `solve_alpha` → `solve_fg_bg`(clip된 α). 짧은 변 < 2·win_r+1 이면 ValueError.

`UnmixResult`(frozen): `alpha` f32 (H,W) ∈[0,1], `alpha_raw` f32, `fg` f32 (H,W,3) ≥0, `bg` f32 (H,W,3) ≥0, `trimap` uint8, `band` bool(=trimap==UNKNOWN), `edges` bool(=near|far), `thin` bool(None이면 전부 False), `depth_stride:int`, `n_unknown:int`, `band_frac`, `clip_frac`(= U에서 `alpha_raw<−0.05 또는 >1.05` 비율, U 비면 0), `recon_err`(= U에서 `|αF+(1−α)B − I|` 최대(f64로 계산), U 비면 0), `low_conf`(= `clip_frac>clip_tau or recon_err>recon_tau`), `meta()->dict`(텐서·배열 없음, `json.dumps(allow_nan=False)` 가능, 키 ⊇ n_unknown, band_frac, clip_frac, recon_err, low_conf, depth_stride, thin_frac, rel_jump, band_px, eps, win_r).

## 불변식
U 밖: α∈{0,1}이고 `αF+(1−α)B == I`(f32 입력이면 비트 동일). α가 창마다 색의 affine 함수이면 라플라시안 에너지 ≈0(color-line). 결정론·입력 불변·torch 미로드.

## 수용 기준 (`tests/rd_18/`, CPU <60 s)
trimap 정확 띠(곧은 경계 폭 6, 근/원 쪽 라벨, 10% 문턱 양쪽, NaN 무시, thin 합류, 에지 없음→전부 FG) · 깊이 업샘플 stride 2/4·잘못된 모양 · 라플라시안 = 조밀 오라클(1e-10)·대칭·L1=0·PSD·color-line 에너지 · solve_alpha = 전체-L 조밀 해(1e-6)·알려진 화소 정확 · F/B 에너지 정상점·상수 F/B 복원 · 종단: 부드러운 원판(α MAE ≤0.01, 최대 ≤0.05, F 오차 ≤0.01 vs 순진 할당 ≥0.05, 재구성 ≤2e-3), stride 4 깊이(α MAE ≤0.005), 몸통+털 가닥(thin 있음 α MAE ≤0.01, 없음 ≥0.3) · 좌우 대칭 등변 · 결정론·meta JSON·검증 · 512² 속도 <15 s.
**미검증:** 실사진(털·잎·철망) 품질과 halo 지수(X-EDGE, 눈 판정 V), 2K 5–15 s 실측, `thin`을 MRH sem에서 뽑는 규칙(가는 구조 클래스 라벨 털/잎/철망은 v0에서 bool 하나), 매팅 신뢰 판정(`low_conf`) 문턱의 타당성.
