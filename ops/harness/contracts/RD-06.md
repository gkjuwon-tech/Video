# RD-06 R4 톤·색 v0 — 4파라미터 필름 곡선 · WB · CDL · 룩 잔차 LUT 17³

**목적.** 입력의 톤·색 처리 `G`를 모형으로 두고 역추정(`estimate_tone_color`)하며, 역 `G⁻¹`로 "중립 룩 장면 선형" `L̂`을 낸다(ExplainAway의 𝒯⁻¹). 명제 L2: 곡선·CDL·LUT가 같으면 WB·EV의 선형 오귀속은 다시 찍을 때 정확히 상쇄된다(`forward(inverse(I).linear·r)==G(L·r)`). 남는 오차는 곡선 곡률 차뿐이고 `|log r|`에 따라 커진다.
**소유.** `buc/read/tone_color.py`, 테스트 `tests/rd_06/`(동결 `RD-06.tests.json`). 의존: RD-01(`image_lin` 입력), LNS-08 `chain.wb_gains`(WB 규약 그대로), LNS-04 `sensor_film`(LUT·로그 규약), FND-06 `color`. numpy·scipy만, **torch 금지**, import 부작용·전역 RNG 사용 없음, 결정론(RNG 없이 균등 격자 솎기), 입력 불변, 새 배열 반환.

## 모형 (모두 float64로 계산, 표시값 = sRGB 부호화)
`x=L·g(K,t)·2^ev`(g=`chain.wb_gains(wb_kelvin, wb_tint)`) → `y=clip(F(x),0,1)` → `c=srgb_enc(y)` → CDL(항등이면 생략)·`clip` → LUT17(없으면 생략)·`clip` → `D=srgb_dec(c)`.
**F(필름 곡선).** `p=0.18·(x/0.18)^slope`; `t=p(p+a)/(p+b)`, `a=0.02, b=a(1+2·toe)`(원점 기울기 `1/(1+2toe)`); `shoulder=0`이면 `y=min(t,white)`, 아니면 `y=t/(1+(t/white)^S)^(1/S)`, `S=1/shoulder`(로그 합산으로 오버플로 없이). 기본값은 `min(x,1)`(항등). 역: `t=y/(1-(y/W)^S)^(1/S)`(또는 `t=y`), `p=((t-a)+√((t-a)²+4bt))/2`, `x=0.18(p/0.18)^(1/slope)`; `y≥white(1-1e-3)`는 `clipped`이고 그 값으로 자른 하한을 돌려준다.
**CDL(표시 부호화 영역).** `v=max(c·slope+offset,0)^power`, `Y=v·(0.2126,0.7152,0.0722)`, `out=Y+sat(v-Y)`(클립 없음). 역: `v=Y_out+(out-Y_out)/sat`(휘도 보존), `c=(v^(1/power)-offset)/slope`; `v≤1e-6`인 채널이 있으면 `lost`.
**LUT17.** `(17,17,17,3)` 표시 부호화 입력→출력, 삼선형, 입력은 [0,1]로 클램프, 항등 = `sf.identity_lut(17)`. 역은 고정점 `x←clip(x-(LUT(x)-y))` 반복(항등 근처에서 수렴), 잔차 `<1e-5`이 아니면 `ok=False`.

`inverse`: `c_out=srgb_enc(D)` → LUT⁻¹ → CDL⁻¹ → `srgb_dec` → `F⁻¹` → `L̂=x/(g·2^ev)`(WB·EV 제거). `status` 비트: **CLIP_HI** 표시 채널 ≥1-1e-3 또는 곡선 `clipped`(`linear`는 하한); **CLIP_LO** CDL 또는 LUT가 있을 때 표시 채널 ≤1e-3, 또는 CDL `lost`(CDL·LUT가 없으면 0은 정확히 `x=0`으로 닫힌다); **LUT_LOST** `ok=False`. 소유(`status==0`) 화소는 `|L̂-L|≤2e-3·L+2e-4`. `forward(inverse(D).linear)`는 소유 화소에서 `D`와 1e-5 안.

## 추정 `estimate_tone_color` (R4, 방법 자유·목적식 고정)
`image_lin`(RD-01) `(H,W,3)` float32/64 유한 ≥0, H,W≥8(아니면 TypeError/ValueError). `k=max(1,⌈√(HW/max_samples)⌉)` 격자 솎기, `n_used=⌈H/k⌉⌈W/k⌉`. `clip_hi_frac`=한 채널이라도 부호화 ≥1-1e-3인 비율, `clip_lo_frac`=모든 채널 ≤1e-3인 비율. 미지수 `ev, wb_kelvin, wb_tint, toe, shoulder, slope, white`(CDL은 항등; `fit_sat`이면 `sat`만, 나머지 CDL·LUT는 추정 안 함 → `lut=None`)를 `G⁻¹` 뒤의 `L̂`에 대한 합으로 최소화: (1) 클립 안 된 화소 휘도의 log2 분위수(0.03–0.97)가 `N(log2 lum_median, lum_sigma_stops)`를 따를 것(앨베도 통계 prior), (2) 회색 세계: `mean ln(R̂/Ĝ)`, `mean ln(B̂/Ĝ)`≈0, (3) `priors.ev/wb_*`(MRH 헤드)에 시그마 가중 가우시안 prior(없으면 중립 0/6500/0), 곡선은 중립 근처 약한 prior. `sky`가 있으면 (1)의 위치 항을 끄고 모양만 쓰며 `mask` 화소의 `L̂` 휘도 중앙값(log2)을 `sky.luminance`에 맞춘다(절대 앵커). `fit_sat`이면 `L̂`의 `ln(R/G), ln(B/G)` 합동 표준편차가 `chroma_log_sigma`가 되도록 `sat`.
경고: `insufficient_pixels`(클립 안 된 점<64), `insufficient_dynamic_range`(5–95 % log2 휘도 폭<`min_range_stops`) → **추정하지 않고** prior(없으면 중립) 값과 항등 곡선, `reliable=False`, `fit_rms_stops=nan`; `clipped_dominant`(`clip_hi_frac>clip_dominant_frac`), `black_dominant`(`clip_lo_frac>…`), `poor_fit`(분위수 RMS>`poor_fit_stops`). `reliable = not warnings`.
**`fit_residual_lut`.** `source`(물리 θ̂로 다시 찍은 표시 선형)→`target`(관측) `(…,3)` 또는 `(N,3)`. 부호화 영역에서 잔차장 `R=LUT-항등`을 `J=(1/N)Σw̃‖tri_i·R-d_i‖²+smooth·(1/E)Σ_edge‖R_a-R_b‖²+ridge·(1/V)Σ‖R‖²`(`w̃=w/mean w`, `d=tgt_c-src_c`, E=14688, V=4913)의 유일해로 푼다(볼록; 관측 없는 셀은 항등으로 감쇠). `r_look`=부호화 영역 `‖lp(O-P)‖/‖lp(O)‖`(가우시안 σ=`sigma_frac·W`, 분모 ≈0이면 0.0).

## 수용 기준 (`tests/rd_06/`, CPU, 합계 <60 s)
공개 표면·검증(범위 경계, NaN, 타입)·불변성·torch 미로드·전역 RNG 불변; 곡선 오라클 일치(독립 구현)·단조·항등·피벗·역 왕복 1e-8; CDL 오라클·휘도 보존·역; LUT 아핀 정확·적합 복원(ΔE00 평균≤0.4)·희소 영역 감쇠·가중 불변·평활 단조·역 수렴; `forward/inverse` 왕복·소유 건전성·비트 의미; WB 규약이 `chain.apply_wb`와 같음; **L2: WB·EV 오귀속은 r∈{⅛,½,2,8}에서 오차 ≤2e-6, 곡선 오귀속은 `|log r|`에 단조 증가**; `bake_lut`가 `sf.apply_look`로 `srgb_enc(forward)`를 평균 3e-3·p99 1.5e-2 안으로 재현하고 항등은 `sf.make_lut("none")`과 같음; 합성 장면(앨베도 prior에 맞춘 로그정규, 알려진 `G`) 복원: 이득비 ≤0.10 stop, EV ±0.3, 곡선 −3…+1.5 stop 램프 ΔE00 평균≤2.5·최대≤5.0, 재조명(r=½,2) ΔE00≤2.5이고 항등 가정의 0.7배 이하; prior 당김·정보 없음/클립 경고; 하늘 앵커가 `mask` 휘도 레벨을 ±0.35 stop로 고정(앵커 없는 해는 >0.8 stop 틀림)하고 EV 오차를 절반 이하로; `fit_sat` ±0.15; 결정론·JSON; 1080p <10 s.
**미검증:** MRH EV·WB 헤드 품질, 실사에서 앨베도 prior의 타당성, CDL slope/offset/power·잔차 LUT의 단일 영상 식별성(L2로 상쇄되는 몫만 보장), 사람 눈 판정(V).
