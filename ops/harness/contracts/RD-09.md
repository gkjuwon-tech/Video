# RD-09 R7 내재 분해 v0 — Retinex 평활 + 기하 음영 사전 (알베도 A · 음영 S · 소유 L_d)

**목적.** 중립 룩 장면 선형 `L̂`(RD-06 `inverse(...).linear`)을 `L_d = A·S`(S는 무채색 스칼라 음영)로 가른다. **첫 프레임 외관은 L_d(입력 그대로)가 소유한다.** A는 `L_d/S`로 파생되고, 재조명·프레임 밖 팔레트에만 쓴다(분해 오차가 첫 프레임을 해치지 않는다). S는 RD-10 FitLights의 관측. R7↔R8을 `n_alt`번 교대한다(광원 ← S, S ← 광원).
**소유.** `buc/read/intrinsics.py`, 테스트 `tests/rd_09/`(동결 `RD-09.tests.json`). numpy·scipy만, **torch·yaml import 금지**(텐서는 `.detach().cpu().numpy()` 덕 타이핑), import 부작용·전역 RNG 없음, 결정론(같은 입력 → 비트 동일), 입력 불변, 새 배열 반환. 의존: RD-06(`inverse`의 `linear`·`status`), RD-07(`MrhReadout.outputs`의 `albedo`·`shading`·`normal`, H/4 격자 `[1,c,⌈H/4⌉,⌈W/4⌉]`). 법선 규약(FND-08): 카메라 좌표(OpenCV), 단위, 카메라를 향함(`n_z≤0`). 광원 방향 ω = 표면→광원 단위벡터.
**상수.** `Y_FLOOR=1e-6, S_MIN=1e-4, GEO_FLOOR=1e-3, NORMAL_MIN=0.5, MIN_LIGHT_PIXELS=16`. `IntrinsicsError(ValueError)`.

## 공개 API (배열 float32/64 ndarray 아니면 TypeError, 모양·비유한·범위 위반 ValueError)
- `IntrinsicsOpts(frozen, kw_only)`: `alpha=1.0, beta=0.1, gamma=1.0, eta=0.3, delta=0.1`(≥0), `tau_chroma=0.05, tau_normal=0.5, light_poor_rel=0.25`(>0), `n_alt=2`(int 1..5), `max_side=320`(int ≥8). bool·문자열 TypeError, numpy 스칼라 허용.
- `GeoLight(frozen, kw_only)`: `direction`(단위 3-튜플, |‖·‖−1|<1e-6), `intensity≥0`, `ambient≥0`; `to_meta()`. `LightFit(light, rms, n_used)`.
- `geometric_shading(normal (H,W,3), light, *, visibility=None) -> f64 (H,W)` = `ambient + intensity·vis·max(0, n·ω)`(n은 정규화하지 않는다, 영벡터면 ambient). `visibility∈[0,1]` (H,W).
- `fit_geo_light(normal, shading, *, weight=None, mask=None) -> LightFit`: 사용 화소 = `weight>0 ∧ ‖n‖≥NORMAL_MIN ∧ mask`, 개수 <16이면 `IntrinsicsError`. 법선은 단위로 되돌려 쓴다. 목적식 `Σ w (S − amb − k·max(0,n·ω))²`를 `ω∈S², amb,k≥0`에 대해 **전역 최소화**(방법 자유). `rms=√(Σ w r²/Σ w)`.
- `decompose(linear (H,W,3) ≥0, *, normal=None, shading_head=None, albedo_head=None, geo_shading=None, light=None, geo_weight=None, exclude=None, status=None, opts=None) -> IntrinsicsResult`. H,W≥4. `exclude` bool, `status` uint8(RD-06 `inverse.status`), `status≠0`은 제외. `light`와 `geo_shading` 동시 지정, `light`만 있고 `normal` 없음은 ValueError.
- `relight(result, *, light=None, geo_shading=None, normal=None, visibility=None, floor=GEO_FLOOR) -> f32 (H,W,3)`: `Ŝ_old=result.geo_shading`(없으면 `IntrinsicsError`), 정확히 하나만(light는 normal 필요), `floor>0`. `out = L_d · max(Ŝ_new,floor)/max(Ŝ_old,floor)`. 같은 조명이면 L_d(1e-6).
- `heads_from_readout(outputs, hw) -> {"albedo": (H,W,3)|None, "shading": (H,W)|None, "normal": (H,W,3)|None}` f64: 헤드 `[1,c,h,w]`를 torch `bilinear, align_corners=False`와 같이 `(H,W)`로 키우고 `normal`만 재정규화(‖·‖≤1e-6이면 0). 없는 키 None, 다른 키 무시, 랭크·배치 위반 ValueError.

`IntrinsicsResult(frozen)`: `L_d` f32(입력의 float32 복사, 비트 동일), `albedo` f32 `=L_d/shading`(제한 없음), `shading` f32 (H,W) >0, `valid` bool(=¬제외), `geo_shading` f32|None, `light` GeoLight|None, `geo_source∈{"none","light_fit","light","geo_shading"}`, `r_intr`(float|nan), `n_solves`, `solve_stride`, `warnings`(정렬·중복 없는 tuple), `opts`; `reliable = not warnings`; `meta()`(JSON `allow_nan=False`, nan→None, 키 ⊇ light, geo_source, r_intr, n_solves, solve_stride, n_valid, excluded_frac, warnings, reliable, opts).

## 풀이 (유일해, 방법 자유)
`s=ln S`, `l=ln max(Y,Y_FLOOR)`(Y=L_d·(.2126,.7152,.0722)). 유효 화소(제외 아님)의 4-이웃 간선 E와 화소 x에 대해
`E(s)=Σ_E[α ω_xy((l_x−l_y)−(s_x−s_y))² + β b_xy (s_x−s_y)²] + Σ_x[γ g_x(s_x−ŝ_x)² + η(s_x−s^H_x)² + 3δ(s_x−s^A_x)²]`.
`ω_xy=exp(−(‖c_x−c_y‖/τ_c)²)`, `c=(R,G)/max(R+G+B,1e-6)`; `b_xy=exp(−(‖n_x−n_y‖/τ_n)²)`(법선 없으면 1); `ŝ=ln max(Ŝ_geo,S_MIN)`; `s^H=ln max(head,S_MIN)`; `s^A=mean_c[ln max(I_c,Y_FLOOR)−ln max(A_c,Y_FLOOR)]`. 항은 원천이 있을 때만(γ항 `g_x`=geo_weight, `light` 경로에서는 `‖n_x‖≥NORMAL_MIN`도 곱). 제외 화소는 그래프·사전에서 빠진다. 각 연결 성분의 사전 가중 합이 0이면 `IntrinsicsError`; 사전 원천이 하나도 없으면 `IntrinsicsError`.
**기하 음영 원천.** `geo_shading` > `light`(고정) > 광원 적합. 적합 경로(`normal`+`shading_head` 또는 `albedo_head`): `S_0`=shading_head, 없으면 `Y(L_d)/max(Y(albedo_head),1e-3)`; `k=1..n_alt`: `light_k=fit_geo_light(normal,S_{k−1},weight=geo_weight,mask=¬제외)` → 풀이 → `S_k`. 고정 경로는 풀이 1회(`n_solves=1`). 기하 원천이 없으면 경고 `no_geometry`(`geo_source="none"`, `r_intr=nan`).
**제외 폴백.** 제외 화소 S = `max(Ŝ_geo,S_MIN)` > `max(head,S_MIN)` > `exp(s^A)` 순(전해상도에서 덮어쓴다).
**스트라이드.** `f=⌈max(H,W)/max_side⌉`. `[::f,::f]` 점 표본으로 풀고(모든 입력 동일), `ln S`를 표본 좌표 `(y/f,x/f)`에서 쌍선형 보간(끝은 마지막 표본으로 고정). L_d·A는 전해상도.
**r_intr** = 유효 화소에서 `√mean((ln S − ln max(Ŝ_geo,S_MIN))²)`(기하 없으면 nan; 기하가 모르는 음영의 크기 → PCI `−r_intr`).
**경고.** `no_geometry`; `light_fit_poor`(첫 적합 `rms > light_poor_rel·(S_0의 geo_weight 가중 평균, 사용 화소)`); `excluded_dominant`(제외 비율 >0.5).

## 불변식
`L_d` 비트 소유; `albedo·shading=L_d`(상대 5e-6); 해는 위 E의 최소점(독립 오라클 기울기 ≈0); 좌우·상하 반전 등변; 알베도 사전만 있으면 영상 c배 → S가 정확히 c배; `alpha=0`이면 영상 무관; 제외 화소의 영상·사전 값은 나머지 해에 영향 없음; 색도가 변하는 곳에서는 음영이 안 움직이고(휘도만 변하면 일부 흡수 — Retinex 한계), 법선이 갈리는 곳에서는 평활이 풀린다.
