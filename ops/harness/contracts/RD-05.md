# RD-05 R3 광학 블러 추정 v0 — c(z) 강건 회귀 → z_f·N_eq, 모션블러 방향장

**목적.** 입력의 블러를 θ_in으로 설명한다(이중 보케 방지의 전제: 렌더는 같은 θ로 블러를 다시 만들므로, 입력 보케를 세계에 굽지 않는다). (1) MRH `defocus`(CoC 지름, 입력 px)와 미터 깊이(RD-08 `s·exp(log_depth)`)로 박막 렌즈 `c(z)=f²/(N(z_f−f))·|z−z_f|/z`를 강건 회귀해 `z_f`, FF 환산 `N_eq`를 낸다. (2) 영상에서 타일별 방향성 블러(방향·길이)를 추정하고 깊이와의 물리 일관성을 검사한다. 디컨볼브하지 않는다.
**소유.** `buc/read/blur_est.py`, 테스트 `tests/rd_05/`(동결). 의존: RD-07(`outputs["defocus"]`, `coverage`; torch `[1,1,h,w]` 또는 2D 배열), RD-08(`ms.s`, `ms.sigma_s`), RD-02(`g.K[0,0]`=f_px, `g.W`), LNS-02 `buc.lens.dof.coc_px`(같은 CoC 정의, 테스트 오라클). numpy·scipy 필수, torch는 입력 변환에만(import 시 torch 로드 금지). import 부작용·전역 RNG 변경 없음, 결정론(같은 입력 → `to_meta()` 비트 동일), 입력 불변.

## 좌표·단위
`u=1/z`(1/m, `z=+inf`→0). 모델 `c(u)=D·|u−u_f|`, `D=f²/N·(W/s)/(1−f·u_f)`(px·m). FF 환산: `f_ff=0.036·f_px/W`(m), `s=0.036`. 따라서 `N_eq = f_ff²·(W/0.036) / ((1−f_ff·u_f)·D)`, `z_f=1/u_f`(`u_f≤U_INF=1e-3`이면 `inf`, 경고 `focus_at_infinity`). 탐색 범위 `u_f∈[0, 1/(2f_ff)]`. 이 정의는 LNS-02 `coc_px(z, focal_mm=1000·f_ff, f_stop=N_eq, focus_m=z_f, sensor_width_mm=36, width_px=W)`와 정확히 같다.

## 공개 API
```python
U_INF = 1e-3; FF_SENSOR_MM = 36.0; HYPERFOCAL_COC_MM = 0.03
class BlurEstError(ValueError)
@dataclass(frozen=True, kw_only=True) BlurOpts:
    min_points=50; min_log_depth_span=0.1; pan_focus_px=1.0; default_n_eq=11.0
    inlier_abs_px=1.0; inlier_rel=0.25; min_inlier_frac=0.7; sigma_s_max=0.35; n_range=(1.0, 32.0); max_points=50_000
    tile_px=64; aniso_min=0.4; min_length_px=2.0; tau_motion=0.3; min_motion_tiles=4
    # 비유한·비양수·tile_px<16·n_range 역순은 ValueError
def estimate_defocus(coc_px, depth_m, *, f_px, width_px, weight=None, sigma_s=0.0, opts=None) -> DefocusFit
def estimate_motion_field(image, *, opts=None) -> MotionField
def motion_depth_consistency(length_px, depth_m, weight=None) -> tuple[float, float, float]   # (a, b, rel)
def read_blur(*, defocus, depth_m, f_px, width_px, image=None, weight=None, sigma_s=0.0, opts=None) -> BlurRead
```
**입력 검증(ValueError):** `coc_px`·`depth_m`·`weight`는 같은 2D 모양(torch `[1,1,h,w]`는 2D로 접는다), `coc≥0` 유한, `depth>0`(+inf 허용, NaN 금지), `weight≥0` 유한(None=1), `f_px>0` 유한, `width_px` 정수≥1(bool 금지), `sigma_s≥0` 유한.

**`DefocusFit`(frozen):** `status∈{"fit","pan_focus","insufficient"}`, `z_f_m: float|None`(inf 가능), `u_f: float|None`, `d_px_m: float`(D, fit 외 0.0), `n_eq: float`(fit 외 `default_n_eq`), `f_ff_mm`, `sigma_log_zf`, `sigma_log_n`(fit 외 None), `rel_resid`(`√Σw r²/√Σw c²`, fit 외 None), `inlier_frac`, `n_used`, `reliable`, `warnings`(정렬·중복 없는 tuple).
메서드: `coc_pred(depth_m, signed=False)->ndarray float64`(`D|u−u_f|`, 부호=`sign(z−z_f)`, fit 외 0), `residual(coc_px, depth_m)->ndarray`(`c−pred`), `theta_fields()->{"focal_mm","sensor_width_mm"=36.0,"f_stop"=clip(n_eq,0.7,64),"focus_m"}`(fit 외 focus는 과초점 `f²/(N·0.03mm)+f`), `to_meta()->dict`(`json.dumps(allow_nan=False)` 가능, inf→None; 키 ⊇ status,z_f_m,n_eq,f_ff_mm,d_px_m,u_f,sigma_log_zf,sigma_log_n,rel_resid,inlier_frac,n_used,reliable,warnings).

**절차.** `w>0`인 점만 쓴다(w=0 점의 값은 결과에 영향 없음). n<`min_points` → `insufficient`(+경고 `insufficient`). 가중 95백분위 c<`pan_focus_px` → `pan_focus`(+경고). 가중 log z의 5–95백분위 폭<`min_log_depth_span`(유한 깊이) → `insufficient`. 그 외 `Σw·ρ(c−D|u−u_f|)` 강건 최소화(재하강 IRLS 권장, 방법 자유, 전역 탐색으로 국소해 회피). `max_points` 초과 시 결정론 균등 솎기. inlier: `|r|≤max(inlier_abs_px, inlier_rel·pred)`, `inlier_frac`=가중 비율 → `<min_inlier_frac`이면 경고 `depth_inconsistent`(깊이를 따르지 않는 보케, F-M7·r_look 입력). 불확실도 `σ_log_zf=√(σ_stat_zf²+σ_s²)`, `σ_log_n=√(σ_stat_n²+σ_s²)`(스케일 k배 → z_f k배, N≈1/k배: 미니어처 신호). `σ_s>sigma_s_max` → `scale_unreliable`. N_eq∉n_range → `n_out_of_range`. `reliable = status=="fit" ∧ ¬depth_inconsistent ∧ ¬scale_unreliable`.

**`MotionField`(frozen):** 휘도(RGB면 0.2126/0.7152/0.0722) 타일 격자 `gh=H//tile_px, gw=W//tile_px`(나머지 버림, 0이면 ValueError). 배열 `theta[gh,gw]`(줄무늬 방향 rad ∈[0,π), +x(열)에서 +y(행, 아래)로; 무늬 없는 타일은 NaN), `length_px[gh,gw]`(전체 선분 길이, 모션 아니면 NaN), `anisotropy[gh,gw]∈[0,1]`, `is_motion[gh,gw]`(=aniso≥aniso_min ∧ length≥min_length_px), `tile_px`, `theta_global`(motion 타일의 aniso 가중 2θ 원형 평균, 없으면 None), `length_global`(motion 타일 length 중앙값|None), `frac_motion`. `to_meta()` JSON 가능.
**`motion_depth_consistency`**: 유한·양수 길이 점에서 가중 비음수 최소제곱 `L≈a+b/z`(a,b≥0; 회전=a, 병진=b), `rel=√(Σw r²/Σw)/max(Σw L/Σw,1e-6)`. 점<2이면 `(nan,nan,nan)`.
**`BlurRead`**: `defocus`, `motion|None`, `motion_consistency: tuple|None`(motion 타일≥min_motion_tiles일 때, 깊이는 타일 풋프린트에 비례 대응한 깊이 맵 블록의 중앙값), `warnings`(defocus 경고 ∪ `motion_nonphysical`(rel>tau_motion)), `to_meta()`(키 `defocus`,`motion`,`motion_consistency`,`warnings`).

## 수용 기준 (`tests/rd_05/`, CPU, <60 s)
LNS-02 `coc_px`로 만든 합성 c(z): 무잡음 → z_f·N_eq 상대오차 ≤1e-3; 5 % 곱 잡음 + 10 % 이상치 → z_f ±10 %, N_eq ±½ stop(`|2log2(N̂/N)|≤0.5`), 여러 (z_f, N) + 무한 초점 + 한쪽 깊이만; 전경 양귀비 장면(D15) 재렌더 CoC 일치; 스케일 k배 동변(z_f·D); w=0 무관·순열 불변; pan_focus·insufficient·depth_inconsistent·scale_unreliable 판정; σ 전파·잡음 단조; `theta_fields`↔`coc_px` 왕복; 검증 오류; JSON·결정론·입력 불변·torch 미로드. 모션: 선 커널 L∈{7..21}, 각 {0,30,90,135}° → 각 ±8°, 길이 ±max(1.5, 0.15L)(타일 ≥80 %, 중앙값); 등방 블러·평탄 → motion 아님; 일관성 함수 수식; `read_blur` 물리/비물리 판정.
**미검증:** MRH defocus 헤드 품질·단위(라벨=LNS-02 `aov["coc_px"]`라고 가정), 틸트·스윙·상면 만곡(v0 밖, `depth_inconsistent`로만 드러남), 실사 텍스처의 모션 길이, 셔터→속도(Phase 2).
