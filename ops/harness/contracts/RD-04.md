# RD-04 ExplainAway 연산자 v0 — 역사슬 · 그레인 Wiener · 광원 HDR · 고스트 보간 · 대역 마스크 · 대역 제한 Wiener

**목적.** "설명할 수 있는 것은 세계에 넣지 않는다"(명제 L3). 입력 `image_lin`에서 θ̂_in·RD-03 추정치로 설명되는 화면 고정 효과를 빼 Ĩ(WB 이전 중립 장면 선형)를 내고, 디포커스·모션블러·해상도 한계는 **디컨볼브하지 않고** 대역 마스크 `M_b`로 표시한다. 관측 대역(|H(ν)|≥0.5) 안에서만 Wiener 보정한다(그 위는 발명이다). 학습 파라미터 0, 결정론.
**소유.** `buc/read/explain_away.py`, 테스트 `tests/rd_04/`(동결 `RD-04.tests.json`). **의존.** LNS-08 `chain`(explain·invert_look·wb_gains·OWN_*), LNS-04 `sensor_film`, RD-03 `screen_fx` 데이터형, FND-02 `Theta`, FND-06 `color`. numpy·scipy만, **torch·cv2·skimage 금지**, import 부작용·전역 RNG 없음, 입력 불변, 새 배열.

## 공개 API (`__all__` 전부)
상수 `OCTAVES=4, OCTAVE_HI=(.5,.25,.125,.0625), H_MIN=0.5, BAND_TAPER=0.7, WIENER_K=0.01, COC_MIN_PX=0.5, GHOST_MIN_OCTAVE=3, R_RATIO_MIN=1/16, HDR_NEAR_SAT=0.97`, 소유 비트 `OWN_OK/SENSOR_BLACK/SENSOR_SAT/LUT_LOST/HALO_TAINT`(=LNS-08 0/1/2/4/8), `OWN_GHOST=16`, `OWN_HDR=32`.
```python

```
입력 규칙: `image_lin` ndarray float32/64 (H,W,3) 유한·비음수(비ndarray·다른 dtype `TypeError`, 모양·NaN/inf·음수 `ValueError`; 1 초과는 1로 자름). `theta`는 `Theta`, `screen_fx`는 `ScreenFx|None`(`size`≠(H,W)면 `ValueError`), `spec`·`opts` 타입 위반 `TypeError`. `coc_px/motion_len_px/length`: None | 실수 스칼라 | ndarray (H,W), 유한·비음수(bool·리스트·문자열 `TypeError`, 음수·NaN·모양 `ValueError`). `r_ratio`(RD-01 r_eff/r_in) 실수 ∈[1/16,1](비실수 `TypeError`, 범위 밖 `ValueError`). `shape`는 양의 정수 2-튜플.

## 대역 마스크
컷오프 `ν_c(x)=min(0.5·r_ratio, defocus_cutoff(c), motion_cutoff(L))`(저장은 f32, 판정은 f64). 옥타브 b(0=최고 대역)의 윗 가장자리 `OCTAVE_HI[b]≤ν_c(1+1e-9)`이면 `mask[b]`=True(관측). 따라서 `mask[b]⇒mask[b+1]`, `min_octave`=첫 True의 b(없으면 4). 모션은 마스크에만 쓰고 보정하지 않는다.

## 단계 (이 순서가 계약, 각 단계는 공개 함수와 동치)
1. `d_in=color.linear_to_display(clip(image_lin,0,1).astype(f32))`; `sigma_grain=mean_c grain.sigma_at(d_in_c)`(fx 없으면 0, `opts.grain`과 무관).
2. fx이고 `opts.grain`이면 `d=wiener_grain(d_in, fx.grain, nsr=opts.grain_nsr)`, 아니면 `d=d_in`. 이후 `e=chain.explain(d, theta, spec=spec)` → `linear, status, error_bound`. fx도 coc도 없으면 결과가 `e`와 **비트 동일**.
3. **HDR(H⁻¹)**: fx.halation.detected ∧ n_blobs>0 ∧ `a>0`(a=θ.halation>0 ? θ.halation : fx.halation.amount)일 때 `Y=min(halation.source_luminance(min(a,1)), HALO_SOURCE_MAX)`(노출 영역 휘도). `near=all_c invert_look(d_in, θ.lut)≥HDR_NEAR_SAT`의 4-연결 성분 중 각 블롭 중심(반올림) ±3 px 창에서 화소가 가장 많은 성분을 광원으로 보고, 합집합을 4-연결 십자로 1 px 침식한 영역에서 `u=linear·V·2^ev·wb_gains`를 `max(u_c, Y)`로 올려 `linear=u'/(V·2^ev·g)`. 어느 채널이 실제로 오른 화소에만 `OWN_HDR`(포화 하한을 낮추지 않는다; 중립 광원 가정).
4. **고스트(F⁻¹)**: fx이고 `opts.ghost`이고 반점이 있으면 `m=fx.ghost.mask(H,W)`; m 안 `linear`를 m 밖 화소로 저대역 보간(방법 자유), `status|=OWN_GHOST`(m과 정확히 일치).
5. **대역 Wiener**: `coc_px` 있고 `opts.defocus`이면 `linear=wiener_band(linear, coc_px, k=opts.wiener_k, h_min=opts.h_min, valid=(status==0))`.
6. `error_bound=+inf` where `status≠0`(그 밖은 chain 값: **체인 한계만**, 그레인 잔차·블러 보정은 포함하지 않음 — 잔차는 `sigma_grain`·`band`가 나른다). `band=observed_band(...,h_min=opts.h_min)`에 고스트 화소 강등: `mask[:GHOST_MIN_OCTAVE]=False`, `cutoff_nu≤OCTAVE_HI[GHOST_MIN_OCTAVE]`, `min_octave` 재계산.

## 필터 정의
**`wiener_band`**: 화소 c≥COC_MIN_PX에 대해 등방 주파수 이득 `G(ν)=1+t(ν/ν_c)·((1+K)H/(H²+K)−1)`, H=defocus_mtf, `t`=1(u≤0.7), `½(1+cos(π(u−0.7)/0.3))`(0.7<u<1), 0(u≥1). DC 이득 1, ν≥ν_c 이득 1(대역 밖은 건드리지 않음). c<COC_MIN_PX 화소와 `valid=False` 화소는 **비트 동일**(무효 화소는 필터 입력에서 이웃 평균으로 채워도 됨), 출력은 0 이상 f32. c 지도는 양자화·보간해도 되나 구역 안쪽에서 균일-c 필터와 5 % 이내. **`wiener_grain`**: 표시값 영역 채널별 신호 의존 잡음 σ(u)=`grain.sigma_at(u)`, 상관 반경 `radius_px`, 잡음 분산 배율 `nsr`인 에지 보존 Wiener(방법 자유). σ가 0이면 입력과 비트 동일.

## 불변식
1. 효과 없음 ⇒ `chain.explain`과 비트 동일(linear·status·error_bound). 2. status는 chain 비트를 지우지 않고 소유는 줄기만 하며 추가 비트는 GHOST/HDR뿐; `error_bound` 유한 ⇔ `status==0`. 3. Wiener는 비소유 화소를 바꾸지 않는다. 4. 같은 입력 → 같은 바이트, 전역 RNG·입력 불변. 5. 모션·`r_ratio`는 `linear`를 바꾸지 않는다.

## 수용 기준 (`tests/rd_04/`, CPU, <60 s, 동결)
표면·상수·검증·결정론·torch 미로드; MTF·컷오프 오라클(MTF(ν_c)=h_min ±1e-8)과 옥타브 규칙·min 결합; `wiener_band`가 순수 코사인에서 위 `G`와 ±0.03, 대역 밖 ±1 %, DC·백색잡음 RMS 이득(±8 %)·k 단조·무효/작은 c 비트 동일; 그레인: 평탄 RMS ≤0.45배·편향 ≤0.003·강한 에지 +1 px·격자 85 %·σ/nsr 단조·σ=0 항등, RD-03 실추정과 오차 0.45배 이하; HDR 복원(중앙값 ±2 %, ±0.5 EV 90 %, 비네팅·EV·WB 반영, 16 상한, 하한 비하강, 색 광원 제외); 고스트(걷힘 ≤진폭/3, 밖 비트 동일, 대역 강등); 체인 분해 동치·건전성(`owned ⇒ |linear−x|≤1.02·bound+2e-6`)·전 스택(비네팅 ±6 %, 대역 안 RMS ≤12 %, 광원 ±0.8 EV); 144×256 전 단계 <10 s.
