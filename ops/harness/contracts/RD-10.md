# RD-10 R8 FitLights + 치트 라이트 v0 — NNLS 세기 · CMA-ES 방향 · 그림자 에지 · CL1–CL6

**목적.** R7 음영 S(RD-09 `decompose().shading`)와 법선으로 입력의 빛을 `S ≈ a + Σ I_j·V_j·max(0,n·ω_j)`(a,I≥0)로 역적합한다. 먼저 **동기 광원 1개(키, 이름 `"key"`)**, 남은 잔차만 **치트 라이트**(CL1)가 설명한다. 못 설명하면 **폴백 = 복사휘도 굽기**(`status="fallback_bake"`, `geo_shading=None`; 하류는 L_d를 그대로 소유). 음의 광원·light linking 없음(CL2). 치트는 유령(CL3). 광원 ≤4, 플래그 ≤4, 치트 에너지 몫 ≤35 %는 넘으면 `r_light`를 적색으로 올려 **보고**(CL4; 막지는 않는다). 몫·개수·위치는 기록(CL6).
**소유.** `buc/read/fit_lights.py`, 테스트 `tests/rd_10/`(동결 `RD-10.tests.json`). numpy·scipy만, **torch·yaml import 금지**(텐서는 `.detach().cpu().numpy()` 덕 타이핑), `cma` 패키지 금지(CMA-ES는 직접 구현), import 부작용·전역 RNG 없음(지역 `np.random.default_rng(seed)`), 결정론(같은 입력 → 비트 동일), 입력 불변. RD-09 `GeoLight`는 `geo_light()` 안에서만 지연 import. RD-08 `MetricScale`은 덕 타이핑(`.interval(k)`, `.reliable`). 좌표: 카메라(OpenCV), 법선 카메라를 향함, ω=표면→광원 단위벡터, 위=−y. 모든 배열 float32/64 ndarray(아니면 TypeError; 모양·비유한·범위 위반 ValueError), 마스크는 bool.
**상수.** `MAX_CHEAT_LIGHTS=4, MAX_FLAGS=4, CHEAT_SHARE_MAX=0.35, SUN_ANGULAR_MAX=0.02, PRIOR_LAMBDA=0.01, NORMAL_MIN=0.5, MIN_PIXELS=16, CHEAT_ANGULAR_RADIUS=0.25, KEY_NAME="key"`. `FitLightsError(ValueError)`.

## 자료형 (frozen, kw_only는 표시)
- `FitLightsOpts`(kw_only): `popsize=16`(int≥4) `generations=30`(≥1) `max_cheat=4`(0..4) `min_gain=0.02`(>0) `resid_tau=0.02`(≥0) `r2_min=0.5`([0,1]) `n_coarse=512`(≥16) `seed=0`(≥0) `loss="l2"|"huber"`. bool·비정수 TypeError, 범위 ValueError, numpy 스칼라 허용.
- `Light`(kw_only): `name:str(비어 있지 않음) role:"motivated"|"cheat" kind:"sun"|"area"|"spot"|"bounce" direction:단위3-튜플(|‖·‖−1|<1e-6) intensity≥0(유한) angular_radius∈[0,π/2]=0`. 치트 `sun` 금지, `bounce`는 치트 전용(ValueError). 속성 `ghost == (role=="cheat")`(필드 아님). `to_meta()` 키: name, role, kind, direction, intensity, angular_radius, ghost, `cheat`(1/0), azimuth_deg, elevation_deg.
- `Flag(name, light, coverage)`: 차광판. `coverage` (H,W) [0,1], 읽기 전용 사본. 지명한 광원의 수송에만 `(1−coverage)`를 곱한다. `eq=False`.
- `DirectionPrior(direction, sigma_rad>0, source="user"|"shadow"|"probe")`; `ShadowEdge(shadow_point, occluder_point, weight=1)`(3-벡터, 길이>1e-9, weight>0).
- `IntensityFit(intensities(J,), ambient, rms, r2, nmse, n_used)`; `CmaResult(x, fun, n_evals, history: tuple)`; `EnergyReport(energies, ambient_energy, shares, cheat_share, n_cheat, n_flags, r_light, red)`; `LightHint(az_deg, el_deg, cause, distance_m, distance_rel, metric_reliable)`.
- `FitLightsResult`(eq=False): `status∈{"ok","fallback_bake"}, lights`(키 먼저, 이름 `key`,`cheat1..`; 세기 0인 치트는 버림), `ambient, flags, geo_shading`(f32 (H,W)|None), `r2, rms, nmse`(사용 화소 가중), `cheat_share, r_light, red, n_used, n_evals, warnings`(정렬·중복 없는 tuple), `priors, energies`(광원별), `opts`; `recommend_safe=red`, `reliable = status=="ok" ∧ ¬warnings`; `geo_light()`→RD-09 `GeoLight(키 방향·세기, ambient)` | None(폴백); `meta()`(JSON `allow_nan=False`, nan→None; 키 ⊇ status, motivated[], cheat[](각 `Light.to_meta()`+`energy_share`), probe[{direction,sigma_rad}], ambient, r2, rms, cheat_share, r_light, red, recommend_safe, n_used, n_evals, warnings, reliable).

## 공개 함수
- `transport(normal, direction, *, visibility=None)` → f64 (H,W) = `V·max(0,n·ω)`(n 정규화 안 함, V∈[0,1]). RD-09 `geometric_shading(ambient=0,intensity=1)`과 같다.
- `render_shading(lights, normal, *, ambient=0.0, visibility=None, flags=())` = `a + Σ I_j·T_j·Π_{플래그→j}(1−cov)`; `visibility`는 {이름→(H,W)}; 이름 중복·플래그>4·ambient<0 ValueError; 없는 광원을 지명한 플래그는 무시.
- `solve_intensities(T(J,H,W), shading, *, weight=None, ambient=True, loss="l2")`: `min Σ w (S−a−Σ I_j T_j)²`, `I,a≥0` (NNLS, 전역 최적). `huber`: 위 해에서 시작해 12회 IRLS(σ̂=1.4826·MAD(r), c=1.345σ̂, 가중 `w·min(1,c/|r|)`). `nmse=Σw r²/Σw(S−S̄_w)²`, `r2=1−nmse`(분산≤1e-12면 둘 다 nan), `rms=√(Σw r²/Σw)`는 원래 w·최종 해로 계산. 사용 화소(w>0) < 미지수면 `FitLightsError`.
- `cmaes_minimize(f, x0, sigma0, *, lower=None, upper=None, popsize=16, generations=30, seed=0)`: 표준 (μ/μ_w,λ)-CMA-ES, 후보는 경계로 클립한 값을 평가·갱신(스칼라 경계 방송), **평가 정확히 popsize×generations회**, `history`=세대별 최선값(비증가), `x,fun`=전체 최선. f가 비유한을 반환하면 `FitLightsError`.
- `find_shadow_edges(shading, normal, *, valid=None, grad_tau=0.15, normal_tau=0.1)`(두 임계 >0) → bool (H,W): 4-이웃 쌍 둘 다 유효, `|ln max(S,1e-4)| 차 > grad_tau` ∧ `‖n_x−n_y‖ < normal_tau`이면 두 화소 표시(음영 단차인데 기하 에지가 아니다 = 드리운 그림자).
- `shadow_direction_prior(edges, *, sigma_floor=0.02)` → `DirectionPrior(source="shadow")`: `u_i=unit(occluder−shadow)`, 방향=`unit(Σ w u)`, `sigma=max(floor, √(Σ w θ_i²/Σ w))`(θ_i=평균과의 각). 빈 목록·상쇄는 `FitLightsError`.
- `penumbra_angular_size(width, distance)=width/distance`(>0); `classify_source(θ_s)`=θ_s<0.02이면 `"sun"` 아니면 `"area"`.
- `direction_to_az_el(d)`→(방위°, 고도°): 고도=asin(−d_y), 방위=atan2(d_x,d_z)(정면 +z가 0, 오른쪽 +; 카메라 쪽은 ±180).
- `energy_report(lights, normal, *, ambient, weight=None, visibility=None, flags=())`: `E_j=Σw I_j T_j/Σw`, 몫=`E_j/(a+ΣE)`(합 0이면 0), `cheat_share`=치트 몫 합, **`r_light=max(cheat_share/0.35, n_cheat/4, n_flags/4)`, `red = r_light>1`**.
- `cheat_shadow_index(lights, normal, visibility, *, valid=None, vis_thresh=0.5)` = 유효 화소 중 어떤 **치트** 광원이 비추는 면(n·ω>0)인데 그 광원 `V<vis_thresh`인 비율(CL5; 가시성 맵 없는 광원은 0).
- `promote(light)`: 치트→동기(이름·종류·값 유지, 새 객체). 동기·`bounce`는 ValueError. `light_hint(light, *, source_size_m=(0.5,1.5), metric=None)`: `az/el`, `cause`(sun→sky_open, area→window_or_lamp, spot→lamp, bounce→reflector); `kind=="area"`이고 각반경>0이면 `distance_m=(lo,hi)/(2·angular_radius)`; `metric` 있으면 `(s_lo,s_hi)=metric.interval(2.0)`로 `distance_rel=(lo_m/s_hi, hi_m/s_lo)`, `metric_reliable=metric.reliable`. 크기 0<lo<hi 아니면 ValueError.
- `fit_lights(shading, normal, *, valid=None, weight=None, visibility=None, init_light=None, direction_priors=(), flags=(), penumbra=None, opts=None)`. `visibility`는 호출 가능 `(단위방향 (3,))→(H,W)∈[0,1]`(GPU 광선 대역; CPU 시험에서는 합성 함수. 모양 틀리면 ValueError). `init_light`는 `.direction` 객체(RD-09 `GeoLight`·`Light`). `penumbra=(폭,거리)`면 키 `kind=classify_source(θ_s)`, `angular_radius=θ_s/2`. 사용 화소 = `valid ∧ w>0 ∧ ‖n‖≥0.5`(법선은 단위로 되돌려 씀); 무효 화소의 S 값은 결과에 영향 없음.

## fit_lights 결과 기준 (방법은 자유; 참조 레시피: 피보나치 격자 n_coarse + 접선 2차원 CMA-ES, 비용=NMSE+PRIOR_LAMBDA·Σ(θ_i/σ_i)²)
1. **키**: 비용 최소 방향(격자 ∪ init_light ∪ 사전 방향에서 시작, 사전분포는 키에만 건다). 세기·ambient는 매 평가마다 NNLS. 잔차 NMSE<`resid_tau`면 치트 없음(잡음만 남으면 치트를 만들지 않는다).
2. **치트(CL1)**: 키 뒤에 하나씩 후보(`kind="area"`, `angular_radius=CHEAT_ANGULAR_RADIUS`)를 더하고 **모든 광원 방향을 좌표 교대로 정련**한 뒤, 사전분포 벌점을 뺀 NMSE 개선이 `min_gain` 이상일 때만 채택. 최대 `max_cheat`.
3. 폴백: 사용 화소<16 `few_pixels`, 분산 0 `degenerate_shading`, `r2<r2_min` 또는 키 세기 0 `low_r2`; 모두 `fallback_bake` 동반, 예외 아님(입력 형식 오류만 예외). `n_used`는 폴백에서도 채움.
4. 경고: `cheat_share_exceeded`(몫>0.35), `cheat_limit`(치트 수==max_cheat ∧ NMSE≥resid_tau), `flag_unused`(플래그가 지명한 광원이 없음). `geo_shading`=`render_shading(결과 광원, 가시성 적용, 플래그)`.

## 불변식
세기·ambient ≥0(음의 광원 없음); 영상 c배 → 세기 c배, 방향·R² 불변; 좌우 반전 등변; 같은 입력 비트 동일; 치트는 항상 `ghost`; `geo_shading`을 RD-09 `decompose(geo_shading=)`에 넘기면 `geo_source=="geo_shading"`.
