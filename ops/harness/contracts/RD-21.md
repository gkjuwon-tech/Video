# RD-21 판독 오케스트레이터·패킷 조립 v0 — R0–R13 순서 · 단계 캐시 · 단계별 폴백

**목적.** S-1 실물. `InputImage` 한 장에 판독 단계 R0–R13을 정해진 순서로 돌려 `ReadPacket`(FND-02)을 조립한다. 어떤 단계가 예외를 내거나 계약 밖 출력을 내도 **그 단계만** 고정 폴백값으로 바꾸고 나머지는 계속 돈다. 폴백은 `packet.fallbacks`에 남는다.
**소유.** `buc/read/pipeline.py`, 테스트 `tests/rd_21/`(동결). **의존.** FND-02 `contracts`, PRD-01 `spine.Impl`, RD-01 `ingest`, RD-02 `geom_cam`, RD-07 `mrh_call`(**지연 import**), RD-08 `metric_scale`. `import buc.read.pipeline`은 torch를 로드하지 않는다. 전역 RNG 불변, 입력 불변, 결정론.

## 공개 API
```python
PIPELINE_NAME="rd21_read"; PIPELINE_VERSION="0.1.0"
STEP_IDS=("R0","R1",…,"R13")                        # 14개
EXEC_ORDER=("R0","R1","R2","R4","R5","R6","R3","R7","R8","R9","R10","R11","R12","R13")  # R3는 R5·R6 뒤
CORE_STEPS=("R0","R1","R5","R6")
class StepOutputError(ValueError)                    # 출력 검증 실패(폴백 사유 이름)
@dataclass(frozen=True, kw_only=True) ReadOpts: cam_height_m=1.5; z_near_m=0.5; z_far_m=50.0
    default_sigma_s=1.5; depth_min_m=1e-3; sensor_width_mm=36.0     # 양의 유한, z_near≤z_far, 위반 ValueError
@dataclass(frozen=True) ReadStep(sid:str, name:str, version:str, fn, needs:tuple[str,...]=())
    # fn(state: ReadState, params: dict) -> dict.  sid∉STEP_IDS·빈 name/version·fn 비호출 → ValueError
class ReadState: image, H, W, opts; state[sid] -> 읽기 전용 Mapping (sid ∉ needs 이면 KeyError)
    status(sid) -> "ok"|"fallback"|"skipped"  (needs 안만; hit는 "ok")
@dataclass(frozen=True) StepRecord(sid, name|None, version|None, status∈{ok,hit,fallback,skipped}, key|None, error|None, wall_s)
@dataclass(frozen=True) ReadResult(packet: ReadPacket, records: tuple[StepRecord] (EXEC_ORDER, 14개), outputs: {sid: Mapping})
class MemoryReadCache: get(key)->dict|None; put(key, outputs); __len__     # put·get 모두 깊은 사본
def default_steps(*, reader=None, size_obs_fn=None) -> tuple[ReadStep,...]
def run_read(image, *, steps=None, params=None, cache=None, opts=None) -> ReadResult
def make_read_impl(*, steps=None, cache=None, opts=None) -> spine.Impl
    # Impl("S-1","real",PIPELINE_NAME, f"{PIPELINE_VERSION}+{content_hash({steps:[[sid,name,version] EXEC_ORDER], opts})[:12]}", fn); steps=None → default_steps()
def read_stage(inputs, ctx) -> {"read": ReadPacket}   # = make_read_impl().fn. params = ctx.params에서 "_seed" 뺀 것; 인자 위반은 예외(→스파인이 스텁 폴백)
def plane_depth(K, up_cam, H, W, *, cam_height_m, z_near_m, z_far_m) -> (H,W) float32
def upsample_grid(a (h,w), H, W) -> (H,W) float32                         # 쌍선형 align_corners=False (torch F.interpolate와 atol 1e-5)
```

## 실행 규칙
1. **검증 먼저**(어떤 fn도 부르기 전): image는 `InputImage`(아니면 TypeError); steps의 sid 중복·`needs`가 STEP_IDS 밖이거나 EXEC_ORDER상 자기 뒤·자기 자신 → ValueError; params는 `{sid: dict}`(sid∉STEP_IDS·값 비dict → ValueError, 비Mapping → TypeError).
2. EXEC_ORDER 순서로 등록 단계만 호출(미등록은 `skipped`). 단계는 `needs`의 출력만 본다. `fn`의 `Exception`(KeyError·읽기 전용 배열 쓰기 포함) 또는 출력 검증 실패 → 그 sid의 **고정 폴백값**, status `fallback`. `BaseException`(KeyboardInterrupt 등)은 전파.
3. **출력 스키마**(모든 단계 `meta`: `json.dumps(allow_nan=False)` 가능한 dict; 추가 키 허용):
   R0 `image_lin`(H,W,3) 유한 ≥0 → float32, `fov_x_prior_deg` None|(0,180). R1 `K`(3,3) 유한·fx,fy>0·마지막 행 [0,0,1]·`fx/W·sensor_width_mm`∈(1,2000], `k1,k2` 유한, `up_cam`(3,) 노름 0.99–1.01(정규화), `f_source`∈{vp3,vp2,prior,default}. R5 `log_depth`(h,w) 유한, `r_dis_map` 같은 모양 유한 ≥0. R6 `s`>0 유한, `sigma_s`≥0 유한, `reliable` bool. R11 `level`(있으면 LEVELS 안).
4. **폴백값**(skipped도 같은 값; meta=`{"status": "fallback"|"skipped"}`):
   R0 `image_lin` = PRD-03 `classic_read` 전달함수, `fov_x_prior_deg` = exif `focal_35mm`(양의 유한)이면 RD-01 `fov_x_prior_deg(f35,W,H)` 아니면 None.
   R1 `K=[[f,0,(W-1)/2],[0,f,(H-1)/2],[0,0,1]]`, `f=(W/2)/tan(fov/2)`, fov=R0의 `fov_x_prior_deg`(→`f_source="prior"`) 또는 `DEFAULT_FOV_X_DEG=50`(→`"default"`), `k1=k2=0`, `up_cam=(0,-1,0)`.
   R5 `log_depth=r_dis_map=None`. R6 `s=1, sigma_s=opts.default_sigma_s, reliable=False`. 그 밖 `{}`+meta.
5. **캐시**(`cache` 주어질 때): 단계 키 = `content_hash({pipeline 버전, sid, name, version, params[sid], opts, image.content_hash(), needs의 유효 키})`. 유효 키 = 성공 단계는 그 키, 폴백·skipped는 `(sid, status, image, opts, R1이면 R0 유효 키)`의 해시. hit이면 fn 0회(status `hit`). 성공(`ok`)만 put; 폴백은 캐시하지 않는다. 저장·반환 출력의 ndarray는 쓰기 금지 플래그.
6. **기본 단계**: R0 `ingest`(`ingest(pixels, color_space=None if unknown, prov, consent, opts=IngestOpts(letterbox=False, apply_orientation=False))`, fov는 결과값 또는 exif 규칙, 모양≠(H,W,3)이면 실패; params 없음). R1 `geom_cam`(needs R0; `estimate_geom_camera(image_lin, fov_prior_deg=…, opts=GeomCamOpts(**params))`, meta=`to_meta()`). R5 `mrh_call`(reader 있을 때만; reader에 비지 않은 str `cache_id` 없으면 ValueError; version `0.1.0+{cache_id}`; needs R0; `read_mrh(image_lin, reader, prov=image.prov, cfg=ReadConfig(**params, list→tuple))`; `log_depth=outputs["log_depth"][0,0]`, `r_dis_map`, meta=`meta()`+`"prov": ro.prov.to_dict()`). R6 `metric_scale`(needs R1,R5; version `0.1.0+{size_obs_fn.cache_id|none}`, cache_id 없는 fn은 ValueError; `estimate_metric_scale(list(size_obs_fn(state)) or [], sigma_log_f=SIGMA_LOG_F[f_source], opts=ScaleOpts(**params))`, meta=`to_meta()`).

## 패킷 조립
`input_hash=image.h_I`, `prov=image.prov`(그대로; RD-07의 `USER-DERIVED`는 FND-02 TAINT_BASES 밖이라 meta에만), `image_lin`=R0, `obs=Obs(K,R=I,t=0,W,H,k1,k2)`, `theta_in=Theta(aspect=W/H, focal_mm=fx/W·sensor, sensor_width_mm=sensor)`.
- R5 `ok/hit`: `depth = max(R6.s·exp(upsample(log_depth)), depth_min_m)`, `depth_conf=clip(1-upsample(r_dis_map),0,1)`, `scale_s=R6.s`, `sigma_s=R6.sigma_s`, `depth_source="mrh"`.
- 아니면: `depth=plane_depth(R1.K, R1.up_cam, …)`(지면 `up·X=-h`; d=K⁻¹[u,v,1], `-(up·d)>1e-9`이면 `clip(h/-(up·d), z_near, z_far)` 아니면 z_far), `depth_conf=0`, `scale_s=1`, `sigma_s=default_sigma_s`, `"plane"`.
- `level` = R11 `level` 또는 "L1"; `normals=None`, `esc={}`, `faces=()`, `lights={}`, `dyn={}`.
- `fallbacks` = EXEC_ORDER 순: 폴백 단계 `f"{sid}:{name}@{version}:{예외 타입명}"`(출력 검증은 `StepOutputError`), CORE_STEPS 중 skipped `f"{sid}:skipped"`.
- `meta = {"input": R0.meta, "read": {"pipeline": "rd21_read@0.1.0", "depth_source", "steps": {sid: {"impl": "name@version"|None, "status": ok|fallback|skipped}} (14개), "geom": R1.meta, "mrh": R5.meta, "scale": R6.meta, "extra": {그 밖 sid: meta}}}`. 시간·hit 여부는 패킷에 넣지 않는다.

## 불변식
패킷은 `check_stage_io("S-1")` 통과. 같은 입력·단계·params·opts → 패킷 `content_hash` 비트 동일(캐시 hit/miss 무관). 한 단계 실패가 다른 단계의 출력을 바꾸지 않는다(그 단계에 의존하는 단계 제외). 단계 실패로 `run_read`가 예외를 내지 않는다.

## 수용 기준
`tests/rd_21/` 전부(CPU, <60 s): 순서·needs 검증, 단계별 실패 격리와 폴백값 오라클(R0 스텁 일치, R1 K 공식, 평면 깊이 기하, R6), 출력 검증 폴백, 조립 수식(업샘플 torch 대조, 깊이·신뢰도), 캐시 hit·최소 재실행·폴백 미캐시·사본, 실제 R0/R1/R6 + 가짜 읽기기로 실제 `read_mrh`, 스파인 등록·hit·스텁 폴백, torch 미로드. GPU 테스트 없음.
