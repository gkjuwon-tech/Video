# RD-03 R2 화면 고정 효과 추정기 v0 — 비네팅 · 그레인 PSD · 횡색수차 · 할레이션 · 고스트

**목적.** 명제 L3: 비네팅·그레인·색수차·고스트·할레이션은 이미지 평면에 붙어 있어 세계에 구우면 카메라가 움직일 때 드러난다. RD-01 `image_lin` 한 장에서 이것들을 **고전 통계로 측정**해 θ 필드와 ExplainAway(RD-04) 입력으로 낸다. LNS-04 순방향의 역문제이며 학습 파라미터 0. 화면 저주파 이득 8×8과 룩 잔차 LUT는 범위 밖(RD-20이 TTO로 소유).
**소유.** `buc/read/screen_fx.py`, 테스트 `tests/rd_03/`(동결 `RD-03.tests.json`). **의존.** RD-01(입력·`crop_box`·JPEG 품질), LNS-04(상수·모델 정의), FND-06 `buc.core.color`. numpy·scipy만, **torch·cv2·skimage 금지**, import 부작용 없음, 전역 RNG 불변(난수 불사용), 순수·결정론(같은 입력 → `==`), 입력 불변. 결과는 모두 `frozen kw_only` 데이터클래스이고 배열 필드는 없다(튜플). 일반 영상에서 필드는 유한값(`rms_resid_*`만 정의 불가 시 nan 허용; `to_meta`는 nan→None).

## 입력·규약
`image_lin`: ndarray float32/float64 `(H,W,3)` 장면 선형(음수는 0 취급). 비ndarray·다른 dtype `TypeError`, 모양·비유한 `ValueError`, 짧은 변<32 `ScreenFxError(ValueError)`. `opts`는 `ScreenFxOpts|None`(아니면 `TypeError`). 짧은 변<64는 가능하지만 `small_image` 경고+`reliable=False`. 픽셀 중심 정수 좌표, 광학 중심 기본 `((W-1)/2,(H-1)/2)`, `r_norm`(비네팅 반경 척도) 기본 반대각선. **크롭 영상**이면 호출자가 `center=(cx-x0, cy-y0)`(크롭 좌표)와 `r_norm`(원 프레임 반대각선)을 준다. 상수는 LNS-04와 같다: `GRAIN_SIGMA_MAX=0.08, VIGNETTE_MAX_DROP=0.8, HALATION_THRESHOLD=0.8, HALATION_SIGMA_FRAC=0.02, HALATION_TINT=(1,.35,.12)`, LNS-08 `HALO_SOURCE_MAX=16`, 본 단위 `HALO_ASSUMED_SOURCE_Y=2.0`.

## 공개 API (`__all__` 전부)
```python
class ScreenFxError(ValueError)
@dataclass(frozen=True, kw_only=True) ScreenFxOpts: max_side=1024(>=64) block=16(8..64) sat_level=0.98((0.5,1]) min_blob_px=30(>=4) ghost_max=4(>=0)   # 위반·bool ValueError
estimate_vignette(image_lin, *, center=None, r_norm=None, opts=None) -> VignetteFit
estimate_grain(image_lin, *, jpeg_quality=None, opts=None) -> GrainFit      # jpeg_quality None|(0,100] 실수(bool·nan ValueError)
estimate_ca(image_lin, *, center=None, opts=None) -> CAFit
estimate_halation(image_lin, *, opts=None) -> HalationFit
estimate_ghost(image_lin, *, center=None, opts=None) -> GhostFit
estimate_screen_fx(image_lin, *, center=None, r_norm=None, jpeg_quality=None, opts=None) -> ScreenFx   # 위 다섯 개의 합. 각 필드 == 개별 호출 결과
identity_screen_fx(h, w) -> ScreenFx      # 효과 없음(강도 0, reliable=False). RD-21 폴백값
```
모든 Fit에 `warnings: tuple[str]`(정렬·중복 없음). 어휘: `small_image, few_flat_blocks, few_levels, jpeg_lossy, ca_no_color, no_saturation, neutral_halo, vignette_extrapolated`.

**VignetteFit** `coeffs(a2,a4,a6)`(a2≤0), `center, r_norm, shape(H,W), corner_ev=log2 V(1), strength=clip((1-V(1))/0.8,0,1)`(θ.vignette 동치), `rms_resid_ev, reliable, curve`; `gain_at(rho)`(ρ=r/r_norm 임의 모양 배열; **V(0)=1, 비증가, [0.05,1]**, ρ>1은 V(1)), `gain() -> (H,W) float32`(중심·r_norm 기준 `gain_at`).
**GrainFit** 표시값(sRGB 부호화) 영역: 화소 σ(u)=√(c²u(1-u)+n0²). `strength=clip(c/0.16,0,1)`(θ.grain 동치), `sigma_coef=c, floor_sigma=n0, floor_frac`(중앙 레벨에서 n0² 몫), `nonphysical=(floor_frac>0.5 and n0>0.004)`(신호 무관 잡음), `radius_px`(자기상관 exp(-d²/r²)의 r; 잡음 없으면 0.75), `channel_corr`(채널 간 상관 평균; 필름 그레인≈0), `n_flat_blocks, levels, sigma_by_level, psd_nu(0..0.5, 간격 1/block), psd`(실측 방사 PSD), `reliable`(평탄 블록≥24 ∧ 짧은 변≥64 ∧ ¬jpeg_lossy); `sigma_at(u)`, `psd_model(nu, u=0.5)=σ(u)²·πr²·exp(-π²r²ν²)`(평면 적분=σ²; RD-04 Wiener 입력).
**CAFit** 정의: 채널 내용이 중심에서 (1+eps)배 커져 보이면(바깥 이동 eps·r) eps>0, 녹색 기준. `eps_r, eps_b, center, r_corner`(중심~가장 먼 모서리), `shift_corner_px=(eps_r,eps_b)·r_corner, n_samples, rms_resid_px, reliable`(샘플≥200 ∧ 짧은 변≥64); `shift_px(r_px, 'r'|'b')=eps·r`(그 밖 채널 ValueError). 세 채널이 같으면 eps=0+`ca_no_color`.
**HalationFit** 모델 `층=amount·tint_c·G_σ*max(Y-0.8,0)`. 포화 연결성분(Y≥sat_level, 면적≥min_blob_px)=광원 `blobs(HaloBlob x,y,area_px)`, `n_blobs`. 광원 주변 비포화 화소에서 곱 **`halo_gain=P=amount·(Y_src-0.8)`**, `sigma_px, sigma_frac=σ/W`(0.02), `tint`(R=1 정규화, 측정값; 광원 없으면 사전)를 로버스트 회귀(σ 격자)로 맞춘다. `detected = P≥0.03 ∧ tint_g≤0.8 ∧ tint_b≤0.8`(적색 우세); P≥0.03인데 무채색이면 `neutral_halo`. 광원 없음 `no_saturation`. **식별성 한계**: P만 식별되고 amount와 광원 휘도는 분리되지 않는다 → `amount_min=P/(HALO_SOURCE_MAX-0.8)`(하한, detected일 때), `amount=min(1,P/(HALO_ASSUMED_SOURCE_Y-0.8))`(광원 휘도 2.0 가정; detected 아니면 0), `source_luminance(amount)=0.8+P/amount`(amount∈(0,1] 아니면 ValueError; 헤일로 에너지로 HDR 광원 역산). `reliable=detected`.
**GhostFit** 가장 큰 포화 광원 `source=(x,y)|None`, `center`, `ghosts: tuple[GhostSpot(x,y,radius_px,z,k)]`(z 내림차순, ≤ghost_max). 반점은 중심–광원 직선(수직 거리≤6 px) 위의 원형 DoG 블롭, 로버스트 z(MAD)≥6, 광원 근방 제외; `k`는 `p=c+k(s-c)`. `mask(h,w)->bool`은 반점 반경 1.25배 원판의 합(ValueError: h,w<1). 식별성 낮음: 질감 바탕의 거짓 반점은 허용 한계이며 RD-04는 부분 관측 강등만 한다.
**ScreenFx** `size, vignette, grain, ca, halation, ghost, warnings`(합집합), `reliable = vignette.reliable ∧ grain.reliable`; `theta_fields() -> {"vignette","grain","halation"}`(float [0,1]; `C.Theta(**tf, lut="none")` 가능); `to_meta()`(JSON 가능, 키 ⊇ size, vignette{strength,corner_ev,coeffs,center,r_norm,reliable}, grain{strength,radius_px,floor_sigma,nonphysical,channel_corr,reliable}, ca{eps_r,eps_b,shift_corner_px,reliable}, halation{detected,n_blobs,sigma_frac,tint,halo_gain,amount,amount_min,reliable}, ghost{n,source,spots}, warnings, reliable).

## 방법 요지 · 식별성
- **비네팅**: 휘도의 로그2를 (고리 0.05ρ × 12 섹터) 셀 중앙값으로 모아 `log2 V(ρ)`+상수를 로버스트(soft-L1) 최소제곱, a4·a6는 릿지(오캄), V 비증가 투영. 한계: **저주파 구조(경사·큰 물체)는 방사 이득과 구분되지 않는다.** 정상 질감에서 V(1) ±0.08, 약한 경사(≈0.7 EV)에서 V(1)≥0.8.
- **그레인**: 블록(16) 평면 제거 잔차의 σ/√(u(1-u))이 낮은 쪽(하위 25 %×1.3) 평탄 블록만 골라(포화·클립 블록 제외) 레벨 구간별 σ²를 `c²u(1-u)+n0²`에 NNLS. 반경은 잔차 자기상관 지연 1·2. 목표: 세기 ±20 %, 반경 ±25 %(상위 목표 ±20 %).
- **색수차**: 에지 창 국소 LS(`R≈aG+b+β∂_rG`, δ=-β/a)를 방사 거리에 비례 회귀(로버스트). 목표 ±0.3 px(시험 0.25).
- JPEG 품질<85는 `jpeg_lossy`로 신뢰만 낮추고 수치는 바꾸지 않는다. AI 업스케일이 PSD 꼬리를 채운 입력의 보정은 MRH.obs(RD-07/14) 몫.
