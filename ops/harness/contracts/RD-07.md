# RD-07 R5 독심 판독 호출 v0 — 전역 σ 2점 · 1024² 타일 · 가장자리 혼합 · r_dis · 클린룸 레인

**목적.** 입력 한 장(RD-01 `image_lin`, 또는 ExplainAway 통과본)을 엔진 교사 σ-스냅 forward로 통과시키고 탭을 MRH(MDL-03)에 넣어 H/4 조밀 판독을 낸다: 전역 뷰 σ 2점 + 1024² 타일(σ 0.25) → 타일을 전역 뷰에 affine 정렬해 혼합 → 판독 불일치 r_dis. ext 입력은 클린룸 레인 규칙(탭은 임시, 링 금지, 가중치 불변)을 지킨다.
**소유.** `buc/read/mrh_call.py`, 테스트 `tests/rd_07/`(동결). 의존: TCH-02 `TeacherSampler`·`SigmaTable`·`add_noise`, TCH-03 `TapBus`·`TapRing`·`TapSet`, MDL-03 `buc.models.mrh.heads.HEAD_NAMES`, RD-01(`image_lin`을 받을 뿐 import 안 함), FND-04 `buc.gov.prov`, FND-03 `det.derive_seed`, FND-06 `color.linear_to_display`. numpy·torch만. CUDA·diffusers 없이 import, import 부작용·전역 RNG 변경 없음. 소유 밖 요청: 없음.

## 상수·예외
`STRIDE=4, UNIT=16, TILE_PX=1024, GLOBAL_PIXELS=589_824(=1024·576), READ_LONG_MAX=3840, FEATHER_PX=64, GLOBAL_SIGMAS=(0.20,0.35), TILE_SIGMA=0.25, DEPTH_FLOOR=0.05, UNC_TAU=0.10, SURVEY_CAPTION, LANE_ENGINE="engine", LANE_CLEANROOM="cleanroom"`. `MrhCallError(RuntimeError)` ⊃ `MrhCallSpecError(+ValueError)`, `CleanroomError`.

## 순수 수치 (torch 텐서, CPU, 결정론; 모양 불일치·음수 가중치·가중치 합 0·헤드 키 불일치는 `ValueError`)
- `global_size(h, w, pixels=GLOBAL_PIXELS)->(gh,gw)`: `s=min(1, sqrt(pixels/(h·w)))`, 각 변 `max(16, 16·round(s·변/16))`. 업스케일 없음. (576,1024)→(576,1024), (2160,3840)→(576,1024), (1000,1000)→(768,768).
- `TileBox(y0,x0,y1,x1)`(frozen, 캔버스 px). `plan_tiles(h, w, tile=TILE_PX)->tuple[TileBox]`: h,w는 16 배수. 두 변이 모두 ≤tile이면 `()`. 변마다 `n=ceil(L/tile)`(L≤tile이면 1, 타일 크기 `min(tile,L)`), 시작은 16의 배수·엄격 증가·첫 0·끝 `L-크기`·인접 간격 ≤ 타일 크기(틈 없음). 행 우선(y 먼저). (2160,3840)→12, (1152,2048)→4, (576,1024)→0.
- `tile_weights(boxes, canvas_hw, feather_px=FEATHER_PX)->Tensor[T,H4,W4]`(H4=H/4): 출력 격자 셀 i(타일 셀 구간 [c0,c1), 캔버스 셀 수 N, F=feather_px/4)의 축 가중치 `d=min(c0>0 ? i-c0+0.5 : ∞, c1<N ? c1-i-0.5 : ∞)`, `u=clamp(d/F,0,1)`, `s(u)=u²(3-2u)`(F=0이면 1). 타일 가중치 = 두 축 곱, 밖은 0. 캔버스 가장자리는 페더 없음.
- `affine_fit(src, ref, weight=None)->(a,b)`: 가중 최소제곱 `a·src+b≈ref`, **a≥0**. 가중 분산 ≤1e-12이거나 LS의 a<0이면 `(0, ref 가중평균)`(부호가 뒤집힌 깊이는 "모순"으로 남는다).
- `affine_residual(src, ref, weight=None, floor=DEPTH_FLOOR)->(rel, resid_map)`: 정렬 뒤 `rel = rms / max(ref의 가중 표준편차, floor)`, `resid_map = |a·src+b-ref| / 같은 분모`.
- `fuse_global(reads: Sequence[Mapping[str,Tensor[1,c,h,w]]], *, depth_key="log_depth", floor=DEPTH_FLOOR)->FusedGlobal(outputs, r_dis_sigma, sigma_map[h,w])`: 1개면 복사·0. 2개면 깊이는 둘째를 첫째에 affine 정렬해 평균(**게이지 = 첫 σ**), 나머지는 평균, `normal`·`sem`은 평균 뒤 채널 단위 정규화(‖·‖≥1e-6). `r_dis_sigma`=정렬 상대 잔차, `sigma_map`=그 `resid_map`.
- `blend_reads(glob, tiles: Sequence[tuple[TileBox,Mapping]], *, canvas_hw, feather_px=FEATHER_PX, depth_key="log_depth", floor=DEPTH_FLOOR)->BlendResult(outputs, coverage[H4,W4], weights[T,H4,W4], affine(tuple[(a,b)]), rel(tuple[float]), r_dis_tiles, tile_map[H4,W4])`. glob은 출력 격자 `[1,c,H4,W4]`, 타일은 자기 격자. 타일 t의 깊이를 풋프린트(균일 가중)에서 전역 깊이에 `affine_fit`한 `T_t'`로 바꾼다. `W=Σw_t`; `out = Σ w_t·T_t' / max(W,1) + max(0,1-W)·G`(깊이 외 채널은 정렬 없음; `normal`·`sem` 재정규화). 즉 가중치 합은 항상 1이고 타일 사이 경계와 타일 없는 곳은 **전역 뷰로 채운다**. `rel[t]`=타일별 `affine_residual` 상대값, `r_dis_tiles=mean(rel)`(타일 없으면 0.0), `tile_map = Σ w_t·resid_t / W`(W<1e-6인 셀은 0).

## 읽기기 (교사→탭→MRH)
`ViewRead(outputs: Mapping[str,Tensor[1,c,h/4,w/4]] f32 CPU 분리본, sigma: float, digest: bytes32, ephemeral: bool)`. 읽기기 규약: `reader.snap(sigma)->float`(표의 점), `reader(image[1,3,h,w] f32 ∈[-1,1], sigma, *, prov, key)->ViewRead`.
`MrhReader(sampler, bus, mrh, *, token_offset=0, caption=SURVEY_CAPTION, seed=0, ring=None)`: `mrh.cfg.tap_layers==bus.layers`, `mrh.cfg.tap_dim==bus.basis.k`이 아니면 `MrhCallSpecError`. 호출은 **검증(`[1,3,h,w]`·유한·[-1,1]·h,w 16 배수·`as_record(prov)`·bus.attached)을 교사 호출 전에** 끝낸 뒤: `σs=snap(sigma)`; `x0=teacher.encode_image(image)`; `ε=teacher.make_noise(det.derive_seed(seed,key),1,h,w)`; `z=add_noise(x0,σs,ε)`; `with bus.capture(prov, grid=(h//16,w//16), token_offset, key, ring)` 안에서 `sampler.predict_x0(z,σs,[caption])` **정확히 1회**; `mrh(ts.features(basis), σs)`(`no_grad`, MRH `t`=σs, 가중치·모드·grad 불변). TapSet은 어디에도 보관하지 않는다. ext prov면 `ephemeral=True`이고 링은 건드리지 않는다(TCH-03 바이패스).

## 오케스트레이터
`ReadConfig(kw_only, frozen)`: `global_sigmas=(0.20,0.35)`(1–2개, 각 (0,1] 유한), `tile_sigma=0.25`, `tiles=True`, `tile_px=1024`(16 배수), `global_pixels=GLOBAL_PIXELS`(≥256), `read_long_max=3840`(16 배수), `feather_px=64`(4 배수, ≥0), `heads=HEAD_NAMES`(부분집합·중복 없음·`log_depth` 포함), `depth_floor=DEPTH_FLOOR`(>0), `unc_tau=UNC_TAU`(>0). 위반 `MrhCallSpecError`.
`lane_for(prov)->"cleanroom"|"engine"`(= ext 비트).
`read_mrh(image_lin, reader, *, prov, cfg=ReadConfig(), key="read", lane=None, cleanroom_binary_hash=None)->MrhReadout`.
1. **검증은 읽기기 호출 전에 전부**: `image_lin` (H,W,3) 실수·유한·≥0·짧은 변 ≥16(아니면 ValueError/TypeError), `prov`→`as_record`, `key` 비지 않은 str, `lane`∈{None,"engine","cleanroom"}(아니면 `MrhCallSpecError`), ext인데 `lane="engine"`이면 `CleanroomError`.
2. 긴 변 > `read_long_max`이면 면적 평균으로 축소(`read_hw`). 16 배수까지 오른쪽·아래 `edge` 패딩 = 캔버스. 표시값 `x=2·linear_to_display(canvas)-1`.
3. 전역 뷰 = 캔버스를 `global_size`로 축소(같으면 그대로). σ는 `reader.snap`한 뒤 중복 제거(앞 우선). 기본 잠정 표에서는 0.2·0.35가 모두 0.3으로 붙으므로 **전역 1회만 부르고 `sigma_pair_degenerate=True`, `r_dis_sigma=0`**. 키 `f"{key}/g{i}"`. 타일(`tiles` 켜짐·`plan_tiles` 비지 않음)은 캔버스 크롭 그대로, `reader.snap(tile_sigma)`, 키 `f"{key}/t{j}"`. 호출 순서 = 전역(σ 순) → 타일(행 우선). 읽기기에는 **스냅한 σ**를 넘기며 `global_sigmas`·`tile_sigma`도 스냅한 값이다(타일이 없으면 `tile_sigma=None`). 읽기기 출력이 `heads` 키를 빠뜨리거나 `[1,c,h/4,w/4]`가 아니거나 비유한이면 `MrhCallError`.
4. 전역 융합(`fuse_global`) → 크기가 다르면 쌍선형(`align_corners=False`)으로 캔버스 출력 격자까지(같으면 항등), `normal`·`sem` 재정규화 → `blend_reads` → `[ :ceil(Hr/4), :ceil(Wr/4)]` 크롭.
5. `r_dis = max(r_dis_tiles, r_dis_sigma)`; `r_dis_map = max(tile_map, 전역 σ 지도 업샘플)`; `uncertain = r_dis_map > unc_tau`.
6. **클린룸**: ext면 모든 `ViewRead.ephemeral`이 True여야 하고 아니면 즉시 `CleanroomError`. 결과 `prov = derive("mrh_read",[prov])`(USER→USER-DERIVED, ns 보존).

`MrhReadout`(frozen, 텐서는 CPU f32): `outputs{head:[1,c,h4,w4]}`, `depth_global[1,1,h4,w4]`(게이지 = 첫 전역 σ), `coverage[h4,w4]`, `r_dis_map`, `uncertain[bool]`, `r_dis, r_dis_tiles, r_dis_sigma, uncertain_frac`, `tiles, tile_affine`, `global_size, global_sigmas, tile_sigma, sigma_pair_degenerate`, `src_hw, read_hw, canvas_hw`, `n_forward`(= 읽기기 호출 수), `lane, ext, ns, prov, cleanroom_binary_hash, key, digests`, `meta()->dict`(`json.dumps(allow_nan=False)` 가능, 텐서 없음, 키 ⊇ lane, ext, ns, key, n_forward, n_tiles, global_sigmas(list), sigma_pair_degenerate, r_dis, r_dis_tiles, r_dis_sigma, uncertain_frac, cleanroom_binary_hash).

## 불변식
같은 입력·같은 읽기기 → 비트 동일. 판독 값은 prov(레인)와 무관하다(digest만 prov 비트로 달라진다). 타일이 전역과 게이지만 다르면(affine) 혼합 결과는 전역 게이지로 돌아오고 `r_dis≈0`. 가중치 합 1(경계 이음매 없음). 출력 정규 헤드는 단위벡터. 입력 배열 불변. 실패는 부분 결과를 내지 않는다.
