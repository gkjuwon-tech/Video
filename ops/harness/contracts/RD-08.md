# RD-08 R6 미터 스케일 v0 — 크기 사전 로그 가중 최소제곱 + 앵커 + 저술된 스케일

**목적.** MRH 깊이는 affine-불변이다. 검출된 객체의 "상대 크기" `ĥ_k`와 크기 사전(DAT-16, 로그정규)으로 전역 스케일 `s`(미터 = s × 상대 단위)와 불확실도 `σ_s`를 푼다. DOF·레벨·CPL·대기 β가 이 `s`를 쓴다. 한 객체에 몰린 크기 잔차는 "저술된 스케일"로 분리해 풀이에서 뺀다. 증거가 없으면 모른다고 말한다(`reliable=False`).
**소유.** `buc/read/metric_scale.py`, 테스트 `tests/rd_08/`(동결). numpy·표준 라이브러리만(torch·cv2 금지), import 부작용 없음(YAML·표 적재는 `default_table()` 호출 때만), 전역 RNG 불변, 순수·결정론·입력 불변. 의존: DAT-16 `tools/size_prior_check.py`(패키지 아님: `importlib` 경로 적재, `default_table()`가 감싼다), RD-02(`f_source`→`SIGMA_LOG_F`), RD-07(`log_depth`는 호출자가 `exp`로 상대 깊이로 바꿔 넘긴다). 소유 밖 요청: 없음.

## 수학 (정확히 이 식)
객체 k: `a_k=μ_c−ln ĥ_k`(그 객체 혼자 말하는 ln s), `v_k=σ_c²+σ̂_h,k²`, `w_k=q_k/v_k`. 앵커 j: `a=log_s`, `w=1/σ²`. 풀이 집합 P(저술 제외)에서
`ln s* = Σ w·a / Σ w`, `σ_stat=(Σ w)^-1/2`, `σ_s=√(σ_stat²+sigma_log_f²)`(FOV 오차는 모든 객체에 공통이라 N으로 줄지 않는다). `s=exp(ln s*)`.
`z_k=(a_k−ln s*)/√v_k`(P의 객체), `chi2_red=Σ w'(a−ln s*)²/(n_P−1)`에서 `w'=1/v`(앵커 포함, 자유도=P의 항 수−1; 항 ≤1이면 None). `log_size_resid_k = ln s* + ln ĥ_k − μ_c`(양수 = 사전 중앙값보다 큼; 저술된 객체도 최종 `s*`로 계산).
**저술된 스케일.** 사용 객체가 `min_obs_author`개 이상이고 `saliency`가 **유일한 최대(>0)**인 객체 k*에 대해, k*를 뺀 풀이 `ln s_-`(앵커 포함, 분산 `σ_-²=1/Σ_{j≠k*} w`)로 `r=a_k*−ln s_-`, `|r|/√(v_k*+σ_-²) > z_author`이고 나머지 모든 사용 객체가 `|a_j−ln s_-|/√v_j ≤ z_inlier`이면 k*를 저술로 표시(`factor = exp(ln s_- + ln ĥ_k* − μ)` = 사전 중앙값 대비 크기 배수)하고 풀이에서 뺀다. 저술은 최대 1개.
**증거 없음**(P 비어 있음): `ln s*=default_log_s`, `σ_s=default_sigma`(+공통모드), `source="default"`, 경고 `no_scale_evidence`. `source`∈{"size_prior","anchor","size_prior+anchor","default"}. 경고 어휘: `no_scale_evidence, unknown_class, scale_inconsistent`(chi2_red>chi2_warn), `authored_scale`, `scale_ambiguous`(σ_s>sigma_reliable). `reliable = source≠"default" ∧ σ_s≤sigma_reliable ∧ ¬scale_inconsistent`.

## 불변식
같은 입력 → 비트 동일. 객체 순서 불변(상대 오차 1e-12). 모든 `ĥ`를 c배 → `ln s` 는 정확히 `−ln c` 이동, σ 불변. `q→0` 객체는 결과를 바꾸지 않는다. 사전 중앙값 크기로 만든 관측은 `s`를 1e-9로 복원. 입력 불변. 비유한은 구성 시 ValueError. 부분 결과 없음.

## 수용 기준 (`tests/rd_08/`, CPU, <60 s)
수식 오라클(손계산 2–3객체, 앵커 포함), 불변식 위 전부, 복원(중앙값·잡음 없음), 몬테카를로(고정 시드, q=1, 실제 DAT-16 표에서 뽑은 객체 ≥3개: `|ln s*−ln s_true|≤2σ_s` 포함률 93–97.5 %; 공통모드 FOV 오차 주입 시 `sigma_log_f` 없으면 미달·있으면 충족), 저술(야크: 주 피사체 ×3 → 표시·풀이 불변·factor≈3; 비최상 saliency·2객체·두 객체 동시 위반은 표시 안 함 + `scale_inconsistent`), 알 수 없는 클래스·별칭(`door`), 증거 없음 기본값, 앵커 헬퍼 수식, `rel_size`/`make_obs`↔기하(핀홀 투영 왕복), 단일 약한 객체 → σ 큼·`reliable=False`, 검증 오류(음수·NaN·타입), `to_meta` JSON, `torch`·`yaml` 미로드(import 시점), 실제 표 적재·RD-02 `SIGMA_LOG_F` 키 일치.
**미검증:** 상대 크기 `ĥ` 자체를 어떻게 얻는가(MRH sem→검출·마스크→픽셀 범위, 피치 단축 보정은 미구현), affine 깊이의 이동(shift) 모호성(호출자가 스케일-전용 게이지로 넘긴다고 가정), 실제 장면의 사전 적중률, EXIF 피사체 거리(RD-01 화이트리스트에 없음).
